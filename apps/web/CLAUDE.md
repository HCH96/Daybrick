# 공유 웹 규칙 (apps/web)
공유 웹 코드를 다루거나 웹 기능을 명세·계획할 때 따른다. 문서 색인은 공유 웹을 시작할 때 docs/web/index.md로 만든다.
서버를 쓰는 기능이면 supabase/CLAUDE.md(모든 앱 공용 서버 규칙)를 먼저 읽는다.

## 지금 구성
- `public/`의 정적 HTML·CSS만 있다: 안내 페이지(index.html), 개인정보처리방침(privacy.html), site.css.
- Vercel 프로젝트에 연결돼 있다 (`.vercel/`은 커밋하지 않는다).
- 원래 계획은 React였다. 정적 HTML로 계속 갈지 React로 바꿀지는 공유 웹 기능을 시작할 때 정한다.

## 원칙
- 읽기 전용이다. 웹에서는 데이터를 고치지 않는다.
- 계획된 페이지: 면접관용 공개 페이지(공부 통계), 친구용 링크 공유 페이지(지원 현황 포함).

## 명령어
- 빌드 도구가 생기면 추가한다.
