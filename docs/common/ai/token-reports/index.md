# 토큰 보고서 목차
`/implement` 실행 한 번(또는 직접 분석한 세션 하나)당 보고서 파일 하나. 토큰을 많이 쓰는 작업과 컨텍스트가 길어지는 원인을 찾아 줄이는 데 쓴다.

- 만드는 법 (프로젝트 루트에서): `node .claude/scripts/token-report.mjs [세션ID] --title "<제목>" --out docs/common/ai/token-reports/<기능명>-<YYYY-MM-DD>.md`
  - 세션ID를 생략하면 가장 최근 세션. 메인 세션과 그 세션이 띄운 하위 에이전트(단계)를 함께 분석한다.
- 같은 날 두 번이면 파일 이름 끝에 `-2`를 붙인다.

| 날짜 | 기능 | 보고서 | 하위 에이전트 수 | 총 입력 | 최대 컨텍스트 |
|---|---|---|---:|---:|---:|
