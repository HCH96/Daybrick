# Daybrick 디자인 방향
모든 페이지를 폴리싱할 때 기준이 되는 문서. 여기 없는 내용이 필요하면 **추측하지 말고 사용자에게 물어서 확인받은 뒤 이 문서에 먼저 적고** 작업한다.
값은 apps/desktop/src/styles/theme.css의 토큰을 쓴다. 새 값이 필요하면 토큰으로 추가한다.

## 방향 한 줄
**하루를 벽돌처럼 쌓는다.** 밤 책상 위 모눈종이처럼 바탕은 조용하고, 쌓인 기록과 지금 진행 중인 것만 색과 움직임을 갖는다.
- 성격: 묵묵함, 꼼꼼함, 쌓일 때 조금 즐거움
- 서명: 성과 하나 = 작은 벽돌 한 장. 줄마다 반 칸씩 엇갈려 쌓는다. 기록을 보여주는 곳에만 쓴다

# 1부. 공통 규칙

## 1. 페이지 틀
- 본문은 **최대 1280px, 가운데 정렬**. 창이 더 넓으면 양옆은 바탕색 여백으로 남는다. 모든 메뉴 페이지에 똑같이 적용한다 (투데이·캘린더·플랜·프로젝트 포함)
- 예외: 설정은 입력 위주라 **최대 880px, 가운데 정렬**
- 바깥 여백은 지금 값(AppLayout `28px 32px`)을 유지한다
- 첫 실행 안내·연결 마법사는 사이드바 없는 전체 화면이라 이 규칙과 따로 간다 (가운데 카드)

## 2. 페이지 제목
- 맨 위 큰 제목(h1)은 **사이드바와 같은 영어 이름**: Home, Today, Calendar, Plan, Projects, Applications, Job Search, Settings. `NAV_LABELS`에서 가져온다
- 제목만 영어다. 부제, 탭, 카드·섹션 제목, 버튼, 안내 문구는 한글을 유지한다
- 예외: **홈은 제목 자리에 "좋은 하루예요"를 그대로 둔다** (위의 날짜 줄도 유지)
- 예외: 프로젝트 상세처럼 메뉴 안의 하위 화면은 그 항목 이름을 제목으로 쓴다 (‹ 뒤로 + 색 점 + 프로젝트 이름, 26/600)
- 제목 크기는 26px/600, 자간은 -0.3px. 제목 옆이나 아래의 부제는 13px muted

## 3. 글씨체
- 인터페이스: **Pretendard** (Variable). 앱 안에 글꼴 파일을 넣어서 쓰고, 인터넷에서 불러오지 않는다
- 숫자: Pretendard에 `font-variant-numeric: tabular-nums`. 따로 숫자 글꼴을 쓰지 않는다
- mono(`--mono`, Cascadia Mono): 투데이 타이머 시계, 코드 상자(CodeBox)에만 쓴다
- 대체 글꼴 순서: `"Pretendard Variable", Pretendard, "Malgun Gothic", "Segoe UI", sans-serif`

## 4. 글자 크기와 굵기
- 크기는 이 단계만 쓴다: **11, 12, 13, 14, 16, 20, 26**. 큰 숫자 표시(타이머 등)만 34, 56. 12.5나 13.5 같은 중간값은 쓰지 않는다
- 굵기: 본문 400, 라벨·강조 500, 제목 600. **700·800은 쓰지 않는다**
- 위계는 굵기보다 크기와 색(text, muted, faint)으로 만든다
- 음수 자간은 20px 이상 제목에만. 작은 글자는 0
- 영어 라벨도 대문자로 바꾸지 않는다. 기울임(italic)은 쓰지 않는다

## 5. 색
- 바탕은 지금의 그라파이트 단계를 유지한다: `--bg`, `--sidebar`, `--surface`, `--surface-2`, `--popup`
- 글자색은 세 가지만 쓴다: `--text`, `--muted`, `--faint`
- 강조색은 **보라 `--accent` 유지**. 쓰는 곳은 셋뿐이다: 주요 버튼, 선택된 것, 화면마다 가장 중요한 칸이나 숫자 하나. 포커스 링도 보라
- 보라 바탕 위 글자는 `--on-accent`(어두운 색)
- 상태색(파랑·주황·초록·빨강)은 뜻이 있을 때만 쓰고, 연한 바탕(`*-soft`)과 짝지어 쓴다
- 테두리는 `--border`, `--border-2`만 쓴다
- **theme.css 밖에서 색을 직접 쓰지 않는다.** 예외는 "순간" 그림 안(투데이 트랙·도트 캐릭터, 깃발·모닥불, 색종이), 기능용 그라데이션(가림 마스크, 색 고르기 판), 저장되는 데이터 색(카테고리·프로젝트 기본색은 hex)뿐
- 쓰지 않는 것: 그라데이션 바탕, 빛 번짐(radial), 글로우, 색 그림자. 점선 줄무늬·가림 마스크 같은 기능용 그라데이션은 괜찮다
- 그림자는 팝업·모달·끌고 있는 카드에만 쓰고, 무채색으로 작게. 평소 카드는 바탕 단계와 테두리로만 구분한다

## 6. 간격
- 모든 여백·간격·고정 높이는 **4px 배수**. 작은 부품 안의 미세 조정만 2px 허용 (6, 10, 14, 18, 22px는 쓰지 않는다)
- 카드 안쪽 여백 20, 작은 패널·팝업 16, 카드 사이 간격 20
- 목록 한 줄 높이: 보통 36, 촘촘하게 32. 한 목록 안에서는 모두 같게
- 묶음 안쪽 간격은 묶음 사이 간격보다 작게. 섹션 라벨은 아래 내용과 8, 위 내용과 24 띄운다
- 사이드바 메뉴 줄은 높이 34, 줄 사이 2

## 7. 모서리
- 버튼·입력 8, 카드 12(`--radius`), 모달·큰 패널 16
- 안쪽 모서리 = 바깥 모서리 − 사이 여백, 최소 4
- 알약(완전히 둥근) 모양은 알림 숫자 배지와 켜고 끄는 스위치에만 쓴다

## 8. 부품
- **상태 배지**: 알약 대신 높이 22, 모서리 6, 연한 바탕, 6px 점 + 글자 12px/500
- **사이드바 활성 메뉴**: 보라 바탕·보라 글자 대신 `--surface-2` 바탕 + `--text` 글자 + 왼쪽 3px 보라 막대
- **탭**: 밑줄 탭 유지. 선택된 탭은 `--text` 글자(500) + 2px 보라 밑줄
- **개수 표시**: 빛나는 배지 대신 muted 숫자. 알림 숫자 배지만 `--badge`
- **아이콘**: 프로젝트 자체 라인 아이콘(LineIcon)만 쓴다. 16px, 선 굵기 1.5, 글자색을 따른다. 이모지는 쓰지 않는다
- **카테고리 색 띠**: 태스크를 나타내는 칩·카드(캘린더 태스크 칩, 투데이 칸반 카드, 회고 기록 막대)는 왼쪽 3px 카테고리 색 띠를 둔다 (`box-shadow: inset 3px 0 0 <색>`). 앱 전체에서 같은 모양으로 쓴다
- **차트**: 강조는 하나만(오늘, 이번 주, 지금 진행 중). 나머지는 무채색 단계. 사용자가 고른 카테고리 색은 그대로 쓴다
- **로고**: 보라 벽돌 칸 + "Daybrick" 글자를 유지하되, 글자 굵기는 600

## 9. 문구
- 느낌표를 쓰지 않는다. 예외: 골인 연출의 "골인!"
- 버튼, 라벨, 제목, 짧은 안내 끝에 마침표를 찍지 않는다. 여러 문장으로 된 안내 문단만 찍는다
- 개발 메모 같은 문구를 화면에 두지 않는다 (예: "기능이 늘면 아래에 칸이 추가됩니다")
- 숫자는 화면 안에서 형식을 하나로 맞춘다
- 시간은 용도별로 나눈다: 시계와 목표 대비 진행은 `H:MM`(예: "3:20 / 6:00"), 길이를 말하는 문장·범례는 한글(예: "1시간 20분")
- 홈 제목 외에는 인사 문구를 쓰지 않는다

## 10. 움직임
- 곡선은 하나: `cubic-bezier(0.2, 0.7, 0.3, 1)`. 시간은 반응 120ms, 들어오는 것 200ms
- 바꾸는 속성을 이름으로 적는다 (`transition: background-color 120ms …`). `all`과 너비·높이·위치 애니메이션은 쓰지 않는다
- 반복 애니메이션은 **실제로 지금 진행 중인 것**(타이머 작동, 실시간 표시)에만 쓴다
- 골인·완료 축하는 한 번만 재생하고 2초 안에 끝낸다
- `prefers-reduced-motion`이면 반복과 이동을 끈다

# 2부. 페이지 유형별 표현
"순간"은 화면에서 색과 공을 가장 많이 들이는 한 곳이다. 그 밖은 1부 규칙대로 조용하게 둔다.

| 유형 | 페이지 | 순간 | 보라 쓰는 곳 |
|---|---|---|---|
| 한눈에 보기 | 홈 | "이번 주 집중" 막대그래프 | 이번 주 집중의 막대(오늘은 보라, 지난 요일은 흐린 보라), 빠른 추가 |
| 지금 실행 | 투데이 | 타이머 트랙 장면 (지금 그대로) | 타이머 시작 버튼, 트랙 진행선 |
| 시간 축 계획 | 캘린더, 플랜, 지원 관리의 캘린더 보기 | 없음 | 오늘 날짜 표시 하나 |
| 쌓인 기록 | 프로젝트 | 잔디 히트맵(정사각 칸 그대로), 모닥불 | 잔디 진하기, 진행 중 표시 점 |
| 모음과 관리 | 지원 관리, 구직 관리 6탭 | 없음 (추천 점수 상자 정도) | 주요 버튼, 선택된 탭 밑줄 |
| 가끔 들르는 화면 | 설정, 첫 실행 안내, 연결 마법사, 서버 화면 | 첫 실행 안내의 큰 벽돌 마크 | 다음 단계 버튼, 로고 |

## 한눈에 보기 (홈)
- 요약 줄 4칸은 라벨 + 큰 숫자(또는 한 줄)만. 작은 막대·장식을 넣지 않는다
- 카드는 크기를 섞는다 (지금처럼 7·5·4칸). 순간 카드 하나 외에는 목록과 숫자만
- "이번 주 집중"은 벽돌 벽으로 바꾸지 않고 **월~일 세로 막대그래프**를 유지한다 (벽돌 벽을 그려 봤으나 사용자가 막대를 골랐다). 오늘 막대와 요일 글자는 보라, 지난 요일 막대는 흐린 보라(`--accent-dim`, 차트 규칙의 예외), 안 온 요일은 납작한 회색, 하루 목표는 가로 점선
- 홈 안의 주요 버튼(지금 하는 것의 [시작]·[완료]·[재개])은 보라 대신 **밝은 무채색**(`--text` 바탕 + `--bg` 글자). 홈의 보라는 이번 주 집중 막대, 빠른 추가, 포커스 링에만

## 지금 실행 (투데이)
- 타이머 시계는 mono로 크게. 도트 캐릭터 장면은 유지하되, 골인 반복만 한 번 재생으로 바꾼다
- 칸반 카드는 가장 담백하게: 왼쪽 3px 카테고리 색 띠, 제목, 카테고리 점, 시간
- 오늘 요약 타일은 숫자 중심. 연속 기록은 벽돌 서명을 쓸 수 있다

## 시간 축 계획 (캘린더·플랜)
- 정보 밀도가 먼저다. 칸 선은 `--border`, 칩은 카테고리 색 점이나 연한 바탕. 태스크 칩은 연한 바탕 + 왼쪽 3px 카테고리 색 띠
- 칩 높이와 간격은 한 달력 안에서 모두 같게. 강조는 오늘 하나
- 요일 머리의 주말은 예외로 색을 둔다: 토요일 `--blue`, 일요일 `--red` 글자. 오늘 보라 표시와 따로 가고, 캘린더·플랜에서 같게 쓴다
- 월 넘김 슬라이드(200ms)처럼 위치를 알려주는 움직임만 쓴다

## 쌓인 기록 (프로젝트)
- 앱에서 가장 풍부해도 되는 화면. 잔디 히트맵이 주인공이고, 버블은 그보다 작고 조용하게
- 잔디는 엇갈린 벽돌로 바꾸지 않고 **정사각 칸 + 보라 4단계 진하기**를 유지한다 (차트 강조 하나 규칙의 예외). 오늘 칸은 테두리로 표시하고, 한 프로젝트로 거르면 그 프로젝트 색으로 칠한다
- 타이머 진행 중 표시 점은 빨강 대신 보라. 타이머가 도는 동안만 보이고 깜빡인다
- 모닥불·깃발 트랙은 유지한다. 반복 움직임은 타이머가 작동 중일 때만

## 모음과 관리 (지원 관리·구직 관리)
- 가장 조용한 화면. 카드·표의 주인은 회사명, 상태, 날짜, 점수
- 상태는 1부의 상태 배지. 점수·금액·개수는 tabular 숫자
- 구직 관리 탭이 6개라 탭마다 제목을 또 달지 않는다
- 구직 관리 점수 등급 색은 4색 유지: 적극 추천 초록, 추천 보라, 애매 주황, 비추천 회색. 점수 상자를 이 유형의 순간으로 보고 보라를 허용한다 (카드·목록·팝업 모두 같게)
- 보라였던 상태 칩은 뜻대로 나눈다: 진행 중인 것(처리 중, 새 초안, 상태 변경 제안)은 파랑, 그 밖(포함 조건, 공유)은 무채색. 제외 조건은 빨강
- 새 공고 표시는 파랑 상태 배지 "새 공고"(알약·빨강 쓰지 않음), 카드 테두리는 다른 카드와 같게

## 가끔 들르는 화면 (설정·첫 실행·마법사)
- 첫 실행 안내만 장면을 허용한다: 큰 벽돌 마크 + 하는 일 한 줄 + 버튼 하나와 보조 링크 하나. 보라 빛 번짐은 없앤다
- 첫 실행 안내의 제목은 인사 대신 "Daybrick", 아래에 하는 일 한 줄. 준비물은 카드 대신 버튼 아래 faint 글자 한 줄로 (자세한 건 ① 준비 단계)
- 마법사·서버 화면에서 진행 중(실행 중 줄, 돌아가는 원)은 파랑. 보라는 다음 단계 버튼, 지금 단계 번호, 세팅 진행 막대, 로고에만
- 마법사는 단계 진행선과 입력만. 설정은 순수한 입력 화면
