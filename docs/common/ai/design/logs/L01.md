# L01 · 2026-11-07 · 수정: 공통 기반 폴리싱

- 요구사항: 폴리싱 (design-direction.md 1부 중 여러 페이지에 걸리는 것)
- 한 일:
  - theme.css에 글자 크기·굵기·간격·모서리·그림자·움직임 토큰과 무채색 겹침색(마우스 올림, 덮개, 위험 버튼, 띠 테두리 등)을 추가했다. 공용 CSS에 직접 쓴 색을 모두 토큰으로 바꿨다
  - Pretendard Variable을 npm 패키지(`pretendard`)로 앱에 넣고, 대체 글꼴 순서와 body 전체 tabular-nums를 적용했다. 움직임 줄이기(reduced-motion) 규칙을 추가했다
  - 본문 최대 1280px 가운데 정렬: 본문 칸을 너비 측정 틀(container)로 감싸고 좌우 여백을 `max(32px, (100cqw − 1280px) / 2)`로 계산한다. 감싸개를 쓰지 않아 꽉 채우는 페이지와 긴 페이지의 아래 여백이 그대로다
  - 사이드바: 줄 높이 34·간격 2, 선택 메뉴는 surface-2 바탕 + 왼쪽 3px 보라 막대, 로고 16px/600. 너비 애니메이션을 없애 접기·펴기가 바로 바뀐다 (모달 최대화의 left 전환도 제거)
  - 공용 부품(Modal, Popover, ConfirmDialog, EmptyState, SegmentedControl, MiniCalendar, 알림 패널·행·종, 서버 띠, 이어하기 창, 업데이트 안내): 4배수 간격, 굵기 400/500/600, 모서리 8/12/16, 그림자 두 단계, 곡선·시간 토큰. 탭 개수와 알림 줄 버튼에서 보라를 뺐다
  - LineIcon 기본 16px·선 1.5, 각 아이콘의 기본 크기 15·18을 16으로. 서버 띠 문구 5개와 이어하기 창 한 줄의 끝 마침표를 지웠다 (features/server/messages.ts는 문자열만 수정)
- 확인: `npm run build` 성공. 미리보기(1600×900)에서 본문 너비 1280·좌우 여백 60, 사이드바 줄 34, Pretendard 적용, 홈 아래 여백 28 유지, 캘린더 높이가 본문에 꽉 참(스크롤 없음), 알림 패널 빈 상태, 콘솔 오류 없음을 확인했다
- 코드만 보고 판단: 확인 창, 이어하기 창, 서버 띠, 미니 달력, 칸 나눔 버튼 (미리보기에서 열지 않음)
- 사용자 확인: 대기
- 남은 문제:
  - 작은 전용 아이콘(기본 12~14px, TodayIcons·CalendarIcons의 14px 좌표 아이콘 선 1.3~2)은 칩 배치에 맞춘 것이라 그대로 두었다. 해당 페이지 차례에 본다
  - 페이지 CSS에 남은 700·800 굵기, 4배수 아닌 값, 직접 쓴 색은 각 페이지 차례에 고친다
  - Modal.tsx가 붙이는 `modal-layer--follow` 클래스는 이제 스타일이 없어 아무 일도 하지 않는다
- 주요 파일: styles/theme.css, styles/base.css, components/layout/AppLayout.*, components/layout/Sidebar.css, components/common/*.css, components/icons/LineIcon.tsx
