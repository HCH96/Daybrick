- 작성일: 2026-10-22
- 상태: 승인됨, T1~T3 구현 완료, 사용자 확인 완료 (2026-10-22)

## 결정 사항 (2026-10-22 사용자 결정)
1. 사이드바 접힘 상태는 앱을 다시 켜도 기억한다 (PC 안의 localStorage).
2. 단축키를 넣는다: `Ctrl+B` 사이드바, `Alt+←`/`Alt+→` 뒤로/앞으로, 마우스 옆 버튼 뒤로/앞으로.
3. 명세서의 "사이드바 접기 기능은 넣지 않는다"를 이 계획으로 바꾼다.

## 화면
```
[▥] [←] [→]        (빈 곳: 끌어서 창 이동, 더블클릭 최대화)        ─  □  ✕   ← 높이 40px
```
- 제목 표시줄 색은 사이드바와 같은 `#1C1C20`, 아래 구분선. "Daybrick" 글자는 넣지 않는다 (사이드바 로고에 있음).
- 왼쪽 버튼: 18px 선 아이콘, 마우스를 올리면 밝은 바탕. 사이드바가 펼쳐져 있으면 사이드바 버튼이 눌린 상태로 보임. 갈 곳이 없는 ← →는 흐리게, 비활성.
- 오른쪽 버튼: Windows 기본과 같은 위치·크기(46x40). ✕에 마우스를 올리면 빨간 바탕. 최대화 상태에서는 □가 겹친 네모로 바뀜.
- 사이드바를 접으면 완전히 사라지고 본문이 전체 폭을 쓴다. 0.15초 동안 미끄러지듯 움직인다.

## 뒤로 / 앞으로
- 화면 이동마다 방문 기록에 쌓는다. ←는 이전 화면, →는 뒤로 갔던 화면.
- 뒤로 간 상태에서 새로 이동하면 앞쪽 기록은 지운다. 지금 화면을 다시 누르면 쌓지 않는다.
- 앱을 다시 켜면 기록은 비고 홈부터 시작한다.

## 알려진 제약
- Windows 11의 □ 버튼 위 스냅 레이아웃 메뉴는 나오지 않는다 (직접 그린 제목 표시줄의 공통 제약). `Win+←/→`, 화면 끝으로 끌어 붙이기는 된다.
