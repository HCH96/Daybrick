- 이전 계획: [main-page-plan.md](main-page-plan.md) (1~6단계 구현 완료)

- 상태: 승인됨, 1~5단계 구현 완료 (2026-10-22)
- 경로 기준: `apps/desktop/src/`

## 배경
기존 홈은 카드가 창 높이를 반씩 나눠 가져서, 최대화하면 카드가 지나치게 커진다.
B안: 본문 최대 너비 1280px 가운데 정렬 + 상단 요약 줄 + 12칸 벤토 그리드.

## 결정 사항 (2026-10-22 사용자 결정)
1. 빠른 추가 입력칸: **비활성 상태로 표시** ("할 일 기능을 만들면 사용할 수 있어요")
2. 1200x800 창에서 세로 스크롤: **허용** (본문만 스크롤, 사이드바 고정). 이후 사용자 요청으로 스크롤 바는 숨김 (휠 스크롤은 유지)
3. 요약 줄 4칸 클릭 시 이동: **지금은 이동 안 함**

## 1. 각 칸의 빈 상태
원칙: 가짜 숫자를 넣지 않는다. 데이터가 들어올 틀은 미리 보여준다.

| 칸 | 지금 보여줄 빈 상태 | 누르면 |
|---|---|---|
| 날짜 + 인사 | 지금과 같음 | - |
| 빠른 추가 | 흐린 비활성 입력칸 + "할 일 기능을 만들면 사용할 수 있어요" | 반응 없음 |
| 요약 4칸 | 이름 + 값 "—" + "○○ 연결 전" (캘린더/타이머/스케줄러/지원 관리) | 반응 없음 |
| 오늘 할 일 (large) | 기존 EmptyState | Calendar |
| 오늘 일정 (narrow) | 기존 EmptyState | Scheduler |
| 오늘 집중 시간 (narrow) | 기존 EmptyState | Timer |
| 지원 현황 (wide) | 기존 EmptyState | Applications |
| 이번 주 집중 (narrow, 새 카드) | 월~일 글자 + 납작한 막대 7개, 오늘 요일 강조, "타이머를 연결하면 기록이 쌓여요" | Timer |

## 2. 배치 규칙
- 본문 최대 너비 1280px, 가운데 정렬. 목업의 점선은 넣지 않는다.
- 순서: 상단(날짜·인사 + 빠른 추가) → 요약 줄 4칸 → 12칸 벤토 그리드
  ```
  [ 오늘 할 일 (7칸, 2줄) ][ 오늘 일정 (5칸) ]
  [                       ][ 오늘 집중 시간 (5칸) ]
  [ 지원 현황 (7칸)        ][ 이번 주 집중 (5칸) ]
  ```
- 카드 높이는 창 높이에 맞춰 늘리지 않는다. 최소 높이(약 200px)만 둔다.
- 창 너비 1280px 미만이면 7:5를 6:6으로 바꾼다. 배치 모양은 같다.

## 4. 구현 순서와 확인할 결과
실행: `apps/desktop`에서 `npm run tauri dev` (PowerShell이면 `npm.cmd run tauri dev`)

| 단계 | 할 일 | 확인할 결과 |
|---|---|---|
| 1 | 최대 너비, 벤토 그리드, 기존 카드 4개 크기 조정 | 최대화 시 본문이 가운데 1280px에 모이고 양옆이 여백. 오늘 할 일이 왼쪽에 크게(2줄), 일정·집중이 오른쪽 위아래, 지원 현황이 아래 왼쪽. 최대화해도 카드가 커지지 않음 |
| 2 | 이번 주 집중 카드 | 지원 현황 오른쪽에 카드, 월~일 아래 납작한 막대, 오늘 요일 보라색. "타이머로 가기 →"로 Timer 이동 |
| 3 | 요약 줄 4칸 | 인사 아래 4칸, 값 "—"와 "○○ 연결 전". 눌러도 이동하지 않음 |
| 4 | 빠른 추가 (비활성) | 인사 오른쪽에 흐린 입력칸과 안내 문구, 클릭·입력해도 반응 없음 |
| 5 | 마무리 | `npm run build` 통과, 960x640·1200x800·최대화 확인, 문서 갱신, `/test 메인페이지` 안내 |
