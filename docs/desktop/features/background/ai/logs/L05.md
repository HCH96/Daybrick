# L05 · 2026-11-09 · 구현 3단계: 첫 닫기 안내·타이머 종료 확인

- 요구사항: R4, R10
- 한 일: Rust 새 `background/app_settings.rs`(파일 없거나 깨지면 기본값, 임시 파일 후 바꿔치기, 명령 `load_app_settings`·`mark_close_notice_seen`, 4단계용 `read`·`write`도 pub)를 `lib.rs`에 등록했다.
- 프론트: `api.ts`에 두 명령, 새 `NoticeDialog.tsx`(버튼 하나, ConfirmDialog CSS, Esc는 `onDismiss`, 바깥 클릭으로 닫지 않음), `BackgroundProvider`가 `dialog` 상태와 처리 함수를 context(`useBackground`)로 내준다. 새 `BackgroundDialogs.tsx`를 `TitleBar` 두 모양 모두에 넣었다.
- 종료 흐름: 응답(ack) → 확인 창이 떠 있거나 종료 진행 중이면 무시 → 타이머가 있으면 `showMainWindow` + 확인 창 → [종료]에서야 `runQuitHandlers` → `quitApp`. 저장 전에 묻으므로 [취소]해도 `useCloseFlush`의 sessionRef 문제가 생기지 않는다.
- 계획과 달라진 점: 안내·확인 창이 떠 있는 동안 온 X·Alt+F4는 무시한다 (그 창에서 고르게). 안내 창 제목은 "창 닫기"로 정했다 (자동 진행 중 판단).
- 확인: `cargo check` 성공(경고 0), `npm run build`(tsc 포함) 성공. 앱을 띄워 보는 확인은 하지 않음.
- 사용자 확인: 대기 (최종 테스트)
- 테스트 메모: 안내 창이 떠 있을 때 트레이 "종료"(타이머 없음) → 바로 꺼지는지. 종료 확인 창이 떠 있을 때 X를 눌러도 창이 숨지 않는지.
