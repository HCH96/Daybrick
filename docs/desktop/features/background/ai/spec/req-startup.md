# 백그라운드 실행 요구사항: 시작·자동 시작·중복 실행 (R13–R19)

### 자동 시작
- R13. 윈도우에 로그인하면 Daybrick이 자동으로 실행된다.
- R14. 자동 시작은 처음 실행할 때 켜진다. 설정 페이지의 "앱" 칸에 있는 스위치로 켜고 끌 수 있다.
- R15. 자동 시작으로 실행되면 창을 띄우지 않고 트레이에만 둔다.
- R16. 사용자가 직접(exe나 시작 메뉴로) 실행하면 창을 띄운다.
- R17. 스위치를 바꿨는데 윈도우에 등록하거나 해제하는 데 실패하면, 스위치를 원래대로 돌려놓고 "자동 시작 설정을 바꾸지 못했어요" 문구를 보여 준다.
- R18. 개발 모드(`npm run tauri dev`)에서는 자동 시작을 등록하지 않는다.

### 중복 실행
- R19. 이미 실행 중일 때 다시 실행하면 새로 띄우지 않고, 떠 있는 앱의 창을 R7처럼 연다.

## 화면 구성
설정 페이지에 "앱" 칸을 새로 둔다 (기존 서버·동기화 칸 아래).
```
설정
 ├ 서버
 ├ 동기화
 └ 앱  (새 칸)
     윈도우 시작 시 자동 실행                [● 켜짐]
     켜 두면 로그인할 때 트레이에 숨은 채로 시작해요.
```
