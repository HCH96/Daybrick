## 결정 (계획 중 정함, D10–D17)
- 저장은 앱 데이터 폴더 `plan.json` 하나, Rust `load_plan`/`save_plan`, 0.5초 자동 저장. 화면 설정도 같은 파일 `view` 칸 (D10).
- 메뉴 id `calendar`를 `plan`으로 바꾼다. 홈 "오늘 할 일" 카드는 이동할 곳만 고친다 (D11).
- 끌기는 포인터 이벤트로 직접 만든다. 4px 넘게 움직이면 끌기, 아니면 클릭 (D12).
- 상태 표시는 시작 전 → 진행 중 → 완료 → 시작 전으로 돈다. 완료하면 완료한 날 기록, 풀면 지움 (D13).
- 없어진 지원 카드 연결은 지원 데이터를 다 읽었을 때만 지운다 (D14).
- 카테고리·체크리스트 항목 순서는 배열 순서로 저장한다 (D15).
- 지원 일정·연결 카드를 누르면 페이지 이동 없이 플랜 화면 위에 지원관리 상세 팝업을 띄운다 (D16).
- 기간을 고쳐 시작일 > 끝일이 되면 방금 고르지 않은 쪽을 고른 날로 맞춘다 (D17).

### 작은 규칙
- 카테고리 색은 `#RRGGBB`로 저장하고 화면에서는 `--cat` 변수 + `color-mix`로 옅은 바탕을 만든다 (목업의 `c-blue` 등 클래스 대신).
- 빈 제목으로 Enter·포커스 잃기는 만들지 않고 닫는다. 빠른 입력(R16)·묶음 `+`(R17)는 Enter 뒤에도 입력칸이 남고, 더블클릭 입력(R28)은 Enter 뒤 닫힌다.
- 주 상태는 화면 안에만 둔다 (다시 들어오면 이번 주, R3). 주 계산은 `utils/date.ts` 공용 함수 (extension.md).
- 순수 함수(주 계산·막대 줄 나누기·끌기 날짜 계산)는 Node로 실행해 확인한다. 테스트 도구는 아직 없다.
