R9, R40
6-1카테고리 삭제 (R9)

"C++ 공부" 카테고리를 지울까요?

안에 있는 태스크 5개는 지워지지 않고 미분류로 옮겨져요.

취소카테고리 삭제
6-2태스크 삭제 (R40)

"STL 컨테이너 복습"을 지울까요?

메모와 체크리스트 5개 항목도 함께 지워지고, 되돌릴 수 없어요.

취소삭제
공통
  • 제목에 지울 대상 이름을 따옴표로
  • 설명에 함께 일어나는 일을 한 줄로
  • 지우기 버튼은 빨간 글자 + 휴지통, 기본 선택은 취소
카테고리 삭제
  • 완료한 태스크까지 포함한 개수를 보여준다
  • 태스크가 없는 카테고리면 설명 줄을 "빈 카테고리예요."로
태스크 삭제
  • 메모·체크리스트가 없으면 "되돌릴 수 없어요."만
  • 지운 뒤 팝업은 닫히고 목록·달력에서 바로 빠진다
