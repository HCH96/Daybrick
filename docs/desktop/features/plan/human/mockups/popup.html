문항 정리

  • 문항 3개, 각 1,000자 이내
  • 직무 경험은 프레임 드랍 줄인 경험을 숫자로 (60 → 144fps)

오늘 정리한 것

전투 판정을 프레임마다 다시 계산하던 부분을 이벤트 방식으로 바꾼 과정을 3단계로 나눠 쓰기.

지원관리 카드 공고 요약과 겹치지 않게 쓰기
머리 (지원관리와 같게)
  • 왼쪽 위 최대화 (3-6), 옆에 종류 글자 Task
  • 오른쪽 위 "자동 저장됨" → 삭제 → 닫기. r1의 아래쪽 저장 표시는 없앤다
  • 팝업 바깥(어두운 부분)을 누르면 닫힌다
제목·속성
  • 제목 26px, 누르면 바로 고친다
  • 속성은 이름 150px + 값. 값을 누르면 고르기 창이 열리고, 마우스를 올린 줄만 옅게 칠한다
  • 체크리스트도 속성 한 줄: 진행도 + 작은 막대. 없을 때는 "+ 체크리스트" (3-5)
  • 지원 카드 제목(밑줄)을 누르면 지원관리 팝업, 마우스를 올리면 "연결 끊기"
체크리스트·Notes
  • 항목은 속성 값 칸에 맞춰 들여 쓴다. 맨 아래 "항목 추가"와 오른쪽 "체크리스트 삭제"
  • 체크한 항목은 흐리게만 (취소선 없음, 목록 완료 줄과 같게)
  • 구분선 아래 Notes: 공부·작업 내용을 정리하는 마크다운 본문. 지원관리 본문과 같은 편집기·글자 크기
