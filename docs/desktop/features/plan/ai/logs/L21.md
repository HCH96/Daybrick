# L21 · 2026-11-02 · 구현 수정1 4단계: 체크리스트 속성 줄·끌기

- 요구사항: R37, R38 (영향: R8)
- 한 일: `PropRows` 마지막에 "체크리스트" 속성 줄을 넣었다. 없으면 `+ 체크리스트`(`task-detail__add`), 있으면 `완료/전체` + 80px 진행 막대. `Checklist`는 예전 머리 줄·`+ 체크리스트` 상자를 없애고 항목 목록만 그리며(체크리스트가 없으면 아무것도 그리지 않음), 값 칸에 맞춰 150px 들여 쓴다. 맨 아래 줄은 왼쪽 "항목 추가", 오른쪽 "체크리스트 삭제"(항목이 있으면 확인 창).
- `+ 체크리스트`로 막 만들어지면 빈 항목 하나를 넣고 바로 고치기를 시작한다 (없던 체크리스트가 생긴 것을 알아채서 `addCheckItem`).
- `useReorder`에 `follow` 옵션을 더해 포인터 이동량(`dragOffset`)을 돌려준다. 체크리스트는 이것으로 잡은 항목 복사본(`task-check__item--lift`, -1.2도 기울임)을 원래 자리 위에 띄워 옮기고, 원래 자리는 점선 빈칸(`--gap`), 놓일 자리는 왼쪽 점이 달린 보라 선. 카테고리(`TaskListPanel`)는 옵션 없이 불러 그대로다.
- 쓰는 곳이 없어진 `task-detail__sec-head`·`task-detail__txt-btn` CSS를 `TaskDetailModal.css`에서 지웠다.
- 결정: D20·D24 변경
- 계획과 달라진 점: 고칠 파일 목록에 없던 `TaskDetailModal.css`에서 안 쓰는 클래스를 지웠다 (자동 진행 중 판단).
- 확인: `npm run build` 성공 (tsc 포함). 화면은 띄워 보지 않음.
- 사용자 확인: 대기 (최종 테스트)
- 테스트 메모: 항목이 0개인 체크리스트(모두 지운 경우)는 속성 줄에 `0/0`과 빈 막대로 남음 → "체크리스트 삭제"로만 없어짐. 끄는 중 Esc를 누르면 원래 자리로 돌아가야 함.
