# L14 · 2026-11-02 · 테스트 r1: 사용자 테스트 결과

- 요구사항: 전체 (R1–R41)
- 한 일: 사용자가 r1 체크리스트 12개를 수행했다. 12개 모두 통과, 기능 동작은 정상이고 디자인·사용성 수정 요청이 메모로 남았다(1·4·5·9·10·12번).
- 확인: 사용자 판정 통과 12 · 실패 0. 2번의 "미분류 줄에 … 메뉴 없음"은 7번 이후 확인으로 미룸(결과 메모 없음).
- 사용자 확인: 완료 (r1 체크리스트)
- 남은 문제: 수정 요청 15건 → 명세 수정(/spec)부터 진행
  - 1번: 화면 제목 "Plan"으로 / 위쪽 기간 표시·대시 모양 다듬기 / 달력 머리 요일·날짜 크기·굵기 맞추고 한글 요일 바꾸기 (폰트는 전역 변경 때로 보류)
  - 4번: 완료 표시(초록 원 안 체크가 치우쳐 보임)를 보기 좋은 모양으로 / 완료 항목 취소선 빼고 흐리게만
  - 5번: 팝업 머리 "태스크" → "Task" / "메모" 칸을 작업 내용 정리용 마크다운 본문으로 바꾸고 이름 변경, 지원관리 카드 팝업처럼 아래쪽에 / 체크리스트 버튼을 속성 줄로 / 팝업 전체를 지원관리 카드 팝업 디자인과 같게 / 목록 줄 오른쪽 휴지통 버튼으로 바로 삭제
  - 9번: 알약 풍선의 "누르면 지원관리 카드가 열려요" 문구 삭제
  - 10번: 체크리스트 항목 끌 때 잡은 항목이 마우스를 따라오게 / 목록에서 태스크를 다른 카테고리 묶음에 끌어 놓으면 카테고리 변경
  - 12번: 창을 줄여도 위쪽 기간 표시 모양·크기 유지(최소 창 크기 등) / 왼쪽 목록과 오른쪽 달력이 같은 비율로 줄어들게
