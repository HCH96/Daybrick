# L23 · 2026-11-02 · 구현 수정1 6단계: 목록 안 카테고리 옮기기

- 요구사항: R45 (영향: R13, R22, R27)
- 한 일: `DropTarget`에 `group`(미분류는 `categoryId: null`)을 넣고, 카테고리·미분류 묶음 전체에 `data-drop-group`을 달았다. `PlanDragProvider`는 `list-task` 끌기일 때만 묶음을 찾고, 놓으면 `updateTask(id, { categoryId })`. 막대 옮기기는 예전처럼 목록 전체 = 날짜 지우기(D31).
- 지금 든 묶음 위에서는 놓을 곳이 없음(테두리·알약 없음, 놓아도 변화 없음)으로 본다.
- 모습: 놓을 묶음 전체 보라 테두리 + 머리 오른쪽 "여기로 옮기기" 알약(도구 버튼 대신). 끄는 줄 원래 자리는 흐린 점선(휴지통 숨김). 끄는 모습은 기존 `DragGhost`(기울어진 줄) 그대로라 고치지 않았다.
- 결정: D35 추가
- 계획과 달라진 점: 미분류 묶음이 `list/TaskListPanel.tsx` 안 `UncategorizedGroup`에 있고, 원래 자리 점선은 줄 자체에 붙여야 해서 고칠 파일 목록에 없던 `TaskListPanel.tsx`·`TaskRow.tsx`를 고쳤다. `DragGhost.tsx`는 고칠 것이 없어 그대로 두었다. 원래 자리 점선은 달력으로 끌 때도 보인다 (자동 진행 중 판단).
- 확인: `npm run build` 성공 (tsc 포함). 화면은 띄워 보지 않음.
- 사용자 확인: 대기 (최종 테스트)
- 테스트 메모: 줄을 자기 묶음 위로 끌면 테두리·알약이 없어야 함. 목록 줄을 달력으로 끌 때도 원래 줄이 점선으로 남음(R22 모습 변화).
