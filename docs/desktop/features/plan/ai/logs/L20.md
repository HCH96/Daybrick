# L20 · 2026-11-02 · 구현 수정1 3단계: 상세 팝업 틀·Notes·최대화

- 요구사항: R36, R42, R43 (영향: R35, R39, R41)
- 한 일: `TaskDetailModal`을 지원관리 팝업 틀로 바꿨다. 크기는 `Modal` 기본 760×760, 머리는 왼쪽 최대화 버튼 + 세로 구분선 + `Task`, 오른쪽 `SaveStateLabel`("자동 저장됨") → 삭제 → 닫기이고 아래쪽 저장 표시를 없앴다. 최대화는 `maximized` 상태로 `Modal maximized`를 켜고 내용 폭을 820px까지 넓힌다(`task-detail--max`). 내용은 스크롤 영역 안에 제목(26px) → 속성 줄 → 체크리스트(4단계에서 옮김) → `Notes` 구분선 → `MarkdownBody` 순서이며, 빈 Notes 안내는 CSS로 플랜 글로 바꿨다.
- 속성 줄은 `PropRow`(이름 150px + 값, 마우스를 올린 줄만 옅게)로 바꾸고, 카테고리는 카테고리 색 옅은 칩, 상태는 작은 표시 + 글자, 기간은 `11월 2일 (월) → 11월 4일 (수)` + 회색 일수로 바꿨다. "날짜 없음으로"·"연결 끊기"는 줄에 마우스를 올렸을 때만 보인다(키보드 초점 때도 보임). 지원 카드 줄은 상자 없이 밑줄 제목·회사·상태 배지.
- 결정: D20 변경 (속성 줄 클래스 이름)
- 계획과 달라진 점: 삭제 확인 글의 "메모"를 D26에 맞춰 "Notes"로 바꿨다. `format.ts`는 기존 `formatChipDay`·`formatDayCount`로 충분해 고치지 않았다 (자동 진행 중 판단).
