# L12 · 2026-11-02 · 구현 9단계: 지원 카드 연결

- 요구사항: R39 (영향: R14)
- 한 일: reducer에 `link-application`(id 또는 null)·`clear-missing-links`(남은 카드 id 목록에 없는 연결을 null로, 끊을 것이 없으면 그대로)를 더하고 store에 `linkApplication`을 더했다. `features/plan/useLinkCleanup.ts`는 `PlanProvider` 안에서 지원·플랜 상태가 둘 다 ready일 때만 없어진 카드 연결을 끊는다(읽는 중·실패면 아무것도 안 함, D14). 팝업 속성 줄 기간 아래에 `detail/LinkedCardRow`(연결 없으면 `+ 지원 카드 연결`, 있으면 밑줄 제목·회사·상태 배지·[연결 끊기], 제목을 누르면 `PlanPage`의 `openApplicationId`로 지원 상세 팝업)를, `detail/CardPickDialog`(찾기칸, 진행 중 먼저 가까운 일정 순, 종료는 아래 흐리게, ↑↓·Enter, 누르면 연결 후 닫기, 카드 없음 안내)를 더했다. 목록 줄 아래에 연결 회사(회사가 없으면 카드 제목)를 진행도 뒤에 보인다.
- 결정: D25 추가
- 계획과 달라진 점: 카드 목록·회사·가장 가까운 일정 글자를 만드는 순수 함수는 새 `features/plan/applicationLinks.ts`에 두고, 회사 이름은 `applicationEvents.ts`의 `companyName`을 export해 같이 쓴다. 연결 아이콘·찾기 아이콘은 `PlanIcons.tsx`에 `LinkIcon`·`SearchIcon`으로 더했다. 정리 동작은 store 함수로 열지 않고 `useLinkCleanup(state, dispatch)`가 직접 보낸다. 속성 줄 카드 모양 CSS(`task-card-link`)도 `CardPickDialog.css`에 두었다 (모두 자동 진행 중 판단, D25).
- 확인: `npm run build` 성공 (tsc 포함). 화면은 띄워 보지 않음.
- 사용자 확인: 대기 (최종 테스트)
- 테스트 메모: 연결된 카드가 있는데 지원 데이터를 읽는 중·실패면 속성 줄에 안내 글자와 [연결 끊기]만 보이고 목록 줄 회사는 숨는다. 고르기 창 둘째 줄은 진행 중 카드만 "회사 · 가장 가까운 일정"이고 종료 카드는 회사만 보인다. 회사 속성이 빈 카드는 목록 줄에 카드 제목이 보인다.
