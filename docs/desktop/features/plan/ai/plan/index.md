## 결정 (계획 중 정함, D29–D32 / D20–D24 변경)
- 주 번호는 ISO 주(월요일 시작)로 센다. `Week 45` = 2026-11-02 주 (D29).
- 배치는 `grid-template-columns: minmax(200px, 2fr) 5fr` (D30).
- 막대를 목록에 놓으면 날짜만 지우고(R27) 카테고리는 바꾸지 않는다. 카테고리 옮기기는 목록 줄 끌기만 (D31).
- 메모 저장 칸 이름은 `memo` 그대로 둔다. 화면 이름만 `Notes`. 저장 파일 옮기기 없음 (D32).
- 주 이동·스위치는 페이지 제목 줄로(D21·D23 변경), 팝업 저장 표시는 머리로(D20 변경), 놓을 곳에 카테고리 묶음 추가(D22 변경), 체크리스트는 속성 줄(D24 변경).

### 작은 규칙
- 취소선(`line-through`)은 플랜 화면에서 모두 뺀다 (목록·막대·체크 항목). 완료는 흐리게만.
- 좁은 창 대응은 CSS(컨테이너 폭·미디어 쿼리)로만 하고 JS로 창 폭을 재지 않는다.
- `useReorder`의 "마우스를 따라옴"은 옵션으로 두어 카테고리 순서 바꾸기(R8) 모양은 바꾸지 않는다.
- 같은 묶음에 놓으면 아무것도 바꾸지 않는다 (`updatedAt`도 그대로).
