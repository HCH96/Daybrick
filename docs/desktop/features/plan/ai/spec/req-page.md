# 플랜 요구사항: 페이지·공유 (R1–R5)

### 페이지·공유
- R1. 사이드바의 Calendar 메뉴를 플랜 페이지로 바꾼다. 사이드바 이름과 화면 제목은 모두 `Plan`이다. (L15에서 변경)
- R2. 화면은 왼쪽 태스크 목록과 오른쪽 주간 달력 두 영역으로 나눈다.
- R3. 처음 열면 오늘이 들어 있는 주(월~일)를 보여준다.
- R4. `‹ 이전 주` `이번 주` `다음 주 ›` 버튼으로 주를 옮기고, 보고 있는 기간을 위에 표시한다. 기간 표시는 창 크기와 관계없이 한 줄로, 같은 모양과 크기를 유지한다. 표시 형식은 목업에서 정한다. (L15에서 변경)
- R5. 태스크와 카테고리는 앱 전체가 함께 쓰는 저장소 하나에 두고, 어느 화면에서 바꾸든 다른 화면에 바로 반영된다.

## 화면 구성
```
┌ Plan ─────────────────────────────────────────────────────────────┐
│ [+ 빠른 입력: 제목 ___ 카테고리▾]        ‹ 이전 주  이번 주  다음 주 › │
│                                  (기간 표시: 형식은 목업에서) [지원 일정 ●]│
├──────────────────┬────────────────────────────────────────────────┤
│ ● C++ 공부 (3) +  │  월 2  화 3  수 4  목 5  금 6  토 7  일 8         │
│   ○ 템플릿 정리    │ 🏁넥슨 마감       💻카카오 코테 14:00              │
│     날짜 없음      │ ██ 템플릿 정리 ██████                            │
│   ◐ STL 복습      │       ██ 자소서(넥슨) ████████████               │
│     11/3–11/5     │                          ██ CS 네트워크 █        │
│   ▸ 완료 2개       │                                                │
│ ● TrialGround (2)+│                                                │
│ ● 취업 준비 (1) +  │   (빈 곳 더블클릭 → 그날 새 태스크)               │
│ ○ 미분류 (1)       │                                                │
│ [+ 카테고리 추가]  │                                                │
└──────────────────┴────────────────────────────────────────────────┘
```
- 왼쪽: 카테고리별 태스크 목록 (R11–R20), 아래에 카테고리 추가 (R7)
- 오른쪽: 위쪽에 지원 일정 (R31), 아래에 태스크 막대 (R23)
- 요일 머리는 영어 표기 (R21), 창을 줄일 때 두 영역은 같은 비율로 줄어든다 ([req-window.md](req-window.md) R46)
