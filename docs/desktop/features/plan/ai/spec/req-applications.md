# 플랜 요구사항: 지원관리 일정 표시 (R31–R34)

### 지원관리 일정 표시
- R31. 지원관리 전형 일정(지원 마감·과제 마감·코딩테스트·면접)을 날짜 칸 위쪽에 태스크와 다른 모양(종류 아이콘, 회사 또는 카드 제목, 있으면 시간)으로 보여준다. 지원 마감은 지원관리와 같은 규칙으로 "지원 준비" 카드일 때만 보인다.
- R32. 지원 일정은 끌어서 옮길 수 없고, 누르면 지원관리 상세 팝업이 열린다.
- R33. `지원 일정` 스위치로 보이기·숨기기를 고르고, 이 선택은 다시 열어도 유지된다.
- R34. 지원관리에서 일정을 바꾸면 플랜 달력에도 바로 반영된다.

일정 종류와 지원 마감 규칙은 지원 관리 명세서(R23–R27, R39)를 따른다.
