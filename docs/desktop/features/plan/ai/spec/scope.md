## 나중에 고려할 것
- 투데이: 오늘이 기간 안에 있는 태스크를 상태 3칸 칸반으로 보여준다. "중단"을 어떤 상태로 둘지(진행 중 유지 또는 시작 전으로 되돌림)는 그때 정한다.
- 타이머: 태스크에 붙는 시간 기록(태스크 id, 날짜, 시작·끝 또는 초)을 따로 쌓는다. 날짜별 합계는 이 기록에서 계산하고, 완료하면 태스크 상태를 완료로 바꾼다.
- 프로젝트 페이지: 주차는 월요일 기준 주로 계산하고, 카테고리 단위로 본다. 개발일지는 카테고리·날짜에 묶인 별도 기록으로 둔다.
- 서버 동기화: 태스크 데이터를 통째로 옮기기 쉽게 id를 무작위 고유값으로 만든다.
