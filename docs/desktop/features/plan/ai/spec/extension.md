# 플랜: 확장 구조
다른 기능(투데이·타이머·프로젝트·홈)이 태스크를 쓸 때 읽는다.

- 태스크·카테고리는 화면과 떨어진 공용 저장소 하나에 둔다. 플랜·투데이·타이머·프로젝트 화면은 모두 이 저장소를 읽고 쓰며, 한쪽에서 바꾸면 다른 쪽에 바로 반영된다 (R5).
- 다른 화면은 공용 함수("이 날짜에 걸린 태스크", "카테고리별 태스크", "상태 바꾸기", "기간 바꾸기")를 쓰고, 저장 파일을 직접 다루지 않는다.
- 나중 기능의 데이터(시간 기록, 개발일지)는 태스크 안에 넣지 않고, 태스크 id나 카테고리 id로 연결되는 별도 목록으로 둔다.
- 주 계산(월요일 시작)은 공용 함수 하나로 두어 플랜과 프로젝트 페이지의 "주차"가 같은 기준을 쓴다.
- 구체적인 파일 위치와 함수 이름은 구현 계획에서 정한다.
