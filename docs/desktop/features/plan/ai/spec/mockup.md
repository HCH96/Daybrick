| 상태 표시 | 시작 전 회색 빈 원, 진행 중 주황 반쪽 원(`#F0B860`), 완료 C1: 초록 채운 원(`#66CF95`) + 정가운데 체크(그림으로 그림). 완료 줄은 흐리게만, 취소선 없음 (L16에서 변경) |
| 카테고리 표시 | 색 점 + 이름 + 안 끝난 개수. `…`·`+`는 마우스를 올렸을 때만. 미분류는 테두리만 있는 점, `…` 없음 |
| 태스크 줄 | 제목 아래 작은 회색 글자로 기간(또는 "날짜 없음")·체크리스트 진행도·연결 회사. 마우스를 올리면 오른쪽에 휴지통, 그 위에서는 빨갛게 (R44, L16) |
| 요일 머리·오늘 칸 (r2) | B2: `Mon 2` 한 줄, 요일·숫자 13px 같은 굵기(숫자만 밝은 색). 오늘은 둘을 옅은 보라 알약으로 감싸고 칸 전체를 아주 옅은 보라로. 토요일 파랑, 일요일 빨강 글자 (L16에서 변경) |

| 주 경계 | 잘린 쪽 모서리를 각지게 하고 ‹ / › 표시 |
| 지원 일정 | 날짜 칸 위쪽 알약 모양 (아이콘 + 회사 + 시간). 지원 마감 빨강 깃발, 과제 주황 문서, 코딩테스트 보라 코드, 면접 청록 사람. 막대 영역과 점선으로 구분 |
| 끌기 표시 | 놓일 칸 보라 테두리 + 옅은 보라 바탕, 아래에 놓일 날짜 알약. 옮기는 막대는 원래 자리에 흐린 점선 막대 |
| 막대 끝 손잡이 | 마우스를 올렸을 때만 양 끝에 세로 손잡이 |

### 목업에 넣은 추가 제안 (목업과 함께 승인)
- 지원 일정에 마우스를 올리면 카드 제목·종류·시간 풍선 ("누르면 지원관리 카드가 열려요" 문구는 뺀다, L15에서 변경)
- 막대가 하나도 없는 주는 달력 아래쪽에 옅은 안내 한 줄
- 지원 카드 고르기 창: 찾기칸, 진행 중 카드 먼저(가까운 일정 순), 종료 카드는 아래에 흐리게
- 상세 팝업 기간 줄에 일수 표시와 "날짜 없음으로" 버튼 (r2: 기간 줄에 마우스를 올렸을 때만)
- r2: 기간·주 이동·스위치를 페이지 제목 줄로 옮김 (창 크기 문제 해결용 제안, 승인)
- r2: 체크리스트 체크한 항목도 취소선 없이 흐리게 (목록 완료 줄과 맞춤)
- r2: 지원 카드 값에 마우스를 올리면 "연결 끊기"
