## 준비
1. 실행 중인 Daybrick 창이 있으면 닫는다. 창 설정이 바뀌어서 새로 켜야 한다.
2. 터미널에서 `apps/desktop` 폴더로 이동한다.
3. `npm.cmd run tauri dev`를 실행한다. PowerShell에서는 `npm` 대신 `npm.cmd`를 써야 한다.
4. Daybrick 창이 뜨면 테스트를 시작한다.

> 이번 범위에서 제외된 것(실제 데이터, 로그인, 라이트/다크 전환, 모바일 화면, 빠른 추가의 실제 입력)은 테스트하지 않는다.

### 2. 창 버튼 (최소화, 최대화, 닫기)
- 근거 요구사항: 제목 표시줄 T1

  1. ─를 누른 뒤 작업 표시줄에서 Daybrick을 눌러 다시 연다.

### 9. 뒤로·앞으로 (버튼, 단축키, 마우스 옆 버튼)
- 근거 요구사항: 제목 표시줄 T3, 결정 ② 단축키
- 수행 방법:
  1. 사이드바에서 Calendar → Timer → Applications 순서로 누른다.
  2. 제목 표시줄 ←를 두 번 누른다.
  3. →를 한 번 누른다.
  4. `Alt + ←`, `Alt + →`를 차례로 누른다.
  5. 마우스에 옆 버튼이 있다면 뒤로 버튼, 앞으로 버튼을 차례로 누른다.
- 예상 결과:
  - 2는 지원 현황 → 타이머 → 캘린더 순으로 돌아간다.
  - 3은 타이머로 간다.
  - 4는 캘린더로 갔다가 다시 타이머로 온다.
  - 5도 4와 같다.
  - 처음 화면(홈)까지 돌아가면 ←가 흐려지고, 마지막 화면에서는 →가 흐려진다.
- 확인 위치: 본문 왼쪽 위 제목, 사이드바 강조, 제목 표시줄 ← →
