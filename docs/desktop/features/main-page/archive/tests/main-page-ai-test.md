## 테스트 환경
- Windows 11, Node v24.20.0
- 화면 테스트: `apps/desktop`에서 `npm run build`로 빌드하고 `npx vite preview --port 4173`으로 띄운 뒤, Claude 앱 안의 브라우저 창으로 확인했다.
  - 실제 Tauri 창(WebView2)이 아니라 같은 빌드 결과를 브라우저로 본 것이다.
  - 창 버튼 동작, 끌기, 가장자리 크기 조절, 실제 마우스 옆 버튼은 사용자 테스트(U2~U5, U9)로 넘겼다.
- 조작 방법:
  - 브라우저 창 크기 조절
  - 화면 안 JavaScript로 클릭, 위치·크기·스타일 읽기, 마우스 옆 버튼 이벤트 보내기
  - 실제 키 입력(Tab, Ctrl+B, Alt+←/→), 실제 클릭과 입력
- 함수 테스트: 저장소 밖 임시 스크립트로 `src/utils/date.ts`, `src/utils/korean.ts`를 Node에서 직접 실행했다.
- 범위 밖이라 테스트하지 않음:
  - 실제 데이터 저장/조회, Supabase·로그인, 라이트/다크 전환, 모바일 대응
  - 자정이 지났을 때 날짜 자동 갱신
  - 빠른 추가의 실제 입력 처리
