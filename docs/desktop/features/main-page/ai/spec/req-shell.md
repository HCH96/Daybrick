# 메인 페이지 요구사항: 앱 틀 (R1–R4)

### 앱 틀
- R1. 전체 레이아웃은 제목 표시줄 + 사이드바 + 본문 영역이다.
- R2. 기본 창 크기 1200x800, 최소 960x640, 화면 가운데에 띄운다. (D3)
- R3. 창 맨 위 제목 표시줄(높이 40px)은 앱이 직접 그린다. 왼쪽에 사이드바·뒤로·앞으로 버튼, 가운데 빈 곳은 끌어서 창 이동·더블클릭 최대화, 오른쪽에 최소화·최대화·닫기. (L19에서 추가)
- R4. 본문이 창보다 길면 본문만 스크롤된다. 스크롤 바는 보이지 않게 한다(휠·터치패드 스크롤은 됨). 제목 표시줄과 사이드바는 스크롤되지 않는다. (L17에서 추가)
