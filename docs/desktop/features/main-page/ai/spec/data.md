# 메인 페이지: 다룰 데이터

- 사이드바 접힘 상태: localStorage `daybrick.sidebarCollapsed`에 저장. 저장소를 못 쓰면 펼친 상태로 시작 (R8).
- 방문 기록: 메모리에만 둔다(최대 50개). 앱을 다시 켜면 비고 홈부터 시작 (R9).

## 홈이 읽는 데이터 (L34)
홈은 새 데이터를 저장하지 않는다. 각 기능의 저장소를 읽고, 빠른 추가와 타이머 조작만 그 기능의 공용 함수로 쓴다 (R27).

| 데이터 | 쓰는 곳 | 저장 위치 |
|---|---|---|
| 태스크·카테고리·프로젝트 | 빠른 추가(쓰기), 오늘 완료, 다가오는 7일, 지금 하는 것, 프로젝트 진행 | plan.json (플랜) |
| 시간 기록·실행 중 타이머·하루 목표 | 오늘 집중, 지금 하는 것(조작), 이번 주 집중, 누적 시간 | today.json (투데이) |
| 개인 일정 | 다음 일정, 다가오는 7일 | 캘린더 파일 |
| 지원 카드·전형 일정 | 가까운 마감, 다가오는 7일, 지원 현황 | 지원 관리 파일 |
| 추천 공고·마지막 수집 시각 | 새 추천 공고 | Supabase 서버 (구직 관리) |
| 추천 탭을 마지막으로 떠난 시각 | 새 추천 공고 (읽기만, R47) | job-search.json `recommendOpenedAt` |
