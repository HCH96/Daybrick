지금 하는 것: 타이머 색 비교

정적 화면이며 값은 예시입니다. 카드 모양은 1안, 바탕은 색 A안입니다. 세 안 모두 색을 시계의 초, 오늘 집중 막대, 카드 테두리(또는 위 띠) 세 곳에만 씁니다. 실제 크기의 85%입니다.

R35

T3. 보라 · 이번 주 집중과 같은 색
