# 데이터 동기화 요구사항: 설정 화면 (R29–R33)

### 설정 화면
- R29. 설정 화면에 "데이터 동기화" 구역을 두고 켜기/끄기, 종류별 상태(맞음·대기·선택 필요·오류·건너뜀), 마지막으로 올린 시각을 보여준다. 상태는 이 구역에만 보여주고 제목 표시줄에는 따로 표시하지 않는다.
- R30. "지금 올리기" 버튼으로 대기 중인 종류를 바로 올린다.
- R31. 종류마다 "서버에서 받아오기"를 할 수 있다. 확인창을 거치고, 덮기 전에 R21대로 백업한다.
- R32. 연결 안 됨·로그인 안 됨·서버 구조 번호 낮음일 때는 이유와 할 일(연결·로그인·서버 업데이트)을 안내한다.
- R33. 백업 파일이 있으면 백업 폴더를 여는 링크를 보여준다.

## 화면 구성
```
설정 › 데이터 동기화                         [켜짐 ●]
 플랜        맞음       11/8 19:08 올림
 캘린더      대기       로그인 필요
 지원 관리   선택 필요  [고르기]
 투데이      맞음       11/8 18:40 올림
 [지금 올리기]   종류별 ⋯ › 서버에서 받아오기
 백업 폴더 열기
```
- "고르기"는 R19 선택창(양쪽 수정 시각·기기 이름, 두 버튼)을 연다.
