# 데이터 동기화 요구사항: 처음 켜기·서버와 다를 때 (R17–R23)

### 처음 켜기·서버와 다를 때
- R17. 동기화는 기본으로 꺼져 있다. 설정에서 켜면 종류마다 서버 행과 로컬을 비교한다.
- R18. 비교 결과에 따라 아래 표대로 처리한다.

  | 서버 | 로컬 | 처리 |
  |---|---|---|
  | 없음 | 있음/빔 | 로컬을 올림 |
  | 있음 | 빔 | "서버에서 받아오기" 물음 (재설치·새 PC) |
  | 같음 | 같음 | 맞춘 상태로 기록 |
  | 다름 | 다름 | R19 |

- R19. 서버와 로컬 둘 다 내용이 있고 다르면 종류마다 "PC 내용 남기기(서버를 덮음, 추천)"와 "서버 내용 받기(PC를 덮음)" 중 고르게 한다. 양쪽의 마지막 수정 시각·기기 이름을 함께 보여준다.
- R20. 올리는 중에 R14 상황이 되면 R19와 같은 선택창을 쓴다.
- R21. 덮이는 쪽은 덮기 전에 앱 데이터 폴더에 백업 파일로 남긴다. PC를 덮을 때는 로컬 파일을, 서버를 덮을 때는 서버 내용을 백업한다.
- R22. 서버 내용으로 로컬을 덮는 것은 사용자가 고를 때만 한다(자동 없음). 받은 데이터는 버전·모양 검사를 통과해야 쓰고, 앱보다 새 버전이면 받지 않는다.
- R23. 서버 내용을 받아 온 뒤에는 그 기능의 화면 데이터를 다시 읽는다(앱 재시작 없이).
