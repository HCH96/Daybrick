# 데이터 동기화 범위

## 이번 범위에서 제외
- 웹·폰 화면, 웹·폰에서 쓰기
- QR로 연결 정보(Supabase URL, anon key) 넘기기
- 지원 관리 본문 이미지 올리기 (D2)
- PC 여러 대 동시 사용 (D4)
- 행 단위 테이블(B안) (D1)
- 서버 데이터를 지우는 버튼
- 로그인 풀림(server-setup L22) 원인 수정

## 나중에 고려할 것
- 이미지를 Supabase Storage로 올리기 (본문 경로 `images/파일명`은 그대로)
- 실시간 구독 (realtime publication)
- 서버 쪽 옛 버전 보관, 오래된 백업 정리
- 웹·폰 쓰기가 필요해지면 B안으로 옮기기

## 계획 단계에서 확인할 것
- 리비전 비교를 서버 함수(RPC)로 할지 조건부 update로 할지
- 자동 올리기 대기 시간
- 각 기능 store·useAutoSave의 저장 흐름에 올리기를 끼우는 방법
