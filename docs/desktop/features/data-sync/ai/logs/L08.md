- 계획과 달라진 점: (자동 진행 중 판단) 선택창은 `Modal` 대신 설정 칸의 다른 작은 창과 같은 `SettingsDialog` 틀을 썼다. 로컬 원문 백업을 위해 `kinds.ts`에 `readRaw()`를 더했고, 시각 글자 함수는 새 `pages/settings/syncTime.ts`로 옮겼다. plan.json을 옮기고 켜는 경우는 기능 자동 저장이 첫 읽기를 저장하지 않아 "선택 필요"가 되지 않으므로, sync.json을 읽은 뒤 켜져 있으면 종류마다 로컬이 비었는지 보는 `checkEmptyLocal`을 더했다(서버 호출 없음).
- 확인: `npm run build` 성공 (타입 검사 포함). 실제 서버로 고르기·받아오기는 돌려 보지 않음.
