서버 연결 (server-setup) 목업

내 Supabase 서버와 Anthropic 키를 연결하는 화면들입니다. 디자인 확인용 정적 화면이고 버튼은 동작하지 않습니다. 색과 앱 창 틀은 지원 관리 목업과 같습니다.

1. 처음 켤 때
1. 첫 실행 안내
2. 서버 연결 마법사 (① 준비 → ② 주소·키 → ③ 자동 세팅 또는 로그인 → ④ 완료)
2-1. ① 준비 2-2. ② 주소·키 2-3. ③ 자동 세팅 입력 2-4. ③ 자동 세팅 실행·실패 2-5. 로그인 (이미 세팅된 서버) 2-6. ④ 완료
3. 설정
3. 설정 → 서버 연결 (연결됨·연결 안 함·로그인 필요) 3-1. 키 교체·자동 세팅 다시 실행 3-2. 연결 해제 확인
4. 접속 상태 안내
4. 안내 띠 4-1. 재개 안내 팝업
5. 서버 구조 갱신
5. 서버 업데이트 · 앱 업데이트 안내
색 규칙
  • 보라: 지금 단계, 주요 버튼, 진행 중
  • 초록: 연결됨, 완료
  • 주황: 사용자가 할 일 (로그인, 업데이트, 재개)
  • 빨강: 오류, 접속 불가, 연결 해제
마법사 틀
  • 위: 진행 표시 4단계
  • 왼쪽: 입력, 오른쪽 460px: 단계별 가이드
  • 아래: [취소] … [이전] [다음]
비밀값
  • PAT·Anthropic 키·Google 비밀번호 칸은 항상 ●로 가림
  • Anthropic 키는 설정에서도 "등록됨"과 날짜만
