# 서버 연결 요구사항: 첫 실행·설치 가이드 (R1–R10, R54)

### 첫 실행
- R1. 서버 연결 정보가 없고 "나중에 하기"를 누른 적이 없으면, 앱을 켤 때 전체 화면 첫 실행 안내가 뜬다.
- R2. 첫 실행 안내에는 [서버 연결 시작]과 [나중에 하기]가 있다. [나중에 하기]를 누르면 다시 뜨지 않고 로컬 기능을 그대로 쓴다.
- R3. 서버 연결은 단계 순서로 진행한다: ① 준비 ② Supabase 주소·키 ③ 자동 세팅 ④ 완료. 각 단계에서 [이전]으로 돌아갈 수 있고 [취소]하면 입력값을 버린다.
- R4. ② 단계에서 [확인]을 누르면 서버에 접속해 보고, 주소 형식 오류 / 키 오류 / 접속 불가 / 일시정지를 구분해 알려준다.
- R5. 키 칸은 예전 anon 키(`eyJ…`)와 publishable 키(`sb_publishable_…`)를 모두 받는다.
- R6. 접속에 성공하면 서버 구조 번호를 읽고 다음 단계를 정한다.

| 서버 상태 | 다음 화면 |
|---|---|
| Daybrick 구조 없음 (빈 서버) | ③ 자동 세팅 |
| 앱과 같은 번호 | 로그인 (다른 PC, 재설치) |
| 앱보다 낮은 번호 | 로그인 후 서버 업데이트 (R23) |
| 앱보다 높은 번호 | 앱 업데이트 안내 (R24) |

### 설치 가이드
- R7. 각 단계 화면 오른쪽에 그 단계에서 할 일을 순서대로 적은 가이드를 둔다.
- R8. 입력칸마다 "어디서 찾나요?" 도움말을 둔다. 누르면 Supabase나 Anthropic 화면 어디에서 그 값을 찾는지 짧게 보여준다.
- R9. 가이드의 외부 링크(Supabase 가입·대시보드, PAT 발급, Anthropic 콘솔)는 기본 브라우저로 연다.
- R10. 준비 단계 가이드에 무료 플랜 주의점(7일 동안 쓰지 않으면 일시정지, 재개 방법)과 비용 안내(Anthropic API는 쓴 만큼 요금이 나감)를 적는다.
- R54. ③ 단계에서 Google OAuth 클라이언트에 넣을 리디렉션 주소를 앱이 Supabase 주소로 만들어 [복사] 버튼과 함께 보여준다.

| 단계 | 가이드 내용 |
|---|---|
| ① 준비 | Supabase 가입, 새 프로젝트 만들기(지역·DB 비밀번호), Anthropic 콘솔 가입·결제 수단·API 키 발급, Google Cloud 프로젝트 만들기, 무료 플랜·비용 주의 |
| ② 주소·키 | Project Settings → API에서 주소(Project URL)와 anon/publishable 키 복사 |
| ③ 자동 세팅 | 계정 설정에서 PAT 발급(이름, 만료 기간 짧게 권장), Anthropic 키 붙여넣기, Google Cloud에서 OAuth 동의 화면(프로덕션으로 게시)과 OAuth 클라이언트 만들기(리디렉션 주소 R54 붙여넣기) 후 ID·비밀값 복사 |
| ④ 완료 | 다음에 할 일(설정 화면 위치, 일시정지 시 재개 방법) |

## 화면 구성
```
┌──────────────────────────────────────────────────────┐
│  ① 준비 ─ ② 주소·키 ─ ③ 자동 세팅 ─ ④ 완료   (진행 표시)│
├───────────────────────────────┬──────────────────────┤
│ Supabase 주소                  │ 가이드               │
│ [https://xxxx.supabase.co   ]  │ 1. 대시보드 열기 ↗   │
│   어디서 찾나요?               │ 2. Project Settings  │
│ anon / publishable 키          │    → API             │
│ [                           ]  │ 3. Project URL 복사  │
│   어디서 찾나요?               │ ...                  │
│ (오류·확인 결과 줄)            │                      │
├───────────────────────────────┴──────────────────────┤
│ [취소]                              [이전]  [확인 →]  │
└──────────────────────────────────────────────────────┘
```
첫 실행 안내(R1)는 같은 틀에서 가운데에 앱 소개 한 줄과 [서버 연결 시작] [나중에 하기]만 둔다.
