# 서버 연결 요구사항: 설정 화면 (R45–R50)

### 설정 화면
- R45. 사이드바 맨 아래에 Settings 메뉴를 추가한다. 설정 화면은 칸(섹션) 단위로 나누고, 이번에는 "서버 연결" 칸만 만든다. 이후 기능은 같은 화면에 칸을 추가한다.
- R46. 연결 안 함이면 서버 연결 칸에 짧은 설명과 [서버 연결 시작]을 보여주고, 누르면 첫 실행 흐름(R3)을 연다.
- R47. 연결돼 있으면 상태(R40), 서버 주소, 로그인 이메일, 서버 구조 번호(서버/앱), 마지막 접속 시각, [지금 다시 확인]을 보여준다.
- R48. Anthropic 키는 값을 보여주지 않고 "등록됨"과 등록일만 보여준다.
- R49. 서버 연결 칸에서 아래 관리 작업을 할 수 있다. (L02에서 변경)

| 작업 | 필요한 것 | 하는 일 |
|---|---|---|
| 로그아웃 | — | 저장된 로그인 정보 삭제 |
| Anthropic 키 교체 | PAT, 새 키 | 새 키 확인(R12) 후 비밀값 교체, 등록일 갱신 |
| 자동 세팅 다시 실행 | PAT (Google 클라이언트는 바꿀 때만) | R15의 1~4단계와 6단계를 다시 실행 (복구용, 데이터 유지) |
| 서버 연결 해제 | 확인 | 저장한 주소·키·로그인 정보를 삭제, 서버 데이터는 그대로 |
| 다른 Supabase로 바꾸기 | 확인 | 연결 해제 후 첫 실행 흐름(R3) |

- R50. 연결 해제와 다른 Supabase로 바꾸기는 확인 팝업을 거친다. 팝업에는 "서버의 데이터는 지워지지 않습니다"를 적는다.

## 화면 구성
```
┌ Settings ─────────────────────────────────────────┐
│ 서버 연결                                          │
│  ● 연결됨          마지막 접속 2026-10-26 09:12    │
│  주소     https://xxxx.supabase.co                 │
│  계정     me@example.com             [로그아웃]    │
│  서버 구조 1 / 앱 1                                │
│  Anthropic 키  등록됨 (2026-10-26)   [교체]        │
│  [지금 다시 확인]  [자동 세팅 다시 실행]           │
│  ───────────────                                   │
│  [다른 Supabase로 바꾸기]  [서버 연결 해제]        │
└────────────────────────────────────────────────────┘
```
