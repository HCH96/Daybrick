알림 목업

제목 표시줄 오른쪽 끝(최소화 버튼 바로 왼쪽)에 종 아이콘을 둔다. 어느 화면에서든 같은 자리.

목차1. 종 아이콘·배지2. 펼친 목록3. 목록 상태

1. 종 아이콘·배지

R1–R5

제목 표시줄 오른쪽 끝만 잘라 1.5배로 키워 보여준다. 다른 버튼과 같은 30px 칸, 같은 회색 아이콘.

안 읽음 0개배지 숨김 (R3)
3
안 읽음 3개오른쪽 위 빨간 원 (R2)
99+
안 읽음 124개100개 이상은 99+ (R3)
3
패널 열림버튼 배경이 밝아짐 (R6)
배지
  • 지름 16px, 숫자가 길어지면 옆으로 늘어나는 알약 모양
  • 제목 표시줄 색 테두리 2px로 아이콘과 떨어져 보이게
  • 색은 알림 전용 진한 빨강(--badge)
숫자
  • 목록에 보이는 50개가 아니라 저장된 안 읽은 알림 전체 (R4)
  • 1–99는 그대로, 100 이상은 99+
서버 없이도
  • 서버 연결이 없어도 아이콘·로컬 알림은 그대로 보인다 (R5)
  • 서버 연결 문제는 알림이 아니라 안내 띠로 (R35)
