# L06 · 2026-10-27 · 구현 3단계: 펼침 패널과 알림 행

- 요구사항: R6–R13, R20, R23, R26
- 한 일: `Popover`에 `placement: "bottom-end"`(오른쪽 끝을 버튼 오른쪽에 맞춤)를 더했다. 기존 두 placement 동작은 그대로다. `NotificationBell`이 열림 상태를 갖고 `NotificationPanel`(Popover 사용, 너비 360px, 최대 높이 `min(70vh, 겹침 층 - 16px)`)을 연다. 열린 동안 종에 `titlebar__button--pressed`를 붙인다. 바깥 누르기·Esc는 Popover의 `useOutsideLayer`·`useEscapeLayer`가 닫고, 종은 anchor라 종 클릭이 열고 닫기를 맡는다.
- 패널: `PanelHead`(모양만, 필터는 `"all"` 고정, [모두 확인]은 안 읽음 0개면 비활성), `NotificationRow`(행 hover 때 버튼 보라 바탕, 확인함은 왼쪽 표시·글만 45%), `PanelEmpty`, `NotificationIcons`(경고·체크·되돌리기·두 겹 체크·빈 상태 종)를 만들었다. 상대 시각은 `utils/relativeTime.ts`의 `formatRelativeTime(iso, now)`, 패널 안 `useMinuteClock`이 1분마다 `now`를 바꾼다. 보낸 기능 이름은 `features/notifications/sourceLabel.ts`.
- 계획과 달라진 점: `Popover.css`는 고치지 않았다. 패널 모양 덮어쓰기는 `NotificationPanel.css`의 `.popover.notification-panel`에 두었다 (자동 진행 중 판단).
- 확인: `npm run build`(타입 검사 포함) 성공. Rust는 고치지 않았다. 앱을 띄워 화면을 보지는 않았다.
- 사용자 확인: 대기 (최종 테스트)
