# 알림 요구사항: 알림 보내기·합치기·보관 (R21–R28)

### 보내기
- R21. 앱 안의 기능은 공용 함수 하나로 알림을 보낸다. 함수가 로컬 저장, 합치기, 배지 갱신을 처리한다.
- R22. 알림에는 보낸 기능, 종류, 중요도, 제목, 내용, 갈 곳(선택), 합치기 키(선택)를 넣는다.
- R23. 중요도는 두 단계다. "정보"는 회색 점, "주의"(실패·끊김·한도 초과 등)는 주황 경고 아이콘으로 표시한다.
- R24. 같은 기능이 같은 합치기 키로 보낸 안 읽은 알림이 이미 있으면, 새로 만들지 않고 그 알림의 제목·내용·시각을 바꿔 맨 위로 올린다. 같은 키의 알림이 모두 확인된 상태면 새로 만든다.
- R25. 갈 곳은 페이지 id(main-page의 페이지 목록)와 그 안의 탭·팝업 이름으로 지정한다. 실제로 탭을 열고 팝업을 띄우는 일은 그 기능이 맡는다.
- R26. 보낸 기능의 이름은 페이지 목록의 이름을 쓰고, 목록에 없는 기능이면 "Daybrick"으로 표시한다.

### 보관
- R27. 확인한 알림은 확인하고 30일이 지나면 자동으로 지운다. 안 읽은 알림은 자동으로 지우지 않는다.
- R28. 알림을 하나씩 지우는 기능은 없다. 확인만 한다.
