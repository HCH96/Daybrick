# 알림: 범위

## 이번 범위에서 제외하는 것
- 푸시 알림, OS 알림, 알림 소리
- 알림 하나씩 지우기, 알림 검색

## 나중에 고려할 것
- 기능별 알림 끄기 설정
- 폰 앱·공유 웹에서 알림 보기
- 일정 알림 (applications scope의 "코딩테스트 하루 전" 같은 알림)

## 계획 단계에서 확인할 것 (지금은 추측)
- 로컬 저장 방식을 지원 관리와 같은 방식으로 쓸 수 있는지
- Supabase 무료 플랜 실시간 사용 한도
- 서버 알림 30일 정리 방법 (pg_cron 예약 실행 또는 앱이 받아 올 때 정리)
- 제목 표시줄 끌기 영역과 아이콘 클릭이 겹치지 않게 하는 방법
