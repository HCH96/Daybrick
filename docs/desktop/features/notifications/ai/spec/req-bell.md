# 알림 요구사항: 아이콘·배지 (R1–R5)

### 아이콘·배지
- R1. 제목 표시줄 오른쪽, 최소화 버튼 바로 왼쪽에 알림(종) 아이콘을 둔다. 어느 화면에서든 보인다.
- R2. 안 읽은 알림이 1개 이상이면 아이콘 오른쪽 위에 빨간 원 배지로 개수를 표시한다.
- R3. 안 읽은 알림이 0개면 배지를 숨기고, 100개 이상이면 `99+`로 표시한다.
- R4. 배지 숫자는 목록에 보이는 50개가 아니라 저장된 안 읽은 알림 전체를 센다.
- R5. 서버 연결이 없어도 아이콘과 로컬 알림은 동작한다.

화면 구성은 [req-panel.md](req-panel.md)에 함께 둔다.
