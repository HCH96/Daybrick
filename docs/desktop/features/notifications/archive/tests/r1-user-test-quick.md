# 알림 (notifications) 빠른 사용자 테스트 r1
- 작성일: 2026-10-27 · 원본: [r1-user-test.md](r1-user-test.md) (34항목)에서 주요 기능만 추린 12항목
- 각 항목 끝 괄호는 원본 번호다. 실패하면 원본의 해당 항목을 보고 자세히 확인한다.
- 빠진 것: 창 끌기 겹침, 상대 시각 세부, 30일 자동 삭제, 이동 불가 세부 경우, SQL 합치기·anon 차단, 끊김 후 재수신, 31일 서버 정리, 오프라인 확인 후 재시작 (AI 테스트에서 코드로는 통과)

## 준비
1. `apps/desktop`에서 `npm run tauri dev`로 켜고, 앱 창에서 F12로 콘솔을 연다.
2. 콘솔에 붙여 넣는다 (앱을 다시 켜면 다시 붙인다).
   ```js
   const N = (o = {}) => daybrickNotify({ source: "applications", kind: "test", importance: "info", title: "테스트 알림", body: "내용", ...o });
   const many = (n) => { for (let i = 1; i <= n; i++) N({ title: `알림 ${i}` }); };
   ```
3. 알림을 0개로 되돌리려면 앱을 끄고 `%APPDATA%\com.daybrick.desktop\notifications.json`을 지운 뒤 다시 켠다 (원래 파일은 미리 백업).
4. 서버 항목(10–12)은 테스트용 Supabase 프로젝트에 연결·로그인된 상태에서, 서버 구조 2로 업데이트한 뒤 한다. SQL 편집기용 본인 user id(`<내 id>`)를 Authentication → Users에서 복사해 둔다.
