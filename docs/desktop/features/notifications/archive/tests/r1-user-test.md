# 알림 (notifications) 사용자 테스트 체크리스트 r1
- 작성일: 2026-10-27 · 근거: 명세 R1–R36, 구현 계획 1–8단계 "확인할 결과", 진행 기록 L04–L11
- AI는 화면을 띄워 보지 않았다. 아래 예상 결과는 명세·목업·진행 기록을 근거로 적은 것이다.
- 제외 범위(푸시·OS 알림·소리, 하나씩 지우기, 검색)는 테스트하지 않는다.

## 준비
1. **개발 모드로 켜기**: `apps/desktop`에서 `npm run tauri dev`. 앱 창 안에서 F12(또는 오른쪽 클릭 → 검사)로 개발자 도구 콘솔을 연다. `daybrickNotify`는 개발 모드에서만 있다.
2. **데이터 파일 위치**: `%APPDATA%\com.daybrick.desktop\notifications.json`. 테스트 전에 원래 파일이 있으면 `notifications.backup.json`으로 복사해 둔다. 파일을 고칠 때는 **앱을 끈 상태에서** 고친다.
3. **콘솔 줄임말** — 콘솔에 한 번 붙여 넣어 둔다 (앱을 다시 켜면 다시 붙인다).
   ```js
   const N = (o = {}) => daybrickNotify({ source: "applications", kind: "test", importance: "info", title: "테스트 알림", body: "내용", ...o });
   const many = (n) => { for (let i = 1; i <= n; i++) N({ title: `알림 ${i}` }); };
   ```
4. **기본 알림 세트 "세트 A"** (여러 항목이 같이 쓴다): 알림이 하나도 없는 상태에서 아래를 차례로 실행한다.
   ```js
   N({ title: "메일 제안 2개", body: "확인할 메일이 있습니다" });                         // A1 정보
   N({ title: "새 추천 공고 5개", body: "조건에 맞는 공고가 새로 올라왔습니다" });          // A2 정보
   N({ importance: "warning", title: "수집 실패: 게임잡", body: "페이지 구조가 바뀌었습니다. 아주 긴 내용이 한 줄을 넘으면 끝이 말줄임표로 잘려야 합니다. 아주 긴 내용 아주 긴 내용" }); // A3 주의
   ```
   알림을 0개로 되돌리려면: 앱을 끄고 `notifications.json`을 지운 뒤 다시 켠다 (서버 알림은 남는다).
5. **서버 준비 (U24부터)**: server-setup에서 쓰던 테스트용 Supabase 프로젝트에 연결·로그인된 상태. 대시보드 SQL 편집기와 Authentication → Users에서 본인 user id(uuid)를 복사해 둔다(이하 `<내 id>`). 서버 알림 만들기:
   ```sql
   select public.daybrick_notify('job-search','test','info','서버 알림 1','서버 내용', null, 'k1', '<내 id>');
   ```
   (`p_target`은 `'{"page":"applications"}'::jsonb`처럼 넣을 수 있다. 합치기 키가 필요 없으면 `null`.)
