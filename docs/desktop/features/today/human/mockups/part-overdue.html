줄 구성 (R35)
  • 카테고리 색 점 · 제목 · 며칠 지났는지(빨강).
  • 둘째 줄에 카테고리 이름 · 원래 기간 · 상태.
  • 정렬: 많이 지난 것부터.
미리보기 (R36–R37)
  • 버튼에 마우스를 올리면 오른쪽에 바뀔 기간을 보여준다.
  • 진행 중은 "끝일만 늘림", 시작 전은 "길이 그대로 옮김".
  • 날짜 고르기에서 오늘까지는 흐리게 막고, 고른 날부터 기간 길이만큼 칠한다.
  • 날짜 고르기는 팝업 위에 떠서 팝업 밖으로 걸쳐도 된다.
처리 후 (R39)
  • 처리한 줄은 빠지고 머리 숫자와 진행 바 버튼 숫자가 같이 준다.
  • 마지막 줄을 처리하면 팝업이 닫히고 버튼이 숨는다(2. 아침 빈 상태처럼).
