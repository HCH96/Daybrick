# 투데이 요구사항: 오늘 요약 (R27–R33)

### 오늘 요약
- R27. 오늘 집중 시간과 하루 목표 대비 진행도를 보인다. 하루 목표는 사용자가 요약 칸의 "집중 시간" 타일(연필)에서 바로 고치고, 처음 기본값은 6시간이다. 고친 목표는 스트릭(R30)과 타이머 트랙(R42)에도 같이 쓴다. 목표를 고치는 곳은 여기 한 곳뿐이다.
- R28. 완료 개수를 보인다 (오늘 칸반의 완료 / 전체).
- R29. 오늘 시간을 카테고리별로 나눠 보인다.
- R30. 스트릭: 집중 시간이 목표 이상인 날이 며칠 연속인지 타일에 숫자로만 보인다. 오늘 아직 목표에 못 미쳤으면 어제까지 이어진 수를 보인다. 타일에 마우스를 올린 동안만 타일 아래에 이번 달 작은 달력이 뜬다. 달력은 요일·월 이름 없이 1부터 말일까지 숫자만 7개씩 늘어놓고, 목표를 채운 날은 불이 켜지고(주황 빛), 못 채운 날은 꺼지고, 오늘은 테두리, 아직 안 온 날은 흐린 숫자다. (목업 r2)
- R31. 타임라인: 오늘 시간 구간을 시간 축 위에 카테고리 색 막대로 보인다.
- R32. (삭제, 목업 r2) 여러 날 태스크의 남은 기간은 요약에 보이지 않는다. 칸반 카드의 D-N으로 충분하다.
- R33. 후보 고르기 끝남 (목업 r2): R27–R31을 남기고 R32를 뺐다.

목업 데이터: 집중 3시간 20분 / 목표 6시간, C++ 공부 2시간, TrialGround 1시간 20분, 스트릭 4일.
