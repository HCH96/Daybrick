# 투데이 요구사항: 끝내지 못한 태스크 (R34–R39)

### 끝내지 못한 태스크
- R34. 미완료 태스크는 끝일이 오늘보다 앞이고 완료되지 않은 태스크다. 날짜 제한은 없다.
- R35. "미완료 N" 버튼(R7)을 누르면 팝업에 목록이 뜬다. 줄마다 카테고리 색, 제목, 원래 기간, 상태, 며칠 지났는지를 보인다.
- R36. 오늘로 가져오기: 진행 중인 태스크는 끝일만 오늘로 늘리고, 시작 전인 태스크는 기간 길이를 그대로 두고 시작일을 오늘로 옮긴다.
- R37. 다른 날로 미루기: 오늘 이후의 날짜를 고른다. 진행 중이면 끝일을 그날로 늘리고, 시작 전이면 길이를 그대로 두고 그날부터 시작하게 옮긴다.
- R38. 완료 처리: 완료로 바꾸고 완료한 날을 지금으로 적는다.
- R39. 처리한 태스크는 목록에서 빠지고 N이 줄어든다. 다 처리하면 팝업이 닫히고 버튼이 숨는다.

| 상태 (원래 기간 10/28~10/30) | 오늘로 가져오기 (오늘 11/03) | 다른 날로 미루기 (11/10 고름) |
|---|---|---|
| 진행 중 | 10/28~11/03 | 10/28~11/10 |
| 시작 전 | 11/03~11/05 | 11/10~11/12 |
