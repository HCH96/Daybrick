# 투데이: 확장 구조
다른 기능(홈 카드, 공유 웹, 안드로이드 연동, 백그라운드 상주)이 타이머·시간 기록을 쓸 때 읽는다.

- 타이머 시작·일시정지·완료·중단은 화면과 떨어진 공용 타이머 저장소 하나가 맡는다. 그래서 다른 메뉴에서도 계속 흐르고(R23), 나중에 제목 표시줄·홈 카드에서도 같은 타이머를 쓴다.
- 시작은 "시작 요청 → (나중: 연동 팝업) → 실제 시작" 단계를 거친다(R26). 지금은 가운데 단계가 비어 있다.
- 시간 기록은 태스크 안에 넣지 않고 태스크 id로 연결되는 별도 목록이다 (플랜 extension.md와 같은 방식). 날짜별·카테고리별 합계, 스트릭은 공용 함수로 계산한다.
- 태스크 상태·날짜는 플랜의 공용 함수("이 날짜에 걸린 태스크", "상태 바꾸기", "기간 바꾸기")로 바꾸고, 주 계산도 플랜의 공용 함수를 쓴다.
- 앱 종료 처리(R24)는 종료 직전 한 곳에서 한다. 백그라운드 상주가 생기면 창 닫기와 종료를 나눠 이 지점만 옮긴다.
- 구체적인 파일 위치와 함수 이름은 구현 계획에서 정한다.
