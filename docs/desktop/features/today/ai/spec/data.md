# 투데이: 다룰 데이터

| 데이터 | 항목 | 저장 위치 |
|---|---|---|
| 태스크 (플랜 것) | 투데이가 바꾸는 항목: 상태, 시작·끝일, 완료한 날 | 플랜 저장소. 플랜의 공용 함수로만 읽고 쓴다 |
| 시간 기록 | id(무작위 고유값), 태스크 id, 시작 시각, 끝 시각 | PC 안 JSON 파일 |
| 실행 중 타이머 | 태스크 id, 실행·일시정지 상태, 이번 실행에서 쌓인 구간, 마지막 확인 시각(R25) | PC 안 JSON 파일 (다시 켜도 남아야 함) |
| 투데이 설정 | 하루 목표(분, 기본 360) | PC 안 JSON 파일 |

- 카테고리 이름·색은 플랜 저장소에서 읽기만 한다.
- 시간 기록 등을 플랜 파일과 같이 둘지 따로 둘지는 구현 계획에서 정한다.
- 날짜별·카테고리별 합계와 스트릭은 저장하지 않고 시간 기록에서 계산한다.
