# 투데이 요구사항: 칸반 (R8–R15)

### 칸반
- R8. 오늘이 시작일~끝일 안에 있는 태스크를 시작 전 / 진행 중 / 완료 세 열로 보여준다. 날짜가 없는 태스크는 보이지 않는다.
- R9. 완료 열에는 오늘이 기간 안이고 완료 상태인 태스크가 언제 끝냈든 모두 보인다.
- R10. 카드에는 카테고리 색과 제목을 보이고, 여러 날 태스크는 끝일까지 남은 기간(예: "D-2", 마지막 날은 "오늘 마감")을 보인다.
- R11. 시작 전·진행 중 카드에는 타이머 시작 버튼이 있다. 다른 태스크의 타이머가 돌고 있으면 시작 버튼을 누를 수 없고 그 이유를 안내한다.
- R12. 완료 카드에는 타이머 시작 버튼이 없다.
- R13. 카드를 다른 열로 끌어 상태를 바꿀 수 있다. 타이머가 도는 카드를 완료 열로 끌면 타이머 "완료"(R19), 시작 전 열로 끌면 "중단"(R20)과 같다.
- R14. 카드를 누르면 플랜의 태스크 상세 팝업이 열린다.
- R15. 빈 열에는 짧은 빈 상태 문구를 보인다.
