# 프로젝트 (projects) 사용자 테스트 체크리스트 r1
작성일: 2026-11-05 · 근거: 명세서 R1–R59, 구현 계획 1–10단계, 진행 기록 L01–L13
간단 판: 시나리오 11개. 위에서부터 차례로 하면 앞 항목에서 만든 데이터를 뒤 항목에서 이어 쓴다. 세부 계산(진하기 경계, 연속일, 버블 크기 등)은 AI 테스트(ai/tests/r1/)에서 확인했다.

## 준비
1. 앱 데이터 폴더의 `plan.json`을 다른 곳에 복사해 백업한다 (테스트 뒤 되돌릴 때 사용).
2. `apps/desktop`에서 `npm run tauri dev`로 앱을 켠다. 창은 1200x800 정도로 둔다.
3. 데이터는 U2에서 만든다.
   - **프로젝트 A**: 단계형, 이름 "Daybrick", 단계 `기획`·`프로토`·`폴리싱`
   - **프로젝트 B**: 주차형, 이름 "토익", 시작 주는 이번 주(11/2), 4주, 2주차 이름 "중간"
   - U4에서 A의 `기획`에 태스크 3개, `프로토`에 태스크 2개를 만든다.

### 2. 프로젝트 만들기·카드·순서·이름/색 바꾸기
- 근거 요구사항: R3, R5, R7, R8, R9–R12, R27
- 수행 방법:
  1. `+ 프로젝트 만들기`를 누르고, 이름을 비운 채 `만들기`가 눌리는지 본다.
  2. 단계형으로 프로젝트 A를 만든다. 단계 이름 칸에서 Enter를 누르면 아래에 새 줄이 생기는지 본다.

  5. B 카드의 `…` → `이름·색 바꾸기`로 색을 바꾼다.
  6. 앱을 껐다 켠다.
- 예상 결과:

  - 재시작 뒤에도 카드 순서와 색이 그대로다.
  - 긴 이름은 카드에서 `…`로 줄여 보인다.

### 4. 단계 칸 태스크 관리
- 근거 요구사항: R16, R23, R24, R30–R34
- 수행 방법:
  1. A 상세의 `기획` 칸에서 `+`를 누르고 태스크 3개를 연달아 적는다 (Enter로 이어 적기). `프로토`에도 2개를 적는다.
  2. `기획`의 한 태스크에서 상태 표시를 세 번 누른다.
  3. 줄을 눌러 팝업에서 제목과 기간을 고친다.
  4. `프로토` 태스크 하나를 끌어 `폴리싱` 칸에 놓는다.
  5. `기획`의 나머지 태스크도 모두 완료한다.
  6. 휴지통 버튼으로 하나를 지운다.
  7. 앱을 재시작한다.
- 예상 결과:
  - 새 태스크는 `날짜 없음`·시작 전이다.
  - 상태는 시작 전 → 진행 중 → 완료 순서로 바뀐다. 완료한 태스크는 `완료 N` 아래로 내려가고, 칸 머리 숫자(예: 1/3)가 바뀐다.
  - 팝업에서 고친 제목과 기간이 줄에 바로 보인다.
  - 끌 때는 기울어진 모양이 따라오고, 놓을 칸에 테두리가 생긴다. 옮긴 태스크는 재시작 뒤에도 `폴리싱`에 있다.
  - `기획`을 다 끝내면 칸 머리가 초록이 되고, `기획` 깃발이 끝난 깃발 모양으로 바뀐다. 캐릭터는 통통 뛰며 다음 자리까지 달려간다.
  - 태스크가 없는 칸에는 "+ 를 눌러 추가" 같은 안내가 보이고, 그 단계는 끝난 것으로 치지 않는다.

### 5. 단계 편집·확인 창
- 근거 요구사항: R13, R14
- 수행 방법:
  1. A 상세에서 `단계 편집`을 연다. `+ 단계 추가`로 단계를 하나 더하고, 이름 하나를 바꾸고, 순서를 바꾼 뒤 `저장`한다.
  2. 다시 `단계 편집`을 열어 이름 하나를 비워 본다.
  3. 태스크가 있는 단계를 지우고 `저장`한다. 확인 창에서 `취소`, `옮기기`(대상 선택), `함께 지우기`를 각각 한 번씩 해 본다. 매번 다시 편집을 연다.
  4. B 상세에서 `주차 편집`으로 주 수를 6으로 늘린다. 5주차 칸에 태스크를 하나 넣은 뒤, 주 수를 4로 줄인다. 이어서 시작 주를 다음 주로 바꾼다.
- 예상 결과:
  - 단계 추가·이름·순서 변경이 깃발과 칸에 바로 반영된다. 새로 추가한 빈 줄은 저장할 때 빠진다.
  - 있던 단계의 이름을 비우면 빨간 "있던 단계의 이름은 비울 수 없어요."가 뜨고 `저장`이 막힌다.
  - 확인 창에는 "'<단계>'에 태스크 N개가 있어요"가 뜬다.
    - `취소`: 아무것도 바뀌지 않는다.
    - `옮기기`: 고른 단계로 태스크가 옮겨진다.
    - `함께 지우기`: 태스크도 사라진다.
  - 주 수를 6에서 4로 줄이면 5주차(태스크 있음)만 묻고, 6주차는 묻지 않는다.
  - 시작 주를 바꾸면 깃발 아래 날짜와 칸 기간이 바뀐다.
- 확인 위치: 편집 창, 확인 창, 상세 트랙·칸

### 6. 골인 연출·완료 묶음
- 근거 요구사항: R6, R18, R25
- 수행 방법:
  1. A 상세에서 남은 태스크를 모두 완료한다.
  2. 목록으로 가서 `▸ 완료 1개`를 누른다.
  3. A 상세를 다시 연다.
  4. 태스크 하나를 시작 전으로 되돌리고 목록을 본다. 다시 상세에서 완료한다.
  5. (선택) Plan 화면에서 마지막 태스크를 완료한 뒤 프로젝트 상세를 처음 연다.
- 예상 결과:
  - 마지막 태스크를 완료하면 캐릭터가 결승에 닿는다. 결승 깃발이 펄럭이고 색종이가 약 1.6초 날리며 `골인!` 배지가 보인다.
  - 상세를 다시 열면 연출이 나오지 않는다. 다만 골인 도중에 상세를 떠났다면 다음에 열 때 다시 나온다.
  - 목록에서는 A 카드가 진행 중에서 빠지고 `▸ 완료 1개` 묶음에 들어간다. 펼치면 같은 카드가 흐리게 보이고, 캐릭터는 결승선에, 문구는 `완료 · 단계 N/N`이다.
  - 되돌리면 진행 중 목록으로 돌아온다. 다시 완료하면 연출이 또 나온다.
  - Plan에서 완료한 경우에는 상세를 처음 열 때 연출이 한 번 나온다.

### 7. 타이머 연동 (모닥불·누적·진행 중·잔디 오늘 칸)
- 근거 요구사항: R26, R28, R43, R44, R55, R56, R57
- 수행 방법:
  1. B의 이번 주 칸 태스크 하나에 오늘 기간을 넣는다. 투데이에서 그 태스크로 타이머를 시작한다.
  2. 3분쯤 두고 프로젝트 목록과 B 상세를 번갈아 본다.
  3. 타이머를 일시정지한다.
  4. (가능하면) 어제 기록이 있는 상태에서 오늘 첫 타이머를 시작하는 순간을 본다.
- 예상 결과:
  - 타이머가 도는 동안:
    - 상세와 카드의 모닥불이 활활 타고, 마지막 작업이 `오늘`이 된다.
    - 누적 시간이 1분마다 늘어난다. 숫자만 바뀌고 애니메이션은 없다.
    - 버블 판 위에 `● 토익 진행 중`(상세는 `타이머 진행 중`)이 보인다. B 원이 생기고, 1분마다 통통 튀며 커진다.
    - 잔디 오늘 칸(흰 테두리)이 숨 쉬듯 빛나고, 오른쪽 `오늘` 시간이 늘어난다.
  - 일시정지하면 진행 중 표시가 사라진다.
  - 연속 작업일:
    - 오늘·어제 기록이 있으면 `연속 작업` 2일째로 보인다.
    - 오늘 기록이 없고 어제만 있으면 `연속 작업 (어제까지)`와 함께 불이 약하게 깜빡이고 `오늘 하면 2일째`가 보인다. 1분이 지나면 `연속 작업` 2일째로 바뀐다.
  - 투데이 화면의 스트릭(하루 목표)과 숫자가 달라도 정상이다 (D4).

### 8. 버블·잔디 마우스 동작
- 근거 요구사항: R35–R41, R54, R58, R59
- 수행 방법:
  1. 두 프로젝트 모두에 이번 주 기록이 몇 분이라도 있게 한다. A의 단계를 하나 되돌려 진행 중으로 두고 타이머를 짧게 돌린다.
  2. 버블 판을 30초쯤 지켜본다.
  3. 원 하나를 끌어 세게 던진다.
  4. 원이 오른쪽 아래 범례 위를 지나가는 모습을 본다.
  5. 원과 범례 줄에 마우스를 올렸다 뗀다.
  6. 기록이 있는 잔디 칸과 앞으로 올 날 칸에 마우스를 올린다.
  7. 창 크기를 바꾼다.
- 예상 결과:
  - 원은 프로젝트 색이고, 안에는 퍼센트만 쓰여 있으며 모든 원의 퍼센트를 더하면 100이다 (같은 시간인 원은 34/33/33처럼 1% 차이가 날 수 있다, L15). 1~2분짜리 아주 작은 원은 글자가 원 밖으로 넘칠 수 있는데, 정상이다.
  - 원들은 가운데로 모이지 않고 떠다니며, 벽이나 다른 원에 부딪히면 튕긴다.
  - 던지면 그 방향으로 날아갔다가 다시 떠다닌다.
  - 범례 위에서는 원이 반투명해져 밑의 글자가 비친다.
  - 범례는 시간이 많은 순서이고, 배경·테두리 없이 글자만 있다. 9자가 넘는 이름은 말줄임된다.
  - 원이나 범례 줄에 마우스를 올리면:
    - 잔디가 그 프로젝트 색으로 다시 칠해지고, 머리에 `<이름>만` 칩이 생기며 진하기 범례는 숨는다.
    - 오른쪽 숫자가 그 프로젝트의 작업한 날·16주 합계·마지막 작업으로 바뀐다.
    - 다른 원과 범례는 흐려진다.

### 9. 플랜 연동 (트리·달력·옮기기·상세 팝업)
- 근거 요구사항: R45–R52
- 수행 방법:
  1. Plan을 열어 왼쪽 트리를 본다.
  2. B의 다른 주차 하나를 펴고 앱을 재시작한다.
  3. 단계 머리의 `+`로 태스크를 만든다.
  4. 그 태스크를 주간 달력에 끌어 배치하고, 늘이고 옮긴다.
  5. 단계 태스크를 카테고리 묶음에 놓는다. 반대로 카테고리 태스크를 단계 묶음에 놓는다.
  6. 빠른 입력칸의 선택 목록을 연다.
  7. 태스크 상세 팝업의 카테고리 선택에서 "프로젝트 › 단계"를 고른다.
- 예상 결과:
  - 트리 순서는 카테고리들 → 진행 중 프로젝트들(프로젝트 목록과 같은 순서) → 미분류다. 완료된 프로젝트는 보이지 않는다.
  - 프로젝트 머리에는 색·이름·끝나지 않은 개수가 있고, `+`·`…`는 없다. 단계 머리에는 이름(주차형은 기간도)·개수·`+`가 있다.
  - 처음에는 현재 단계만 펼쳐져 있다. 직접 편 주차는 재시작 뒤에도 펼친 채다.
  - 단계 `+`로 만든 태스크는 프로젝트 상세의 그 칸에도 보인다.
  - 달력 막대는 프로젝트 색이고, 늘이기·옮기기는 카테고리 태스크와 같다.
  - 끌어 놓으면 놓은 곳으로 옮겨진다 (상세 칸에서도 확인). 프로젝트 머리 자체에는 놓이지 않는다.
  - 빠른 입력 목록에는 프로젝트가 없다.
  - 팝업에서 `토익 › 2주차`처럼 고르면 트리에서 태스크 자리가 바뀐다.
- 확인 위치: Plan 왼쪽 트리, 주간 달력, 상세 팝업
