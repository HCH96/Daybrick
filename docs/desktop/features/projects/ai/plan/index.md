## 결정 (계획 중 정함, D5–D9)
- 프로젝트·단계는 `plan.json`에 함께 둔다. 단계는 프로젝트 안 `stages[]`(순서 = 배열 순서), 태스크에 `stageId` (D5).
- 저장 파일은 옮기지 않는다. version 1 그대로, 읽을 때 없는 값은 빈 값으로 채운다. 백업 없음 (D6).
- 방문 기록 한 칸을 `{ page, sub? }`로 바꿔 상세 화면도 앱 뒤로가기로 돌아온다 (D7).
- 버블 그래프는 `d3-force`·`d3-ease`(+ 타입)를 설치해 쓴다 (D8).
- 시간은 10초마다 확인하고 분 단위 값이 바뀔 때만 다시 그린다. 버블 튀기·잔디 오름도 그때 (D9).

### 작은 규칙
- 버블 반지름: 400분 = 50 기준, 원 넓이 합이 판의 32%를 넘으면 모두 같은 비율로 줄인다.
- 골인 연출(R25): 캐릭터가 결승에 닿으면 결승 깃발 펄럭 + 색종이 1.6초 + "골인!" 배지. 본 시각 `goalSeenAt`, 다시 진행 중이 되면 앱 전체 감시(`useGoalReset`)로 비운다.
- 확인 창: 단계 삭제·주 수 줄이기(R14)는 대상 단계 선택 + `옮기기`/`함께 지우기`/`취소`, 프로젝트 삭제(R19)는 "태스크 N개는 미분류로 옮겨집니다".
- 완료 묶음 펼침(R6): 같은 카드를 흐리게, 캐릭터는 결승선에.
- 태스크 끌기(R34): 플랜과 같은 기울어진 끄는 모습, 놓을 칸 테두리.
- 프로젝트 색은 `--c` 변수 하나로 넘긴다. 주차형 단계 이름 ""는 "N주차"로 보인다.
- 순수 함수(`features/projects/*.ts`)는 Node로 실행해 확인한다. 테스트 도구는 아직 없다.
