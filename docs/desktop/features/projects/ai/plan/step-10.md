# 프로젝트 10단계: 마무리·전체 빌드

- 요구사항: 전체 (R1–R59)
- 목업: 전체 ([../../human/mockups/index.html](../../human/mockups/index.html) 목차 기준으로 화면 파일과 비교)
- 경로 기준: [index.md](index.md) 맨 위
- 공통 규칙: D1–D9

## 할 일
- 목업과 비교: 목록·상세(단계형·주차형)·만들기 창·모닥불·버블 빈 상태·잔디 상태를 앱에서 열어 간격·색·글자를 목업과 맞춘다.
- 좁은 창: 앱 최소 너비에서 카드 한 줄, 윗줄 60:40, 단계 칸이 넘치지 않게(카드 누적 시간·미니 트랙을 줄이는 순서는 목업 비율대로).
- 긴 이름: 프로젝트·단계·태스크 이름 말줄임 확인.
- 정리: 쓰지 않게 된 코드·CSS가 남았는지 `npx tsc --noEmit`와 grep으로 확인. 요청하지 않은 리팩터링은 하지 않는다.
- 문서: 진행 기록 남기기, 기능 허브·PROJECT.md 상태 "구현 완료 (테스트 대기)".

## 확인할 결과
- `npm run build`, `npm run tauri build` 성공 (설치 파일이 `src-tauri/target/release/bundle/`에 생김).
- 설치한 앱에서 프로젝트를 만들고 태스크를 추가·완료·옮기기, 타이머 실행이 개발 모드와 같게 동작한다.
- 좁은 창·긴 이름에서 겹침·넘침이 없다.
- 플랜·투데이의 기존 동작(카테고리 태스크, 달력, 칸반, 타이머)이 바뀌지 않았다.
