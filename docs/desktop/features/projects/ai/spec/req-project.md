# 프로젝트 요구사항: 프로젝트·단계 규칙 (R9–R20)

### 프로젝트·단계 규칙
- R9. 프로젝트는 이름, 색(색 선택기), 종류(주차형/단계형)를 가진다.
- R10. 만들 때 종류를 고르고, 만든 뒤에는 종류를 바꿀 수 없다.
- R11. 주차형은 시작 주와 주 수를 고르면 1주차~N주차가 월요일 기준으로 자동으로 생기고, 각 주차에 이름을 붙일 수 있다 (없으면 "N주차").
- R12. 단계형은 단계 이름을 순서대로 적어 만든다 (최소 1개).
- R13. 만든 뒤 단계형은 단계 추가·삭제·이름·순서를, 주차형은 시작 주·주 수·주차 이름을 고칠 수 있다.
- R14. 태스크가 있는 단계가 없어지면(삭제·주 수 줄이기) 확인 창에서 "다른 단계로 옮기기(대상 선택)"나 "함께 지우기"를 고른다.
- R15. 프로젝트 태스크는 반드시 한 단계에 속하고, 카테고리는 갖지 않는다.
- R16. 단계는 태스크가 1개 이상이고 모두 완료이면 끝난 단계다. 태스크가 없는 단계는 끝나지 않은 것으로 본다.
- R17. 현재 단계는 단계형이면 앞에서부터 끝나지 않은 첫 단계, 주차형이면 오늘이 속한 주차다 (시작 전이면 1주차, 기간이 지났으면 마지막 주차).
- R18. 모든 단계가 끝나면 프로젝트가 자동으로 완료되고, 태스크를 되돌리거나 새로 넣으면 다시 진행 중이 된다.
- R19. 프로젝트를 지우면 확인을 받은 뒤 지우고, 안의 태스크는 미분류로 옮긴다 (플랜 카테고리 R9와 같은 방식).
- R20. 주차형은 기간이 지나도 끝나지 않은 단계가 있으면 진행 중으로 남는다.

- 주차는 계획상 묶음일 뿐이고, 태스크 날짜를 그 주 안으로 제한하지 않는다.
- 주차형의 깃발·진행률도 단계형과 같이 태스크 완료(R16)로 정한다. 날짜는 현재 단계(R17)에만 쓴다.
