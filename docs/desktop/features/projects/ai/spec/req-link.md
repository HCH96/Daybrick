# 프로젝트 요구사항: 플랜·투데이 연동 (R45–R53)

### 플랜 왼쪽 트리
- R45. 플랜 왼쪽 트리에 진행 중인 프로젝트를 카테고리와 같은 모양(색·이름·끝나지 않은 개수·접기)으로 카테고리 아래, 미분류 위에 프로젝트 순서(R7)대로 보여준다. 플랜에 프로젝트 탭은 따로 두지 않는다.
- R46. 프로젝트 아래에 단계가 한 층 더 펼쳐지고, 단계 머리에는 이름(주차형은 기간도), 끝나지 않은 개수, `+`가 있다.
- R47. 사용자가 직접 접거나 편 적 없는 단계는 현재 단계(R17)면 펼치고 나머지는 접는다. 직접 바꾼 상태는 다시 열어도 유지된다.
- R48. 단계 안 태스크는 플랜 R13–R15 규칙 그대로 보여준다 (배치한 태스크도 기간과 함께 그대로 보임).
- R49. 단계 태스크도 주간 달력으로 끌어 배치하고, 달력 동작은 플랜 R21–R30과 같다.
- R50. 플랜 목록에서 태스크를 단계 묶음에 놓으면 그 프로젝트 단계로 옮겨지고(카테고리는 없어짐), 카테고리 묶음에 놓으면 프로젝트에서 빠진다.
- R51. 플랜 빠른 입력칸의 선택 목록에는 프로젝트를 넣지 않고, 프로젝트 태스크는 단계 `+`로 만든다.
- R52. 태스크 상세 팝업의 카테고리 선택에 "프로젝트 › 단계"도 고를 수 있다.

### 투데이·타이머
- R53. 투데이 칸반·타이머·오늘 요약은 프로젝트 태스크도 똑같이 다루고, 카테고리 이름·색을 쓰는 자리에는 프로젝트 이름·색을 쓴다.

- 이 묶음은 플랜·투데이 화면 코드를 고치지만, 요구사항은 이 기능(projects)에서 관리한다.
