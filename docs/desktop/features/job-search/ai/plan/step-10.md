# 구직 관리 수정2 10단계: 팝업 출처 칩·따로 보기 메뉴

- 요구사항: R92 (L44에서 변경), R93 (L44에서 변경) (영향: R55 지원하기 링크)
- 목업: `popup.html` popup-head 구역 (CSS: popup.css·common.css). 출처 칩은 목업에 없고 [req-recommend.md](../spec/req-recommend.md) 맨 아래 "출처 표시" 글 그림이 기준이다 (사용자 결정).
- 경로 기준: [index.md](index.md) 맨 위
- 공통 규칙: D39, D54, D58, D62, D63

## 할 일
- `popup/PopupSources.tsx`를 한 줄 칩으로 바꾼다:
  - `출처  [넥슨 ↗ · 대표] [게임잡 ↗]  [⋯]`. 칩을 누르면 그 공고 링크를 연다 (기존 열기 방식 그대로). 대표 칩에는 "· 대표".
  - 출처가 2개 이상일 때만 그린다 (D63 그대로). 칩이 많으면 줄을 넘겨 감싼다.
  - `[⋯]`을 누르면 작은 메뉴가 열리고, 공고마다 "<사이트> 따로 보기" 항목. 바깥 누르기·Esc로 닫힌다.
  - 메뉴 항목 동작은 기존 [따로 보기]와 같다 (`unbundlePosting`, 대표를 풀면 팝업 닫기, 묶인 공고를 풀면 성공 문구·다시 읽기, 지원한 공고면 항목이 꺼짐, 진행 중이면 아래 단추 모두 꺼짐 — D63).
- `popup/PopupHead.tsx`: 출처 자리를 제목 아래 칩 줄로 옮긴다. `PostingPopup.css`에 칩·메뉴 클래스 (`.js-popup__src-chip`, `.js-popup__src-menu`).
- [지원하기]는 지금처럼 대표 링크 (R92).

## 목업과 다른 점
- 목업 팝업 머리에는 출처 블록이 없다. 제목 아래(경력·형태 칩 줄 위)에 출처 칩 줄이 더 있고, 칩 모양은 목업의 기존 회색 칩, ⋯ 메뉴는 목업의 행 메뉴(`sources.html` 사이트 표의 ⋯) 모양을 따른다.
- 수정1의 "출처 줄 ×N + 줄마다 [따로 보기]" 모양은 없어진다.

## 확인할 결과
- `npm run build` 성공.
- 묶음 카드를 열면 제목 아래 `[넥슨 ↗ · 대표] [게임잡 ↗] [⋯]` 한 줄, 칩을 누르면 해당 사이트 공고가 열린다. 출처 하나인 공고는 칩 줄이 없다.
- 이전 사용자 테스트 r2 6번(따로 보기, 보류): ⋯ → "게임잡 따로 보기" → 성공 문구, 칩 하나 줄어듦 → [지금 평가]·일괄 처리 뒤 별도 카드. 다른 묶음에서 대표 항목을 풀면 팝업이 닫히고 남은 공고가 같은 점수로 대표가 됨.
