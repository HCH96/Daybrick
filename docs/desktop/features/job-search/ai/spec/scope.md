# 구직 관리: 범위

## 이번 범위에서 제외하는 것
- 자소서 초안, 면접 준비
- 푸시 알림, OS 알림
- 남은 크레딧 API 조회 (조회할 방법 없음)
- 코드 어댑터, 문장으로 쓰는 필터
- 구직 관리 밖에서 직접 만든 지원 카드의 메일 확인
- IMAP 연결, Claude 외 AI 제공자
- 개발 외 직군을 골라 남기는 기능 (직군 거르기는 "개발 직군만" 하나, L44)

## 다른 기능으로 넘긴 것
- server-setup: 로그인, 첫 실행 설정(주소/키 입력), 빈 Supabase 자동 세팅(테이블·RLS·서버 함수·비밀값), 설치 가이드, 무료 플랜 일시정지 감지·재개 안내
- notifications: 알림 센터 (오른쪽 위 아이콘, 빨간 숫자 배지, 화면 이동 없이 목록 펼침)

## 나중에 고려할 것
- 대형 게임사 어댑터 (사용자 추가 기능으로 넷마블·엔씨소프트·크래프톤·스마일게이트를 직접 테스트)
- 자소서 초안
- 지원 관리 전체 서버 동기화
- 직접 만든 카드를 지원 건으로 연결하기

## 계획 단계에서 확인할 것 (지금은 추측)
- Batch API의 강제 도구 호출·프롬프트 캐시 지원 여부, 결과 보관 기간, 실제 처리 시간, 서버 함수 150초 안에 큰 결과를 읽을 수 있는지 (수정2, L44)
- 게임잡·넥슨 채용 페이지가 서버 함수에서 HTML/JSON으로 바로 읽히는지 (브라우저 스크립트로 그리는 페이지는 규칙 파일로 읽기 어려울 수 있음)
- 각 사이트의 이용약관·robots 규칙
- Supabase 무료 플랜의 예약 실행(pg_cron)과 서버 함수 실행 시간 제한
- server-setup의 Google 클라이언트로 Gmail 권한을 추가하고 갱신 토큰을 받는 방법 (Supabase Google 로그인 재요청 / 앱이 직접 Google 인증)
- Gmail 연결 해제 때 Google 권한을 취소하면 앱 로그인에 영향이 있는지
