### 목업에 넣은 추가 제안 (목업과 함께 승인)
- 추천 공고 도구 줄: 프로필을 바꾼 뒤에만 주황 안내 "N개가 이전 프로필 기준이에요 [다시 채점]", 해당 카드에는 "이전 프로필 기준" 글자 (R23의 표시 방법)
- 필터 탭 맨 위에 처리 순서 줄(수집 → 1차 → 추출 → 2차 → 채점)과 이번 주 단계별 개수. AI를 쓰는 단계는 보라 테두리
- 걸러진 공고 위쪽에 단계 고르기(전체 / 1차 / 2차 / 인젝션 의심)
- 보관함에서 마감이 지난 공고는 남겨 두되 [되돌리기]를 끔
- 일정 제안 창은 모든 항목이 체크된 상태로 열림
- 메일 제안 탭 아래에 최근 30일 "처리한 제안" 목록(승인·거절)
- 어댑터 카드에 "사이트 N곳이 함께 씀"과 마지막 수집 실패 칩
- 프로필 저장 단추에 저장될 버전 번호 표시 ("저장 (v4)")

### 계획 단계에서 정할 것
- 어댑터 가이드 그림의 JSON 키 이름(list.item 등)은 예시다. 실제 규칙 파일 형식은 계획에서 정한다.
- 모델 단가표의 캐시 토큰 단가 칸은 필요하면 계획에서 추가한다.
