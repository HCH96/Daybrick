# 구직 관리 요구사항: 지원하기·일정 제안 (R54–R59)

### 지원하기·일정 제안
- R54. "지원하기"를 누르면 지원 관리에 새 카드를 만든다: 상태 "지원 준비", 제목·회사·직무·공고 링크·경력 구분·고용 형태 속성을 채우고, 본문에 공고 요약(자격, 우대, 적합도 요약)을 넣는다.
- R55. 공고에 지원 마감·과제 마감·코딩테스트·면접 날짜가 있으면 "일정 제안" 창에 목록으로 보여주고, 체크한 항목만 카드의 전형 일정으로 추가한다.
- R56. 날짜가 정확하지 않은 일정(예: "3월 중")은 제안하지 않고 본문에만 적는다.
- R57. 카드는 지금처럼 PC 로컬에 저장하고, 서버에는 지원 건 요약(공고, 회사 이름, 메일 판별용 도메인, 카드 id, 현재 상태)만 저장한다.
- R58. 지원 관리에서 카드 상태를 바꾸면 서버의 지원 건 상태도 바뀐다. 연결이 안 되어 있으면 다음 연결 때 반영한다.
- R59. 카드를 지우거나 종료로 바꾸면 그 지원 건은 메일 확인 대상에서 빠진다.
