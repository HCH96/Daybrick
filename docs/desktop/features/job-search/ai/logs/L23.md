# L23 · 2026-10-28 · 수정: AI 결과를 structured outputs로 받기

- 요구사항: R18–R20, R48–R52, R66–R67
- 한 일: L22 로그로 확인한 원인은 400 `tool_choice: type "tool" and "any" are not supported for this model` (Opus 5.5). 프로필 만들기뿐 아니라 점수 매기기(Opus 5.5)도 같은 문제였다.
  `_shared/ai.ts`의 `callClaude`에서 강제 도구 호출을 빼고 `output_config.format`(json_schema)으로 바꿨다. 결과는 글자 블록의 JSON을 해석하고, `stop_reason`이 end_turn이 아니거나 해석에 실패하면 로그를 남기고 bad-response로 돌려준다.
  `toOutputSchema`가 prompts.ts 형식을 바꾼다: object마다 `additionalProperties: false`, `type: [x, "null"]`은 `anyOf`로 나누고 enum의 null은 null 갈래로 옮긴다.
  프롬프트의 "result 도구로" 문구를 "정해진 JSON 형식으로"로 바꿨다. 생각이 max_tokens 안에서 쓰이므로 상한을 올렸다 (프로필 16000, 추출·채점 8192, 메일 4096).
