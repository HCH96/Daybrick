# L30 · 2026-10-29 · 수정: 게임사 7곳 사용자 추가용 어댑터 규칙

- 요구사항: R25, R29
- 한 일: 엔씨소프트·넷마블·스마일게이트·카카오게임즈·펄어비스·데브시스터즈·시프트업의 규칙을 회사마다 하위 에이전트로 만들어 `supabase/adapters/custom/`에 두었다. 기본 어댑터가 아니라, 앱의 사이트 추가 화면에 붙여 넣는 원본이다. 엔진(adapter.ts)은 고치지 않았다.
  - 읽는 방식: 넷마블·스마일게이트·시프트업은 자체 JSON API. 펄어비스는 HTML. 카카오게임즈·데브시스터즈는 Greeting API 목록과 `.ql-editor` 상세. 카카오게임즈는 처음에 HTML(`data-testid`) 방식이었는데 메인 세션이 Greeting API로 바꿨다.
- 확인 (실제 실행, 이 PC에서 deno로 adapter.ts의 validateRule·readList·readDetail 직접 호출, 모두 형식 검사 통과):

  | 펄어비스 | 21 | 21/21, 596~1,513자 | 사용 가능, 회사명 빈칸 |
  | 카카오게임즈 | 8 | 8/8, 161~1,600자 | 사용 가능 |

- 사용자 확인: 대기 (앱에서 사이트 추가·시험 수집)
- 남은 문제 (형식 v1에 없어서 생기는 것):
  - 고정 회사명 칸이 없음: 펄어비스는 빈칸, 시프트업은 "shiftup".
  - 링크 틀(`?seq={id}` 등)이 없음: 스마일게이트 링크가 API 주소, 엔씨소프트는 regOpId·jopenId 두 값 필요. 넷마블은 `/announce/{id}` 302 이동에 기댐.
  - 상세 본문이 경로 하나뿐: 스마일게이트 본문이 여러 칸에 나뉨.
  - 본문 안 `data:` 이미지를 건너뜀: 넷마블 1891.
  - 세션·토큰 준비 요청이 없음: 엔씨소프트 목록.
  - 공고 0개를 실패로 봄: 데브시스터즈는 공고가 없는 동안 매주 실패로 표시된다.
