# L29 · 2026-10-29 · 수정: 상세 본문이 iframe 안에 있는 사이트 읽기 (detail.frame)

- 요구사항: R25, R29, R30
- 한 일: 크래프톤 채용(krafton.com/careers/jobs/)은 상세 페이지가 공고를 Greenhouse iframe으로 끼워 보여 줘서 규칙으로는 본문이 비었다. 규칙 형식 v1에 선택 칸 `detail.frame`(html만)을 더했다.
  1. `_shared/adapter.ts`: `readDetail`이 frame 선택자의 src를 상세 주소 기준 절대 주소로 바꿔 한 번 더 받고(User-Agent만, 규칙 headers는 붙이지 않음), 그 화면에서 body·images를 읽는다. 이미지 기준 주소도 그 화면 주소. iframe을 못 찾으면 원래 페이지에서 읽고, 받기에 실패하면 실패로 돌려 다음 실행이 다시 받는다. 형식 검사에 frame(빈 글자 아님, type html) 추가.
  2. 앱 `adapterRule.ts`: 같은 검사. `guideContent.ts`: 키 표·AI 프롬프트 틀·자주 나는 오류에 frame 설명.
  3. `plan/structure.md` 규칙 형식에 한 줄.
