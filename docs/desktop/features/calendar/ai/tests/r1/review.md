  - 하루 종일 줄은 ["종일 개인", "기간 개인"]
  - 완료 목록은 ["08:05 완료B", "18:30 완료A"]. 태스크 날짜(11/1·11/20)와 상관없이 completedAt이 11/3인 것만 시각순으로 나오고, 11/4에 완료한 태스크는 빠진다
  - 아무것도 없는 날은 세 목록이 모두 비어 있다(빈 상태 문구 조건, A11)
