# 캘린더 요구사항: 개인 일정 (R21–R30)

### 개인 일정
- R21. 개인 일정은 제목, 시작일, 끝일, 시작 시각(선택)을 가진다.
- R22. 개인 일정에는 타이머와 완료 상태가 없고, 투데이 칸반에도 나오지 않는다.
- R23. 오늘이나 미래 날짜 칸의 빈 곳을 누르면 그 칸에 제목 입력칸이 생긴다. Enter를 누르면 하루짜리 일정으로 저장하고, Esc를 누르거나 제목이 비어 있으면 취소한다.
- R24. 날짜 칸 여러 개를 드래그하면 그 범위가 강조되고, 바로 제목을 입력해 기간 일정으로 저장한다. 지난 날짜가 들어간 범위도 된다.
- R25. 시간이 없는 일정은 하루 종일 일정으로 처리한다.
- R26. 시간은 시작 시각만 적고(예: 14:00), 칩에는 "14:00 치과"처럼 보인다. 시간은 하루짜리 일정에만 넣을 수 있다.
- R27. 기간 일정은 날짜를 가로지르는 막대로 보여주고, 주 경계에서 잘리면 잘린 쪽 끝을 표시한다.
- R28. 개인 일정 칩을 누르면 편집 팝오버가 열린다. 팝오버에서 제목, 시작일·끝일, 시간(없음 또는 시각)을 고치고 삭제할 수 있다.
- R29. 삭제는 확인을 한 번 받은 뒤 지운다.
- R30. 지난 날짜에 하루짜리 개인 일정을 넣을 때는 회고 패널의 [개인 일정 추가] 버튼을 쓴다(R48). 지난 날짜를 누르면 회고 패널이 열리기 때문이다.

- 예: 예비군, 병원, 가족 행사처럼 태스크가 아닌 "그날 있는 일".
- 시작일이 끝일보다 늦어지는 입력은 저장하지 않는다 (막는 방식은 계획에서 정한다).
