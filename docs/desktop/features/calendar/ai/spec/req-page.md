# 캘린더 요구사항: 페이지·월 달력 (R1–R8)

### 페이지·월 달력
- R1. 사이드바의 스케줄러 메뉴를 없애고, 같은 자리(프로젝트 다음)에 캘린더 메뉴를 둔다. 사이드바에는 `Calendar`, 화면 제목은 "캘린더"로 쓴다.
- R2. 보기는 한 달 보기 하나만 둔다. 월~일 7열이고, 그 달을 덮는 주 줄(5~6줄)로 그린다.
- R3. 머리에는 "2026년 11월" 제목, 이전 달·다음 달 버튼, [오늘] 버튼만 둔다. D-day 표시는 넣지 않는다.
- R4. 오늘 칸은 강조하고, 지난 날짜는 살짝 흐리게, 다른 달 날짜는 더 흐리게 보여준다.
- R5. 칸에 다 들어가지 않는 일정은 "+N"으로 줄이고, 누르면 그날 일정 전체를 작은 목록으로 보여준다.
- R6. 집중 시간, 실행률, 카테고리 비율 같은 기록·통계는 보여주지 않는다.
- R7. 홈의 "오늘 일정" 카드는 내용을 바꾸지 않고, 이동 버튼이 가는 곳만 캘린더로 바꾼다.
- R8. 플랜·지원관리·프로젝트에서 바꾼 내용은 캘린더에 바로 반영된다.

- 스케줄러는 "준비 중" 빈 페이지였기 때문에 옮길 기능이나 데이터가 없다. 메뉴 id(`scheduler` → `calendar`), 이름, 아이콘만 바꾼다.
- 홈 카드 이동 버튼의 글자는 메뉴 이름에서 가져오므로 "캘린더로 가기"로 바뀐다.
