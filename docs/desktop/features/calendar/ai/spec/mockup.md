## 목업에서 정한 것
- 칩 4종 구분 (R17, R20): 태스크 = 카테고리·프로젝트 색 바탕 + 왼쪽 3px 색 띠(가장 진함), 지원 일정 = 회색 바탕 + 이니셜 배지, 깃발 = 바탕 없이 프로젝트 색 깃발, 개인 일정 = 점선 테두리 + 회색 글자(가장 조용함). 칩 높이 21px, 모서리 5px, 한 줄 말줄임.
- 지원 일정 종류 (R14): 칩 오른쪽 끝 작은 아이콘. 면접 = 사람(보라), 코딩테스트 = `</>`, 과제 마감 = 문서, 지원 마감 = 보내기(이 셋은 흐린 회색). 칸이 좁을 때(회고 패널이 열렸을 때)는 면접 외 아이콘을 숨긴다.
- 칩 순서 (R12, R17): 지원 일정은 배지 → 회사 이름 → 시각, 개인 일정은 시각 → 제목.
- 회사 이름이 없는 지원 카드는 카드 제목과 그 첫 글자로 배지를 만든다 (R12–R13).
- 마우스 올림 (R20): 밝기 +22%, 1px 위로, 아래 그림자, 120ms. 깃발은 회색 바탕만 생긴다.
- 완료 (R10, R16): 완료 태스크는 불투명도 42%(취소선 없음). 끝난 주차 깃발은 채운 깃발 + 체크, 앞으로 올 주차는 테두리만 있는 깃발.
- 잘린 막대 (R9, R27): 잘린 쪽은 모서리를 펴고 칸 끝까지 붙이며 끝 18px에서 옅어진다. 왼쪽이 잘린 태스크 막대는 색 띠 없이 시작한다.
- 달력 칸 (R2, R4–R5): 칩 자리 4줄, 넘치면 4번째 줄이 "+N". 오늘 = 보라 테두리 + 날짜 숫자 보라 원, 지난 날짜 = 살짝 어두운 바탕, 다른 달 = 더 어두운 바탕. 각 달 첫 칸에만 "10월 26", "12월 1"처럼 월을 붙인다.
- +N 목록 (R5): 칸 아래 너비 250px 목록, 칸과 같은 순서. 여러 날 태스크는 오른쪽에 기간을 붙인다.
- 개인 일정 입력 (R23–R24): 칸의 다음 빈 줄에 칩 모양 입력칸. 드래그 범위는 보라 테두리로 묶고 범위 너비 입력 막대를 둔다. 시각은 저장한 뒤 편집 팝오버에서 넣는다.
- 편집 팝오버 (R28–R29): 제목, 날짜 두 칸, 시간(없음/시각 + 시각 칸), [삭제]·[취소]·[저장]. [저장]을 눌러야 반영한다. 기간 일정이면 시간이 "없음"으로 고정. 삭제는 팝오버 아래 빨간 확인 줄에서 한 번 더 누른다.
- 드래그 (R35–R37): 원래 자리는 흐려지고(28%), 끄는 칩은 -1.5° 기울어 떠 있다. 놓일 칸은 옅은 보라 바탕 + 테두리, 칩 자리는 보라 점선. 놓으면 280ms 튀어오름(위로 3px·1.06배 → 1px 눌림 → 제자리). 드래그 안 되는 칩을 끌면 제자리에서 작게 좌우로 흔들린다.
- 달 넘김 (R41): 가로 48px 이동 + 투명도, 220ms ease-out. 요일 머리줄은 고정. [오늘]도 방향에 맞춰 같은 애니메이션, 연속으로 누르면 쌓이지 않고 바로 넘어간다.
- 회고 패널 (R42–R48): 달력 오른쪽 380px, 달력은 좁아지고 고른 칸은 회색 테두리. 타이머 기록 = 카테고리 색 막대(길이는 시간에 비례하지 않음), 일정 = 빈 동그라미 점 + 칩. 자정을 넘긴 기록은 시각 아래 "11/2 23:20부터". 완료한 태스크는 오른쪽에 완료 시각. 빈 상태 = 시계 아이콘 + "이날은 남은 기록이 없어요". [개인 일정 추가]를 누르면 아래가 입력 줄(제목, 없음/시각)로 바뀐다. 내용이 길면 가운데만 스크롤.
