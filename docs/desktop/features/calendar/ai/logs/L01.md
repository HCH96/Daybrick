# L01 · 2026-11-05 · 명세: 첫 명세서 작성

- 요구사항: 전체 (R1–R48)
- 한 일: 사용자 요구사항을 정리하고 두 번 질문해서 애매한 부분을 정한 뒤, 명세서를 묶음별 파일로 나눠 저장했다. 코드에서 확인한 것: 스케줄러는 빈 페이지(`pages.ts`의 placeholder)라 옮길 기능·데이터가 없다. 지원관리에는 로고 데이터가 없다. 단계형 프로젝트 단계에는 날짜가 없다.
- 결정: D1–D6 추가 (드래그는 태스크·개인 일정만, 이니셜 배지, 주차형 일요일 깃발, 지난 날=회고, 홈은 바꾸지 않고 이동 버튼이 가는 곳만 고침)
- 사용자 확인: 완료 (초안 승인)
- 테스트 메모: 메뉴 id를 바꾸면 홈 카드 `linkTo="scheduler"`도 같이 바꿔야 빌드가 된다. 메인 페이지 D1은 캘린더 D1이 대신한다.
