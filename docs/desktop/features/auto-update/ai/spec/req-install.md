# 자동 업데이트 요구사항: 설치·재시작·실패 (R16–R24)

### 타이머 확인
- R16. "설치하고 다시 시작"을 누를 때 투데이 타이머가 돌고 있지 않으면 바로 받기 시작한다.
- R17. 타이머가 돌고 있으면 "타이머가 실행 중이에요. 기록을 저장하고 설치할까요?" 창에 [기록 저장하고 설치] / [나중에 설치]를 보여 준다.
- R18. [기록 저장하고 설치]는 트레이 "종료"와 같은 방식으로 처리한다(today R24, D9). 지금 시각까지 기록하고 타이머를 멈춘다.
- R19. [나중에 설치]는 창만 닫는다. 받아 둔 것도 예약도 없고, 설정의 새 버전 정보와 버튼은 그대로 남는다.

### 받기·설치
- R20. 받는 동안 진행률을 설정에 보여 주고(req-settings.md 화면 구성), 버튼은 비활성이다. 받는 동안에도 앱은 계속 쓸 수 있다. 받는 사이에 타이머를 시작했으면 설치 직전에 R17 창을 한 번 더 띄운다.
- R21. 다 받고 서명 확인까지 끝나면 종료 전 저장(background D3·D4의 `runQuitHandlers`: 각 기능 저장, 동기화 올리기)을 마친 뒤 설치하고 앱을 다시 띄운다. 다시 뜬 앱은 창을 보여 준다.

### 실패
- R22. 받는 도중 끊기거나 실패하면 설치하지 않고 앱은 그대로 둔다. 설정에 "업데이트를 받지 못했어요. 다시 시도해 주세요."를 보여 주고 "주의" 알림을 보낸다. 버튼은 다시 누를 수 있다.
- R23. 서명이 맞지 않으면 설치하지 않고 받은 파일을 버린다. 설정에 "업데이트 파일을 확인하지 못해 설치하지 않았어요."를 보여 주고 "주의" 알림을 보낸다.
- R24. 실패 알림은 합치기 키 하나를 써서 반복되어도 안 읽은 알림 하나로 합친다.
