# 자동 업데이트 데이터

| 항목 | 종류 | 저장 위치 |
|---|---|---|
| 마지막으로 알린 버전 (R7, R14) | 버전 문자열 | 로컬 `app-settings.json` (AppData) |
| 마지막 확인 시각 (R2) | 시각 | 메모리 (켤 때 다시 확인하므로 저장하지 않음) |
| 찾은 새 버전 정보(번호·변경 내용) | 문자열 | 메모리 |
| 공개키 (R27) | 문자열 | `tauri.conf.json` (커밋함) |
| 비밀키·비밀번호 (R28–R29) | 파일·문자열 | 저장소 밖 `~/.tauri/` + 별도 백업 (커밋 금지) |

- 앱 안의 값은 모두 기기별이라 서버로 동기화하지 않는다.
