# 자동 업데이트 범위

## 이번 범위에서 제외
- `npm run release` 스크립트 (다음 단계에서 따로 만든다)
- "이 버전 건너뛰기" (혼자 쓰는 앱이라 필요가 적다. 알림은 버전마다 한 번만 보낸다)
- 묻지 않고 하는 자동 설치, "다음 종료 때 설치"
- 이전 버전으로 되돌리기, 베타 채널
- Windows 외 OS
- 설치파일 코드 서명 인증서 (SmartScreen 경고 없애기)

## 나중에 고려
- server-setup의 "앱을 최신 버전으로 바꿀 때까지 서버 기능은 꺼 둡니다" 안내(`AppUpdateNotice`)에서 바로 업데이트 확인으로 잇기
