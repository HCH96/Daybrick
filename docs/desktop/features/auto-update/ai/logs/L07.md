- 요구사항: R16–R24
- 한 일: `UpdaterProvider`의 `install`을 채웠다. 타이머가 없으면 바로 받고(R16), 있으면 `timer-confirm` 창(R17). [기록 저장하고 설치]는 이번 흐름 동의로 적고 진행, [나중에 설치]·Esc는 창을 닫고 설치 직전이었으면 받은 것을 버린 뒤 `available`로(R19). 받은 뒤 타이머가 돌고 동의 전이면 한 번 더 묻고(R20), 아니면 `installing` → `runQuitHandlers()` → 설치(R21). 받기·설치 실패는 network → `downloadFailed`, signature → `signatureFailed` + 주의 알림(R22, R23).
- `notices.ts`에 `failureNotice(kind)`(제목 = 설정 실패 문구, mergeKey `update-failed`, R24). 새 `components/updater/UpdateDialogs.tsx`를 `TitleBar`의 `BackgroundDialogs` 옆 두 곳에 넣었다.
- `devUpdater.ts`: 흉내 받기·설치를 바꿔 끼우고 콘솔 동작 install·done·fail·badSignature를 더했다.
