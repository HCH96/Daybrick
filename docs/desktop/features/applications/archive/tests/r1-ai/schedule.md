## A7. 다음 일정 계산
- 근거: R6, R24, D12, D16, 목업 추가 제안(D-1·당일 빨강)
- 수행 방법: `schedule.ts`의 `getNextItem` 실행 (기준일 2026-10-23), `NextEventLabel.tsx` 코드 읽기
- 예상 결과:
  - 오늘 이후(오늘 포함) 가장 가까운 일정 하나만 돌려줌, 지난 일정만 있으면 없음
  - "지원 완료" 일정은 상태가 지원 완료일 때만 셈 (D12)
  - 지원 준비 카드는 마감일도 후보("D-n 마감"), 다른 상태는 마감일 제외
  - 📅 옆은 마감일 속성 대신 null을 넘겨 마감일이 나오지 않음 (D16)
  - 같은 날이면 시간 없는 일정이 먼저
  - 남은 일 수 1 이하면 빨강 표시 클래스
- 실제 결과:
  - 지난 면접 + 10/26 코테 + 10/30 면접 → `D-3 코딩테스트`(days 3). 지난 일정만 → null. 당일 → days 0
  - 전형 준비 카드의 10/24 지원 완료 일정 → null, 같은 카드를 지원 완료 상태로 → 일정으로 나옴
  - 지원 준비 + 마감 10/28 → `deadline`, days 5. 마감일 속성 null로 부르면 null. 지원 완료 상태면 마감일 안 나옴
  - 마감 10/28 + 코테 10/25 → 코테가 나옴. 같은 날 14:00 면접과 시간 없는 코테 → 코테가 먼저
  - `NextEventLabel`: `item.days <= 1`이면 `next-event--urgent`, 당일은 "D-day"로 표시
- 판정: 통과 (검사 11개)
