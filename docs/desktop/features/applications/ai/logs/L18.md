# L18 · 2026-10-23 · 명세: 사용자 테스트 r1 반영 (지원 마감·정렬·최대화)

- 요구사항: R5, R8, R13, R21, R24, R25, R33 변경 / R38–R40 추가
- 한 일: 사용자 테스트 r1 메모(3·4·8·12·22번)를 바탕으로 질문 6개에 답을 받고 수정 요구사항을 정리해 승인받음.
  - 마감일·지원일을 기본 속성에서 없앰. 지원 마감은 📅 창의 일정 종류(카드당 하나)로, 지원 완료는 날짜 없이 상태로만 둔다 (R21, R25, R39, R40).
  - 카드 아래쪽 줄 규칙을 상태별로 정함: 지원 준비는 지원 마감 D-day, 지원 완료는 다음 전형 일정 또는 "지원 완료" (R38). 📅 옆도 같은 규칙 (R24).
  - 정렬은 카드에 보이는 날짜 순, 날짜 없는 카드는 맨 뒤 (R5). 달력의 지원 마감은 지원 준비 카드만 (R8).
  - 최대화 시 사이드바 위를 지나가는 움직임 없이 본문 영역만 채우도록 덧붙임 (R13).
- 결정: D12·D16은 이번 변경으로 대체됨. D4·D18 문구를 고침.
- 사용자 확인: 완료 (초안 승인)
- 테스트 메모: 정렬 실패(4번)는 버그가 아니라 기준 차이였음. 마감일 속성은 비어 있고 "과제 마감" 일정만 있어 만든 순으로 놓였다. 기존 저장 파일의 마감일 값 → 지원 마감 일정 옮기기를 확인할 것.
