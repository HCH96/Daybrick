# 지원 관리 요구사항: 속성 (R28–R33)

### 속성
- R28. 속성을 추가·삭제·편집(이름, 종류, 항목)할 수 있다.
- R29. 속성 종류는 텍스트, 숫자, 선택, 다중 선택, 날짜, URL, 체크박스 7가지다.
- R30. 선택·다중 선택의 항목은 쓰면서 추가할 수 있고, 항목마다 색을 직접 고를 수 있다.
- R31. 모든 속성의 기본값은 "없음"이며 빈칸으로 보여준다.
- R32. 날짜 속성은 직접 타이핑하지 않고 작은 달력에서 클릭해 고른다.
- R33. 제목과 상태는 삭제할 수 없다. 나머지 기본 속성은 삭제할 수 있다. (L18에서 변경)
- R40. 기본 속성에서 마감일과 지원일을 없앤다 (지원 마감은 📅 일정으로, 지원일은 저장하지 않음). 지금 있는 데이터는 마감일 값을 지원 마감 일정으로 옮기고, 지원일 값과 "지원 완료" 일정은 지운다.
