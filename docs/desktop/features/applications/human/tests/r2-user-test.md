- 작성: 2026-10-23 (AI 초안). AI 테스트 결과: [../../ai/tests/r2/index.md](../../ai/tests/r2/index.md)
- AI는 앱 화면을 띄워 보지 않았다. 아래 예상 결과는 명세·계획·진행 기록을 근거로 적은 것이다.
- 위에서부터 차례로 진행한다. 앞 항목에서 바꾼 상태를 뒤 항목이 이어서 쓴다.
- 날짜는 "오늘+3일"처럼 테스트하는 날 기준으로 적었다 (U1·U11의 옛 형식 파일만 고정 날짜).

## 준비
1. 앱이 켜져 있으면 끈다.
2. **원래 파일 백업**: `%APPDATA%\com.daybrick.desktop\applications.json`을 다른 곳(예: 바탕화면 `applications-backup.json`)에 복사해 둔다. 14번에서 되돌릴 때 쓴다.
3. **옛 형식 파일 넣기**: AI가 만든 `r2-data/applications.json`(지금은 없음: 테스트 뒤 지워졌다. 이 단계를 다시 하려면 AI에게 v1 카드 3장 파일을 다시 만들어 달라고 한다)을 `%APPDATA%\com.daybrick.desktop\`에 복사해 원래 파일을 덮어쓴다. 이 파일에는 옛 형식(v1) 카드 3개가 들어 있다.
   - **V1 지원준비**: 지원 준비, 마감일 2026-11-05
   - **V1 지원완료**: 지원 완료, 마감일 2026-10-20, 지원일 2026-10-18, "지원 완료" 일정 10/18, 면접 일정 11/10
   - **V1 종료**: 종료, 마감일 2026-10-01, 코딩테스트 일정 10/08
4. `apps/desktop`에서 `npm run tauri dev`로 앱을 켠다. 창은 처음 크기(1200x800)로 둔다. 사이드바 "지원 현황"을 누른다. → 1번을 한다.
5. 1번이 끝나면 테스트용 카드 4개를 "+ 새 지원"으로 만든다 (이 순서대로 만든다. 만든 순서가 정렬에 쓰인다).
   - **카드 A**: 제목 `A 넥슨`, 상태 지원 준비 그대로. 📅 → `지원 마감` → 작은 달력에서 오늘+5일. 우선순위 높음.
   - **카드 B**: 제목 `B 네오플`, 상태 지원 준비 그대로. 📅 → `지원 마감` → 오늘+10일.
   - **카드 C**: 제목 `C 크래프톤`. 상태 배지 → 전형 준비 → 면접 → "면접 날짜를 골라 주세요" 창에서 "나중에 고르기".
   - **카드 D**: 제목 `D 스마일게이트`. 상태 배지 → 지원 완료. 일정 없음.
   - 📅 창 사용법: 상태 배지 옆 📅 버튼 → 위쪽 종류 버튼 하나 → 작은 달력에서 날짜 클릭 → 저장된다. 줄을 누르면 펼쳐져서 시간·메모를 고칠 수 있다.
