- 한 일: L03에서 남긴 페이지 CSS의 고정 `color-mix` 19곳을 정리
  - theme.css 토큰 추가: `--accent-wash`(보라 6%, 오늘 칸), `--accent-drop`(보라 10%, 끌어서 놓일 곳·점선 추가 칸), `--accent-ring`(보라 18%, 입력 포커스 바깥 링), `--scrim-solid`(바탕 92%, 이미지 확대 뒤), `--text-line`(글자색 25%, 오늘 잔디 칸 숨쉬는 테두리)
  - 바꾼 곳: 캘린더(격자·끌기·개인 일정·회고), 지원 관리 캘린더 보기, 플랜(주 달력·끌기·목록·카드 고르기), 프로젝트(단계 칸·잔디), 구직 관리 이미지 확대

  - 프로젝트 단계 칸은 `--sidebar` 바탕 위에 `--accent-drop`을 한 겹(기능용 그라데이션), 잔디 범례는 칸과 같은 `--hc` 계산(범례 `--hc`는 보라 고정)
- 확인: `npm run build` 성공. 미리보기 Calendar에서 오늘 칸이 `--surface` 위에 보라 6%로 겹쳐 예전 색과 같은 것, 토큰 값이 계산되는 것 확인
