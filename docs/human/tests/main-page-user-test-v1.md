- 기능 명세서: [docs/ai/features/main-page.md](../../ai/features/main-page.md)
- AI 테스트 보고서: [docs/ai/tests/main-page-ai-test-v1.md](../../ai/tests/main-page-ai-test-v1.md) (23개 항목 모두 통과)
- 비교할 목업: [docs/human/mockups/main-page.html](../mockups/main-page.html) (아래쪽 "이번 구현에서 실제로 보일 모습") (2026-10-22 목업이 최종 디자인으로 다시 그려져, 이 체크리스트가 말하는 "아래쪽" 구역은 지금 파일에 없다. 비슷한 모습은 `#home-now`)
- 작성일: 2026-10-22 (초안) · 1차, B안·제목 표시줄 이전 화면 기준. 재테스트는 main-page-user-test.md

## 준비
1. 터미널에서 `apps/desktop` 폴더로 이동한다.
2. `npm run tauri dev`를 실행한다.
3. 잠시 뒤 Daybrick 창이 뜨면 테스트를 시작한다. 처음 실행하면 Rust 컴파일 때문에 1~2분 걸릴 수 있다.

> 이번 범위에서 제외된 것(할 일·일정·지원·타이머의 실제 데이터, 로그인, 라이트/다크 전환, 모바일 화면)은 테스트하지 않는다.

### 7. 카드에서 메뉴로 이동
- 근거 요구사항: "카드 제목을 누르거나 버튼을 누르면 해당 메뉴 화면으로 이동한다" / 계획 5단계
- 수행 방법 (각각 끝나면 사이드바 "홈"을 눌러 돌아온다):
  1. "오늘 할 일" 카드 가운데의 [캘린더로 가기] 버튼
  2. "지원 현황" 카드 오른쪽 위의 "지원 현황으로 가기 →"

### 10. 화면 배율이 큰 환경 (해당하는 경우만)

- 수행 방법:
  1. Windows 설정 > 시스템 > 디스플레이 > "배율"이 125% 또는 150%인지 확인한다.
  2. 그렇다면 앱을 켰을 때 창 아래쪽이 작업 표시줄이나 화면 밖으로 잘리는지 본다.
