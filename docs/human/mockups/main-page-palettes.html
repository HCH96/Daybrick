메인 페이지 · 어두운 색 조합 후보

승인된 목업(main-page.html)의 배치는 그대로 두고 색만 바꾼 후보 5개입니다. 정적 화면이고 데이터는 예시 값입니다.
후보마다 왼쪽은 색 목록과 그 색을 쓰는 자리, 오른쪽은 그 색으로 칠한 메인 화면 축소판입니다.
