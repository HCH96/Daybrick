- B를 확인한 뒤 저장소 버전은 0.2.1로 둔다 (다음 릴리즈는 그보다 크게).

## 확인할 결과
- 설치본 0.2.0을 켜고 몇 초 뒤 알림 "새 버전 0.2.1이 나왔어요"가 온다 (R1, R6). 껐다 켜도 알림이 하나 더 생기지 않는다 (R7).
- 알림 → 설정 "앱" 칸, 새 버전 0.2.1·변경 내용·[설치하고 다시 시작] (R8, R13).
- 타이머를 켜고 누르면 확인 창 → [기록 저장하고 설치] → 받는 중 % → 앱이 꺼지고 설치 → 창이 다시 뜬다 (R17, R18, R20, R21). **설치 프로그램이 앱을 다시 띄우는지 이때 확인** (안 뜨면 방법을 다시 정한다).
- 다시 뜬 앱에서 "현재 버전 0.2.1", [업데이트 확인] → "최신 버전이에요" (R4, R12).
- 투데이 기록이 지금 시각까지 남고 타이머는 멈춰 있다 (R18, today D9). 일정·지원·플랜 데이터가 그대로다 (R33).
- 인터넷을 끄고 [업데이트 확인] → 실패 문구, 자동 확인 실패는 아무 표시 없음 (R9, R12).
- 서명 실패는 실제로 만들기 어려우므로 5단계 흉내 확인으로 갈음한다 (테스트에서 따로 판단).
