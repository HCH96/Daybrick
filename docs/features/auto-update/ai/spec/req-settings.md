# 자동 업데이트 요구사항: 설정 화면 (R10–R15)

### 설정 "앱" 칸의 업데이트 줄
- R10. 설정 "앱" 칸에 "업데이트" 줄을 두고 현재 버전을 표시한다.
- R11. "업데이트 확인" 버튼을 누르면 바로 확인한다. 확인하는 동안 버튼은 "확인 중…"으로 비활성이다.
- R12. 확인 결과를 버튼 아래에 문구로 보여 준다. 최신이면 "최신 버전이에요", 실패하면 "업데이트를 확인하지 못했어요. 인터넷 연결을 확인해 주세요."
- R13. 새 버전이 있으면(자동·수동 모두) 새 버전 번호, 변경 내용(latest.json의 notes, 없으면 줄을 생략), "설치하고 다시 시작" 버튼을 보여 준다.
- R14. 수동 확인으로 찾은 버전은 이미 화면에 보이므로 알림을 보내지 않고, R7의 "알린 버전"으로만 적는다.
- R15. 개발 모드에서는 버튼을 비활성으로 두고 "개발 모드에서는 업데이트할 수 없어요"를 보여 준다.

## 화면 구성
백그라운드 실행의 "앱" 칸(자동 시작 스위치) 아래에 둔다.
```
설정 › 앱
  윈도우 시작 시 자동 실행                 [● 켜짐]
  ─────────────────────────────
  업데이트          현재 버전 0.2.0   [업데이트 확인]
  새 버전 0.2.1
  · 변경 내용 한두 줄
                              [설치하고 다시 시작]
  (받는 중 42%  ▓▓▓▓░░░░)
  (결과·실패 문구)
```
