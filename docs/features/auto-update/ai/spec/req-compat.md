# 자동 업데이트 요구사항: 데이터 호환 (R33–R36)

### 데이터 폴더
- R33. 업데이트 뒤에도 `%APPDATA%\com.daybrick.desktop\`의 JSON 파일을 그대로 읽는다. 업데이트는 데이터 폴더를 건드리지 않는다.
- R34. 식별자 `com.daybrick.desktop`는 바꾸지 않는다.

### 앞으로 저장 형식을 바꿀 때
- R35. 저장 형식을 바꿀 때는 아래 규칙을 지킨다 (모든 기능 공통).
  - 필드는 추가만 한다. 새 필드는 파일에 없으면 기본값으로 읽는다.
  - 이름 바꾸기·지우기·뜻 바꾸기가 꼭 필요하면 파일에 형식 버전을 두고, 읽을 때 옛 형식을 새 형식으로 바꾼다. 바꾸기 전 원본은 백업한다.
  - Supabase 표 구조가 바뀌면 server-setup의 서버 구조 갱신 흐름을 따른다.
- R36. 읽지 못한 파일은 지우거나 빈 값으로 덮어쓰지 않는다.
