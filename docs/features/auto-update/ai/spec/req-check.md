# 자동 업데이트 요구사항: 새 버전 확인·알림 (R1–R9)

### 확인
- R1. 설치본은 앱이 켜질 때(자동 시작 포함) 새 버전을 확인한다. 확인은 앱 시작을 늦추지 않도록 화면이 뜬 뒤 뒤에서 한다.
- R2. 앱이 켜져 있는 동안에는 마지막 확인 뒤 24시간마다 한 번 더 확인한다.
- R3. 확인 주소는 `https://github.com/HCH96/Daybrick/releases/latest/download/latest.json` 하나로 고정한다.
- R4. latest.json의 버전이 지금 버전보다 클 때만 새 버전으로 본다. 같거나 작으면 아무것도 하지 않는다.
- R5. 개발 모드(`npm run tauri dev`)에서는 확인하지 않는다. 자동 시작과 같은 기준(`cfg!(debug_assertions)`, background D6)을 쓴다.

### 알림
- R6. 새 버전을 찾으면 알림센터에 "정보" 알림을 보낸다. 제목 "새 버전 0.2.1이 나왔어요", 내용 "설정에서 설치할 수 있어요", 갈 곳은 설정 페이지(`settings`).
- R7. 한 버전의 알림은 한 번만 보낸다. 다시 켜거나 24시간 확인에서 같은 버전을 찾아도 새 알림을 만들지 않는다. 더 새 버전이 나오면 그 버전의 알림을 보내고, 합치기 키(notifications R24)로 아직 안 읽은 이전 버전 알림을 갱신한다.
- R8. 알림을 누르면 설정 페이지 "앱" 칸의 업데이트 줄로 이동한다.

### 실패
- R9. 자동 확인이 실패하면(오프라인, GitHub 응답 없음, latest.json을 읽을 수 없음) 아무것도 표시하지 않고 다음 확인 때 다시 한다. 다른 기능에는 영향이 없다.

| 알림 | 중요도 | 합치기 키 | 누르면 |
|---|---|---|---|
| 새 버전 (R6) | 정보 | 새 버전용 키 하나 | 설정 "앱" 칸 |
| 받기 실패·서명 불일치 (R22–R24) | 주의 | 실패용 키 하나 | 설정 "앱" 칸 |

- 키 이름과 보낸 기능 이름(notifications R26)은 계획 단계에서 정한다.
