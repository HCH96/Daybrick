## 결정 (계획 중 정함, D7–D10)
- 개인 일정은 `calendar.json` `{ version: 1, events }`에 저장한다. Rust `calendar.rs`, `CalendarProvider`는 `PlanProvider` 안 (D7).
- 칸 4줄. 막대 줄 → 시간 있는 것(시간순) → 시간 없는 것(태스크 → 지원 → 깃발 → 개인). 5개 이상인 날은 1–3줄 + "+N", 4번째 줄 막대는 넘친 날에서 끊는다 (D8).
- 시작일을 끝일 뒤로 바꾸면 끝일이 따라오고, 끝일을 시작일 앞으로 고르면 [저장]을 막고 빨간 안내 (D9).
- 드래그는 포인터 이벤트로 직접 만든다. 4px 넘게 움직이면 드래그. 빈 칸에서 시작 = 기간 입력, 칩에서 시작 = 옮기기 (D10).

### 작은 규칙
- 이니셜 배지 색: 회사 이름 해시 → 목업 7색(h1–h7).
- 깃발 누르기: `navigate("projects", projectId)`. 끝난 주차는 `isStageDone`.
- 회고 타이머 기록은 투데이 `daySlices`로 그날 부분만 (R45).
- 패널이 열린 채 오늘·미래 칸을 누르면 패널은 두고 입력칸을 연다.
- 보던 달은 기억하지 않는다 (다시 오면 이번 달).
- 홈 빈 상태 문구는 바꾸지 않는다 (D6).
- 순수 함수(`features/calendar/*.ts`)는 Node로 실행해 확인한다. 테스트 도구는 아직 없다.
