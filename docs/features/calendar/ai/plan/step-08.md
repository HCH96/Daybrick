# 캘린더 8단계: 플랜 연동

- 요구사항: R31–R34
- 목업: 없음 (플랜 화면 쪽 변화). 칩 모양은 `part-chips.html` chips-board의 개인 일정 칩을 그대로 쓴다.
- 경로 기준: [index.md](index.md) 맨 위
- 공통 규칙: D2, D7

## 할 일
- `PersonalLayer` (R31): 플랜 주간 달력의 지원 일정 층 아래, 태스크 막대 층 위에 개인 일정 층. 여러 날은 점선 막대(주 경계 잘림 표시), 하루짜리는 점선 칩(시각 → 제목). 줄 배치는 `monthLayout`의 막대 규칙을 쓴다.
- 칸 어둡게 (R32): 시간 없는 개인 일정(기간 포함)이 덮는 날은 칸 배경을 살짝 어둡게. 시간 있는 일정만 있는 날은 그대로. 태스크 배치는 막지 않는다.
- 누르기 (R33): 캘린더의 `PersonalEditPopover`를 연다. 끌기는 없다(플랜 드래그 대상에 넣지 않음).
- 스위치 (R34): `showApplicationEvents`와 상관없이 항상 그린다.

## 확인할 결과
- `npm run build` 성공.
- 캘린더에 넣은 "예비군(11/10–11/12)"이 플랜 해당 주에 점선 막대로 보이고 세 칸이 살짝 어둡다. "14:00 치과"는 칩만 보이고 칸은 그대로.
- 플랜에서 `지원 일정` 스위치를 꺼도 개인 일정은 보인다.
- 플랜에서 개인 일정을 누르면 같은 편집 팝오버. 제목을 고치면 캘린더에도 반영. 끌어도 움직이지 않는다.
- 어두운 칸에도 태스크를 끌어 놓을 수 있다.
