# 캘린더 결정 사항

- D1. 스케줄러 메뉴를 없애고 캘린더로 대신한다. 메인 페이지 D1("캘린더와 스케줄러를 따로 둔다")을 대신한다. (적용: 이후 전체) (기록: L01)
- D2. 드래그로 옮길 수 있는 것은 태스크와 개인 일정뿐이다. 지원 일정과 체크포인트는 원래 화면에서만 바꾼다. (적용: 이후 전체) (기록: L01)
- D3. 회사 로고는 회사 이름 이니셜 배지로 대신하고, 인터넷 요청을 하지 않는다. (적용: 이후 전체) (기록: L01)
- D4. 체크포인트는 주차형 프로젝트 주차의 일요일에만 꽂는다. (적용: 이후 전체) (기록: L01)
- D5. 지난 날짜를 누르면 회고, 오늘과 미래 날짜를 누르면 입력이다. (적용: 이후 전체) (기록: L01)
- D6. 이번 작업에서 홈 화면은 바꾸지 않는다. 메뉴 id가 바뀌어서 이동 버튼이 가는 곳만 고친다. (적용: 이후 전체) (기록: L01)
