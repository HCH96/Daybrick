# 캘린더 범위

## 이번 범위에서 제외
- 홈 "오늘 일정" 카드 내용 (나중에 홈 작업에서 따로 한다. 이번에는 이동 버튼이 가는 곳만 바꾼다, R7)
- 집중 시간·실행률·카테고리 비율 같은 통계 (나중에 통계 페이지에서), 가장 가까운 일정 D-day 헤더
- 주 보기·하루 보기
- 반복 일정, 개인 일정 알림, 개인 일정 메모
- 투데이 화면에 개인 일정 표시
- 실제 회사 로고 이미지 (이니셜 배지로 대신한다, D3)
- 단계형 프로젝트 체크포인트 (단계에 날짜가 없음)
- 캘린더에서 막대 끝을 끌어 길이 바꾸기 (R38)
