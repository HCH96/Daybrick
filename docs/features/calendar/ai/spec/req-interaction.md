# 캘린더 요구사항: 드래그·달 넘김 (R35–R41)

### 드래그
- R35. 태스크와 개인 일정 칩만 드래그해서 다른 날짜로 옮길 수 있고, 여러 날 일정은 길이를 유지한 채 옮겨진다.
- R36. 지원 일정과 깃발은 드래그되지 않고, 누르기만 할 수 있다(R19).
- R37. 칩을 놓으면 새 자리에서 살짝 튀어오르는 반응을 준다.
- R38. 막대의 길이(시작일·끝일)는 캘린더에서 바꾸지 않는다. 기간은 상세 팝업에서 바꾼다.
- R39. 태스크를 옮기면 플랜의 날짜가 바로 바뀐다. 완료한 태스크도 옮길 수 있다.
- R40. 다른 달로 보이는 앞뒤 날짜 칸에도 놓을 수 있다.

### 달 넘김
- R41. 이전 달·다음 달로 넘기면 넘기는 방향으로 페이지가 넘어가는 애니메이션을 준다. 세부는 목업에서 정한다.
