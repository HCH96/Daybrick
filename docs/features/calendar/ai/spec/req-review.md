# 캘린더 요구사항: 회고 패널 (R42–R48)

### 회고 패널
- R42. 지난 날짜 칸의 빈 곳을 누르면 오른쪽에 회고 패널이 열린다.
- R43. 패널에는 날짜 제목, 그날의 타임라인, 그날 완료한 태스크 목록을 보여준다.
- R44. 타임라인은 투데이 타이머 기록 구간(예: 09:10–10:40 알고리즘)을 시간순으로 놓고, 그날의 개인 일정과 지원 일정을 시각에 맞춰 끼워 넣는다. 시각이 없는 일정은 맨 위 "하루 종일" 줄에 둔다.
- R45. 자정을 넘긴 기록 구간은 그날에 속한 부분만 보여준다.
- R46. 완료한 태스크는 완료 시각(`completedAt`)이 그날인 태스크다.
- R47. 합계나 비율 같은 통계는 넣지 않고, 기록이 없으면 빈 상태 문구를 보여준다.
- R48. 패널은 X나 Esc로 닫는다. 다른 지난 날짜를 누르면 그 날짜로 바뀌고, 패널 아래 [개인 일정 추가] 버튼으로 그날 일정을 넣을 수 있다.
