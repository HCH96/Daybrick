# 캘린더 요구사항: 플랜 연동 (R31–R34)

### 플랜 연동
- R31. 플랜 주간 달력에도 개인 일정을 캘린더와 같은 조용한 칩·막대로 보여준다.
- R32. 하루 종일 개인 일정(기간 일정 포함)이 있는 날은 플랜 달력 칸 배경을 살짝 어둡게 한다.
- R33. 플랜에서는 개인 일정을 끌어 옮길 수 없고, 누르면 캘린더와 같은 편집 팝오버가 열린다.
- R34. 개인 일정은 플랜의 `지원 일정` 스위치와 상관없이 항상 보인다.

- 칸을 어둡게 하는 목적은 "그날은 바쁘다"는 신호로, 태스크를 너무 많이 배치하지 않게 하는 것이다. 배치를 막지는 않는다.
- 시간이 있는 개인 일정은 칩만 보이고 칸을 어둡게 하지 않는다.
