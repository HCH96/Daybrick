# L14 · 2026-11-05 · 수정: r1 A14 달력 CSS 섞임

- 요구사항: R2, R4 (칸 모양), 지원관리 달력 모양 유지
- 한 일: r1 AI 테스트 A14 실패를 고쳤다. 캘린더 Grid.css의 `.cal-week`·`.cal-day*`·`.cal-week-more` 규칙을 `:where(.cal-grid)` 안으로 묶었다.
- 한 일: 지원관리 CalendarView.css에 남은 전역 선택자를 묶었다. `.cal`·`.cal-bar*`·`.cal-legend*`·`.cal-more`는 `:where(.cal-view)`, `.cal-ev*`는 더보기 팝오버가 body로 나가므로 `:where(.cal-view, .cal-more-pop)`, `.cal-more-pop`은 `:where(.popover)`, `.cal-more-pop__date`는 `:where(.cal-more-pop)` 안으로 묶었다.
- 한 일: `:where()`는 우선순위를 더하지 않으므로 다른 CSS와의 우선순위는 그대로다. 캘린더 +N 목록(`.cal-day-list`)은 팝오버라 묶지 않았다.
- 계획과 달라진 점: 사용자 승인("지금 고침")으로 r1 사용자 테스트 전에 고쳤다.
- 확인: `npm run build` 성공 (청크 500kB 경고 그대로). 빌드된 CSS에 남은 전역 칸 규칙은 새 캘린더 전용 상태 클래스(`--drop`·`--review`·`--sel*`·`--pin`, `.cal-pin`)뿐이고 지원관리 달력은 이 클래스를 쓰지 않는다. 화면은 보지 않았다.
- 사용자 확인: 대기 (r1 체크리스트 2번에 지원관리 달력·더보기 목록 확인을 더함)
