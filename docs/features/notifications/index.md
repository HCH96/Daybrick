# 알림 (notifications)
앱 전체가 함께 쓰는 알림 센터. 제목 표시줄 종 아이콘과 빨간 숫자 배지, 화면 이동 없이 펼쳐지는 목록, 체크로 확인, 서버 알림 받기.

- 상태: 명세·목업 완료
- 선행 기능: server-setup (서버 알림만)
- 이 기능을 먼저 쓰는 기능: job-search
