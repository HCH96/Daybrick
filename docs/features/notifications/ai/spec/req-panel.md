# 알림 요구사항: 펼침 목록 (R6–R20)

### 열고 닫기
- R6. 아이콘을 누르면 화면은 그대로 두고 아이콘 아래로 목록 패널이 펼쳐진다. 아이콘을 다시 누르면 닫힌다.
- R7. 패널 바깥을 누르거나 Esc를 누르면 패널이 닫힌다.
- R8. 패널 너비는 360px, 높이는 최대 창 높이의 70%이다. 넘치면 패널 안에서만 스크롤된다.

### 목록
- R9. 패널 위쪽에 제목 "알림", 필터 [전체 | 안 읽음], [모두 확인] 버튼을 둔다.
- R10. 목록은 최근 50개까지 최신순으로 보여준다.
- R11. 알림마다 중요도 아이콘, 보낸 기능 이름, 제목, 내용 한 줄(길면 말줄임), 시각, 확인 버튼을 보여준다.
- R12. 시각은 "방금", "5분 전", "3시간 전", "어제", "10월 20일"처럼 상대 시각으로 표시한다.
- R13. 안 읽은 알림은 진하게 표시하고, 확인한 알림은 목록에 흐리게 남긴다.

### 확인
- R14. 확인 버튼(✓)을 누르면 확인 처리한다. 배지가 줄고 패널은 열린 채로 있다.
- R15. 확인한 알림의 같은 자리 버튼(↺)을 누르면 다시 안 읽음으로 되돌린다.
- R16. 알림 본문을 누르면 확인 처리하고, 갈 곳이 있으면 그 화면(탭·팝업)으로 이동한 뒤 패널을 닫는다. 갈 곳이 없으면 확인 처리만 한다.
- R17. 갈 곳의 화면이 아직 없거나 열 수 없으면 이동하지 않고 확인 처리만 한다.
- R18. [모두 확인]은 목록 밖의 것까지 안 읽은 알림 전체를 확인 처리한다. 안 읽은 알림이 없으면 비활성으로 둔다.
- R19. "안 읽음" 필터에서 확인한 알림은 패널을 닫기 전까지 흐리게 남아 있다가, 다시 열면 빠진다.
- R20. 알림이 없으면 "새 알림이 없습니다", 안 읽음 필터에서 없으면 "안 읽은 알림이 없습니다"를 보여준다. 패널이 열려 있는 동안 새 알림이 오면 맨 위에 추가한다.

```
│          │                        │ [전체|안 읽음]   [모두 확인] │  R9
│          │                        ├────────────────────────────┤
│          │                        │ ⚠ 구직 관리 · 방금        ✓ │ ← 안 읽음(진하게)
│          │                        │   수집 실패: 게임잡         │
│          │                        │   페이지 구조가 바뀌었…     │
│          │                        ├────────────────────────────┤
│          │                        │ ● 구직 관리 · 3시간 전    ✓ │
│          │                        │   새 추천 공고 5개          │

│          │                        └──────── (패널 안 스크롤) ──┘
```
