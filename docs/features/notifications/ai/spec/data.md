# 알림: 다룰 데이터

| 데이터 | 주요 항목 | 저장 위치 |
|---|---|---|
| 로컬 알림 | id, 보낸 기능, 종류, 중요도, 제목, 내용, 갈 곳, 합치기 키, 만든 시각, 갱신 시각, 확인 시각 | PC 앱 로컬 데이터 (지원 관리와 같은 방식, 계획 단계에서 확정) |
| 서버 알림 | 로컬 알림 항목 + `user_id` | Supabase `notifications` 테이블 (RLS) |
| 서버 알림 사본 | 마지막으로 받은 서버 알림 | PC 앱 로컬 데이터 |
| 보내지 못한 확인 기록 | 서버 알림 id, 확인/되돌림, 시각 | PC 앱 로컬 데이터 |
| 목록 필터 | 전체 / 안 읽음 | 저장 안 함 (열 때마다 "전체") |

- 확인 여부는 "확인 시각"이 있는지로 판단한다 (없으면 안 읽음).
- 갈 곳: 페이지 id + 탭·팝업 이름 (R25).
