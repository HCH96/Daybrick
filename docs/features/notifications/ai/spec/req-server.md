# 알림 요구사항: 서버 알림 받기·확인 기록 (R29–R36)

### 서버 알림 받기
- R29. 서버 작업(수집, 메일 확인 등)은 서버의 알림 테이블에 R22와 같은 항목으로 알림을 쓰고, 합치기도 R24 규칙을 따른다.
- R30. 앱을 켰을 때 서버 상태가 "연결됨"이면 최근 30일의 서버 알림을 받아 와서 로컬 알림과 합쳐 보여준다.
- R31. 앱이 켜져 있는 동안 서버 알림이 새로 생기거나 바뀌면 Supabase 실시간으로 바로 받아 반영한다.
- R32. 실시간 연결이 끊겼다가 다시 이어지면, 끊긴 동안 빠진 알림을 다시 받아 온다.

### 확인 기록·오프라인
- R33. 서버 알림을 확인하거나 되돌리면 그 상태를 서버에 기록한다. 기록에 실패하면 로컬에 기억해 두고 다음에 연결될 때 반영한다.
- R34. 마지막으로 받은 서버 알림은 로컬에 보관해 두고, 서버에 접속할 수 없을 때도 목록에 보여준다.
- R35. 서버 연결 상태 문제(로그인 필요, 일시정지, 접속 불가 등)는 알림을 만들지 않고 server-setup의 안내 띠(server-setup R40–R41)로만 보여준다.

### 서버 구조
- R36. 서버 알림 테이블은 server-setup R27 규칙에 따라 새 번호의 서버 구조 단계로 추가하고, 로그인한 주인만 읽고 쓸 수 있게 한다(RLS).
