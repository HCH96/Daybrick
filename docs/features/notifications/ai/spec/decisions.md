# 알림: 결정 사항

- D1. 푸시 알림·OS 알림은 쓰지 않고 앱 안 알림 센터만 쓴다. (적용: 이후 전체) (기록: L01)
- D2. 확인은 체크 버튼을 누르거나 알림을 눌러 이동할 때만 하고, 패널을 펼치기만 해서는 확인하지 않는다. 확인한 알림은 흐리게 남긴다. (적용: 이후 전체) (기록: L01)
- D3. 앱이 만든 알림은 로컬에, 서버 작업이 만든 알림은 서버 테이블에 두고 목록에서 합쳐 보여준다. 서버 알림의 확인 여부는 서버에 기록한다. (적용: 이후 전체) (기록: L01)
- D4. 서버 알림은 앱을 켤 때 받아 오고, 켜져 있는 동안은 실시간으로 받는다. (적용: 이후 전체) (기록: L01)
- D5. 확인한 알림은 30일 뒤 지우고, 목록은 최근 50개까지 보여준다. 안 읽은 알림은 지우지 않는다. (적용: 이후 전체) (기록: L01)
- D6. 같은 합치기 키의 안 읽은 알림이 있으면 새로 만들지 않고 갱신한다. (적용: 이후 전체) (기록: L01)
- D7. 서버 연결 상태 문제는 알림이 아니라 server-setup 안내 띠로만 보여준다. (적용: 이후 전체) (기록: L01)
