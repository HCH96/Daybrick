# 알림: 목업에서 정한 것

## 목업
- 경로: [human/mockups/index.html](../../human/mockups/index.html) (2026-10-26 승인, 화면별 파일로 나눔)
- 화면: 1. 종 아이콘·배지, 2. 펼친 목록(앱 창 위), 3. 목록 상태(안 읽음 필터·모두 확인 뒤·빈 목록 2가지)
- 화면 배치와 스타일은 이 목업을 기준으로 구현한다. 색과 앱 창 틀은 메인 페이지 목업의 값을 그대로 쓴다.

### 목업에서 정한 것
| 항목 | 결정 |
|---|---|
| 종 아이콘 | 제목 표시줄의 다른 버튼과 같은 30px 칸, 16px 회색 선 아이콘. 최소화 버튼 바로 왼쪽, 오른쪽 여백 4px |
| 배지 | 아이콘 오른쪽 위, 높이 16px 알약 모양(숫자가 길면 옆으로 늘어남), 진한 빨강 `#F0524F` + 흰 글자 10px 굵게, 제목 표시줄 색 테두리 2px |
| 패널 위치·모양 | 종 아이콘 바로 아래, 오른쪽 끝을 종 오른쪽에 맞춤. 360px, 최대 630px(창 높이 70%), 표면색 바탕 + 둥근 모서리 12px + 진한 그림자, 화면은 어둡게 덮지 않음 |
| 패널 머리 | 1줄: 제목 "알림"(15px 굵게). 2줄: 왼쪽 [전체 \| 안 읽음] 칸 나눔 버튼, 오른쪽 [모두 확인] 보라 글자 버튼(두 겹 체크 아이콘) |
| 알림 행 | 왼쪽 18px 칸에 중요도 표시, 가운데 3줄(보낸 기능 · 상대 시각 11px / 제목 13px / 내용 12px 회색, 제목·내용은 한 줄 말줄임), 오른쪽 28px 버튼 칸. 행 사이 구분선 |
| 중요도 | 주의 = 주황 `#F0B860` 경고 삼각형, 정보 = 회색 점 8px |
| 안 읽음·확인함 | 안 읽음: 제목 굵게, 보낸 기능 이름 밝게. 확인함: 왼쪽 표시와 글을 45%로 흐리게, 버튼은 흐리지 않음 |
| 확인 버튼 | 안 읽음 ✓, 확인함 ↺, 같은 자리. 평소 회색 아이콘만 |
| 비활성 [모두 확인] | 회색 글자로 흐리게 |
| 빈 상태 | 패널 가운데 회색 아이콘 상자(44px) + 문구. 전체 = 종 아이콘 "새 알림이 없습니다", 안 읽음 = 체크 아이콘 "안 읽은 알림이 없습니다" |
| 스크롤 | 머리는 고정, 목록만 패널 안에서 스크롤. 얇은 회색 스크롤 막대 |

### 목업에 넣은 추가 제안 (목업과 함께 승인)
- 패널 제목 옆에 "안 읽음 3"처럼 안 읽은 개수를 작게 표시 (0개면 숨김)
- 패널이 열린 동안 종 버튼 배경을 밝게 해서 열림 상태 표시
- 알림 행에 마우스를 올리면 행 배경이 살짝 밝아지고 확인 버튼이 보라색 바탕으로 바뀜
