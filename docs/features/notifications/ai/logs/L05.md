- 요구사항: R1–R5
- 한 일: `TitleBarIcons.tsx`에 16px `BellIcon`(목업 i-bell 모양)을 추가하고, `components/notifications/NotificationBell.tsx`(+css)를 만들었다. 종 버튼은 `.titlebar__button` 클래스를 함께 써서 hover·focus가 같고, `useNotifications().unreadCount`로 배지를 그린다 (0이면 숨김, 100 이상 `99+`). `TitleBar.tsx`의 두 모양(사이드바 있는 화면, 단순 버전) 모두 `WindowControls` 바로 왼쪽에 넣었다. `theme.css`에 `--badge`·`--on-badge`를 추가했다. 누르는 동작은 없다 (3단계).

- 계획과 달라진 점: 오른쪽 여백 4px는 `TitleBar.css`가 아니라 `NotificationBell.css`의 `.notification-bell`에 두었다. `TitleBar.css`는 고치지 않았다 (자동 진행 중 판단).
- 확인: `npm run build`(타입 검사 포함) 성공. Rust는 고치지 않았다.
