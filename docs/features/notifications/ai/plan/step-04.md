# 알림 4단계: 확인·필터·모두 확인

- 요구사항: R14, R15, R18, R19, R20(열린 채 새 알림 추가)
- 목업: panel-states.html (states-unread, states-all-read)
- 경로 기준: `apps/desktop/src/`
- 공통 규칙: [index.md](index.md)의 결정·작은 규칙

## 할 일
- ✓ 버튼을 누르면 확인 처리하고(R14), ↺ 버튼을 누르면 안 읽음으로 되돌린다(R15). 버튼을 누르는 것이 행 본문 클릭으로 이어지지 않게 하고, 패널은 열린 채로 둔다.
- [전체 | 안 읽음] 필터를 연결한다. 패널을 열 때마다 "전체"로 시작하고 저장하지 않는다.
- "안 읽음" 필터: 패널이 열려 있는 동안 확인한 알림 id를 패널 상태에 기억해 두고, 흐리게 남겨 둔다. 패널을 닫으면 기억을 비운다 (R19).
- [모두 확인]은 목록 밖의 것까지 저장된 안 읽은 알림 전체를 확인 처리한다. 안 읽은 알림이 0개면 회색으로 비활성 (R18).
- 패널이 열린 동안 새 알림이 오면 맨 위에 나타난다 (R20). 상태에서 바로 그리면 된다.
- 서버 알림의 확인 기록은 8단계에서 한다. 이번에는 로컬 상태만 바꾼다.

## 확인할 결과
- ✓를 누르면 배지가 1 줄고 행이 흐려지며 버튼이 ↺로 바뀐다. ↺를 누르면 원래대로 돌아온다. 패널은 계속 열려 있다.
- 안 읽음 필터에서 ✓를 누르면 그 행이 흐리게 남고, 패널을 닫았다 다시 열고 안 읽음을 고르면 빠져 있다.
- 안 읽은 알림이 60개일 때 [모두 확인]을 누르면 배지가 사라지고 버튼이 비활성이 된다.
- 안 읽음 필터에 남은 알림이 없으면 "안 읽은 알림이 없습니다"가 보인다.
- 패널을 연 채로 콘솔에서 알림을 보내면 맨 위에 나타난다.
- `npm run build`가 성공한다.
