## 이번 회차 범위
- 대상 R: R10 (같은 시각 정렬), R19 (안 읽음 탭에서 확인하면 바로 빼기)
- 영향받는 R: R14, R16, R18, R20, R24
- 다시 하는 이전 항목: r1 빠른 4번(정렬) → 1번, r1 빠른 6번(안 읽음 탭 변경 요청) → 4번
- 하지 않는 것: r1 빠른 12번(서버에 못 닿을 때). 와이파이·이더넷을 끊는 테스트는 하지 않기로 함 (2026-10-27 사용자 결정)

## 준비
1. 앱을 끈 상태에서 `%APPDATA%\com.daybrick.desktop\notifications.json`을 다른 곳에 백업한 뒤 지운다. **이전 테스트에서 시각이 겹친 알림이 남아 있으면 순서가 틀리게 보이므로 반드시 지우고 시작한다.**
2. `apps/desktop`에서 `npm run tauri dev`로 켜고, 앱 창에서 F12로 콘솔을 연다. 콘솔을 누를 때 패널이 닫히면 개발자 도구를 별도 창으로 띄운다.
3. 콘솔에 붙여 넣는다 (앱을 다시 켜면 다시 붙인다).
   ```js
   const N = (o = {}) => daybrickNotify({ source: "applications", kind: "test", importance: "info", title: "테스트 알림", body: "내용", ...o });
   const many = (n) => { for (let i = 1; i <= n; i++) N({ title: `알림 ${i}` }); };
   const setA = () => { N({ title: "가" }); N({ title: "나" }); N({ title: "다" }); };
   ```
4. "0개로 되돌리기" = 앱을 끄고 `notifications.json`을 지운 뒤 다시 켜서 3번을 다시 붙인다.
5. "세트 A" = 0개에서 `setA()`. 목록은 위에서부터 "다", "나", "가", 배지 `3`.
