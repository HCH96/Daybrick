진행 트랙
  • 깃발은 단계 시작점에 같은 간격, 끝에 체크무늬 결승 깃발 (R22).
  • 끝난 단계 깃발은 색이 차고 펄럭이며 체크 표시, 나머지는 회색으로 늘어진 깃발 (R24).
  • 캐릭터 위치 = 1(기획) + 2/6 = 1.33 → 트랙의 33% (R23).
단계 영역
  • 가로 칸으로 나란히 두고, 현재 단계 칸에 프로젝트 색 테두리와 "현재" 표시.
  • 머리: 이름 · 완료/전체(모두 끝나면 초록) · + 버튼 (R30).
  • 완료 태스크는 "완료 N" 줄 아래로 모인다 (R31). 칸 안이 넘치면 칸 안에서 세로로 넘긴다.
태스크 줄
  • 상태 표시·제목·기간 또는 "날짜 없음"·체크리스트 진행도. 휴지통은 마우스를 올린 줄에만 (R31, R33).
  • 폴리싱 칸 맨 아래: + 를 눌러 바로 적는 입력 줄. Enter 뒤에도 새 입력 줄이 이어진다 (R32).
  • 태스크를 다른 칸으로 끌면 그 단계로 옮겨진다 (R34, 모양은 플랜 끌기와 같음).
