# 프로젝트 요구사항: 상세 화면 (R21–R34)

### 진행 상황
- R21. 위쪽에 프로젝트 색·이름·종류와 진행 트랙, 그 옆에 마지막 작업일·모닥불·누적 시간을 둔다.
- R22. 트랙에는 단계마다 깃발을 같은 간격으로 꽂고 끝에 결승선을 둔다.
- R23. 캐릭터 위치 = 앞에서부터 이어서 끝난 단계 수 + 그다음 단계 안의 완료 태스크 비율이다.
- R24. 끝난 단계의 깃발은 모양이 바뀌고(순서와 상관없이), 캐릭터는 위치가 바뀌면 그 자리까지 달려간다.
- R25. 프로젝트가 완료되면 골인 연출을 한 번 보여준다 (상세를 보고 있으면 바로, 아니면 완료 뒤 처음 열 때).
- R26. 마지막 작업일은 그 프로젝트 태스크에 시간 기록이 있는 마지막 날로, "오늘 / 어제 / N일 전"으로 보여주고 기록이 없으면 "아직 없음"이다.
- R27. 모닥불은 오늘 작업했으면 활활 타고, 안 건드린 날이 길어질수록 사그라든다 (단계는 visual.md).
- R28. 누적 투입 시간은 애니메이션 없이 숫자로만 보여주고, 실행 중인 타이머 시간도 실시간으로 더한다.

### 단계별 태스크 관리
- R29. 아래쪽에 단계별 영역을 순서대로 둔다. 주차형은 주차마다 기간(예: 11/3–11/9)을 쓰고 이번 주에 표시를 한다. 배치(가로 칸/세로 줄)는 목업에서 정한다.
- R30. 단계 영역 머리에 이름, 완료 개수/전체(예: 3/5), `+` 버튼을 둔다.
- R31. 단계 안 태스크 줄은 플랜 목록과 같은 모양(상태 표시·제목·기간 또는 "날짜 없음"·체크리스트 진행도)이고, 완료한 태스크는 아래에 모인다.
- R32. `+`를 누르면 그 단계에 새 태스크 제목을 바로 적고(날짜 없음·시작 전), 만든 뒤에도 이어서 적을 수 있다.
- R33. 상태 표시 누르기(시작 전→진행 중→완료), 줄 누르면 플랜 상세 팝업(메모를 개발일지로 사용), 휴지통 버튼은 플랜과 같다.
- R34. 태스크를 끌어 다른 단계에 놓으면 그 단계로 옮겨진다.
