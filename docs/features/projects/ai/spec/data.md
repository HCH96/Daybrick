# 프로젝트: 다룰 데이터

| 데이터 | 항목 | 저장 위치 |
|---|---|---|
| 프로젝트 | id(무작위 고유값), 이름, 색, 종류(주차형/단계형), 순서, (주차형) 시작 주, 골인 연출을 본 시각(R25) | PC 안 JSON. 플랜 공용 저장소에 함께 둘지는 구현 계획에서 정한다 |
| 단계 | id, 프로젝트 id, 이름(주차형은 없을 수 있음), 순서. 주차형 기간은 시작 주 + 순서로 계산한다 | 프로젝트와 같은 곳 |
| 태스크 (플랜 것) | **단계 id를 더한다.** 카테고리 id와 동시에 갖지 않는다 (D2) | 플랜 저장소. 플랜 공용 함수로 읽고 쓴다 |
| 시간 기록 (투데이 것) | 읽기만 한다. 태스크 id → 단계 → 프로젝트로 묶는다 | 투데이 저장소 |
| 실행 중 타이머 (투데이 것) | 읽기만 한다 (R28, R43, R44) | 투데이 공용 타이머 저장소 |
| 화면 설정 | 플랜 트리에서 직접 접고 편 단계(R47), 완료 묶음 펼침(R6) | PC 안 JSON |

- 진행률, 끝난 단계, 현재 단계, 프로젝트 완료 여부, 마지막 작업일, 누적·주간 시간은 저장하지 않고 계산한다 (D3).
- 단계 id가 생기면서 기존 태스크 저장 파일을 옮길 필요가 있는지는 구현 계획에서 정한다 (없는 값은 "프로젝트 아님"으로 읽으면 옮기지 않아도 된다).
