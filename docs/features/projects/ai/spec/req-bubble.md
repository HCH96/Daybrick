# 프로젝트 요구사항: 주간 투입 버블 그래프 (R35–R44)

### 주간 투입 버블 그래프
사용자 시안 bubble.html을 그대로 따른다 (값은 visual.md). 시안의 "타이머 멈추기" 버튼과 가짜 시간 증가(setInterval)는 넣지 않고 실제 타이머 기록과 연동한다.

- R35. 진행 중인 프로젝트마다 원 하나를 프로젝트 색으로 그리고, 이번 주(월~일) 투입 시간을 쓴다.
- R36. 원의 넓이는 이번 주 시간에 비례한다 (반지름은 시간의 제곱근).
- R37. 원 안에는 모든 원이 똑같이 이번 주 전체 대비 퍼센트만 쓰고, 글자 크기는 원 크기에 맞춘다.
- R38. 오른쪽 아래 범례에 색 점·이름·시간을 배경·테두리 없이 글자만 띄우고, 시간 많은 순으로 정렬하며 순서가 바뀌면 부드럽게 자리를 옮긴다.
- R39. 원은 가운데로 모이지 않고 화면 안을 떠다니다가 벽이나 다른 원에 부딪히면 튕긴다.
- R40. 원을 마우스로 끌 수 있고, 놓으면 끌던 방향으로 날아간 뒤 다시 떠다닌다.
- R41. 원은 범례를 피하지 않고 위로 지나가며, 겹치는 동안 반투명해져 밑의 글자가 비친다.
- R42. 이번 주 0분인 프로젝트는 원·범례 모두 숨기고, 처음 기록이 생기면 원이 나타난다. 모두 0분이면 "이번 주 기록 없음" 안내를 보여준다.
- R43. 실제 타이머가 어떤 프로젝트의 태스크로 돌고 있으면, 그 원은 갱신 때마다 통통 튀듯 커지며 옆 원을 밀어내고 퍼센트와 범례 시간도 실시간으로 바뀐다.
- R44. 위쪽 "○○ 타이머 진행 중" 표시는 실제 타이머가 실행 중일 때만 보여준다 (일시정지·멈춤이면 숨김).

- 실제 시간은 천천히 늘어 원 변화가 작다. 갱신 간격은 구현 계획에서 정하고, 커질 때는 시안처럼 튀는 연출을 쓴다.
