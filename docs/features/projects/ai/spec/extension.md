# 프로젝트: 확장 구조
플랜·투데이 코드와 이어 붙일 때, 그리고 나중 기능(홈 카드, 공유 웹)이 프로젝트를 쓸 때 읽는다.

- 프로젝트·단계는 플랜 태스크처럼 화면과 떨어진 공용 저장소에서 다루고, 플랜·투데이·프로젝트 화면이 같은 함수("프로젝트 목록", "단계별 태스크", "현재 단계", "진행률")를 쓴다.
- 태스크가 속한 묶음(카테고리 또는 프로젝트 단계)의 이름·색을 돌려주는 공용 함수 하나를 두어, 투데이 카드·오늘 요약이 둘을 구분하지 않고 쓴다 (R53).
- 주차 기간은 플랜의 공용 주 계산(월요일 시작, ISO 주)을 쓴다.
- 시간 합계(누적·이번 주·마지막 작업일)는 투데이의 시간 기록과 공용 타이머 저장소에서 계산하고, 실행 중 타이머 구간도 포함한다.
- 구체적인 파일 위치와 함수 이름은 구현 계획에서 정한다.
