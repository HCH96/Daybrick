# 프로젝트: 연출 값과 목업 후보

## 버블 그래프 (bubble.html 시안 값)
| 항목 | 값 |
|---|---|
| 그리는 영역 | 목록 윗줄 오른쪽 40% 판 안 (목업에서 변경. 시안은 640×320 비율·너비 100%). 목업은 440×200 좌표 |
| 반지름 | 시간의 제곱근 비례. 시안은 900분 = 88. 실제 시간이 커도 화면에 맞도록 기준은 구현 계획에서 정한다. 목업은 400분 ≈ 반지름 50 |
| 원 안 글자 | 흰색, 굵기 500, 크기 = 반지름/2.6 (12~30 사이) |
| 충돌 | 반지름 + 4, 세기 0.7, 반복 2 |
| 가운데 끌림 | x 45%·y 50% 쪽으로 세기 0.003 (모이지 않을 만큼 약하게) |
| 떠다니기 | 방향을 매번 ±0.125 무작위로 틀고 힘 0.06, 최고 속도 0.9, 감속 0.08, 멈추지 않음(alphaDecay 0) |
| 벽 | 벽에 닿으면 반대 방향으로 튕김 |
| 끌기 | 끄는 동안 위치 고정, 놓으면 마지막 움직임 방향으로 날아감 |
| 범례 겹침 | 겹치면 투명도 0.35까지 서서히(0.12씩) 바뀜 |
| 범례 | 오른쪽 아래 여백 6, 줄 간격 20, 색 점 반지름 4, 이름 12px, 시간 11px(숫자 폭 고정) (좁아진 판에 맞춰 목업에서 줄임) |
| 재정렬 | 600ms, easeCubicInOut |
| 커질 때 | 700ms, easeBackOut(overshoot 2), 충돌 반지름도 함께 갱신 |
| 진행 중 표시 | 빨간 점 6px, 1.4초 깜빡임 |
| 시간 글자 | "N시간 M분" / "N시간" / "M분" |

## 최근 활동 잔디 (목업에서 정함, R54–R59)
| 항목 | 값 |
|---|---|
| 칸 | 16주 × 7일(월요일 위), 칸 16px·간격 4px·모서리 4px, 앞으로 올 날은 비움 |
| 진하기 | 0분 / 1시간 미만 / 2시간 미만 / 4시간 미만 / 4시간 이상 → 바탕색, 강조색 28%·52%·78%·100% |
| 오늘 칸 | 흰 테두리 2px. 타이머 중이면 2.4초 주기로 강조색 빛 번짐(숨쉬기) |
| 진하기가 오를 때 | 칸이 1.5배로 튀었다 0.9 → 1.06 → 1로 돌아오며 새 색 (약 0.7초, 버블 커질 때와 같은 느낌) |
| 연속 작업 불 | 1–2일 작은 불, 3–6일 보통, 7일 이상 활활, 0일 장작만. 1.8초 주기로 살짝 일렁임. 오늘 기록 전이면 1.1초 주기로 약하게 깜빡임 |
| 프로젝트로 거르기 | 칠하는 색을 그 프로젝트 색으로 바꾸고 같은 진하기 단계를 쓴다. 다른 원은 투명도 0.3, 거른 원은 흰 테두리 |
| 칸 말풍선 | 날짜(요일)·합계, 프로젝트별 색 점·이름·시간·비율 막대. 그날 한 프로젝트 원은 테두리가 1.4초 주기로 반짝임 |
