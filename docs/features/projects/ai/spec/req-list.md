# 프로젝트 요구사항: 목록 화면 (R1–R8, R54–R59)

### 목록 화면
- R1. 사이드바 Plan 바로 아래에 `Projects` 메뉴를 넣고, 화면 제목은 "프로젝트"로 한다.
- R2. 목록 화면 위쪽 줄은 왼쪽 60%에 최근 활동 잔디(R54–R59), 오른쪽 40%에 이번 주 투입 버블 그래프(R35–R44)를 두고, 그 아래에 진행 중인 프로젝트 카드가 나열된다. (목업에서 변경, L02)
- R3. 카드에는 프로젝트 색·이름·종류, 작은 진행 트랙(또는 진행률), 마지막 작업일과 작은 모닥불, 누적 시간을 보여준다. 정확한 모양은 목업에서 정한다.
- R4. 카드를 누르면 상세 화면이 열리고, 뒤로 버튼(앱 공용 뒤로가기 포함)으로 목록에 돌아온다.
- R5. `+ 프로젝트 만들기` 버튼으로 새 프로젝트를 만든다 (R9–R12).
- R6. 완료된 프로젝트는 목록 아래 "완료 N개" 접힌 묶음에 모이고, 누르면 펼쳐진다.
- R7. 진행 중인 카드는 끌어서 순서를 바꾸고, 플랜 트리도 이 순서를 따른다.
- R8. 카드의 `…` 메뉴로 이름·색을 고치고 프로젝트를 지운다 (R19).

### 최근 활동 잔디 (목업에서 추가, L02)
"작업한 날"은 프로젝트 태스크에 시간 기록이 1분이라도 있는 날이다 (R26 마지막 작업일과 같은 기준, D4). 값은 visual.md.
- R54. 최근 16주(이번 주 포함, 월요일 시작)를 하루 한 칸으로 깔고, 그날 모든 프로젝트 태스크의 시간 합계로 진하기 5단계(없음 / 1시간 미만 / 2시간 미만 / 4시간 미만 / 4시간 이상)를 칠한다. 오늘 칸은 테두리로 표시하고, 앞으로 올 날은 비운다.
- R55. 잔디 오른쪽에 연속 작업일과 최장 연속, 최근 4주 작업한 날(N / 28일), 오늘 투입 시간을 보여준다. 오늘 시간에는 실행 중 타이머 시간도 실시간으로 더한다.
- R56. 실제 타이머가 프로젝트 태스크로 돌고 있으면 오늘 칸이 숨 쉬듯 빛나고, 오늘 시간이 다음 진하기 경계를 넘는 순간 칸이 통통 튀며 진해진다.
- R57. 연속 작업일 옆에 모닥불을 두고 연속이 길수록 크게 탄다 (1–2일 작은 불, 3–6일 보통, 7일 이상 활활, 0일 장작만). 연속은 오늘 기록이 있으면 오늘까지, 없으면 어제까지 센다. 오늘 기록이 아직 없고 어제까지 연속이면 불이 약하게 깜빡이고 "오늘 하면 N+1일째"를 보여준다.
- R58. 버블의 원이나 범례 줄에 마우스를 올리면 잔디가 그 프로젝트의 시간만으로 다시 칠해지고(프로젝트 색), 오른쪽 숫자는 그 프로젝트의 작업한 날·16주 합계·마지막 작업으로 바뀐다. 다른 원과 범례는 흐려지고, 마우스를 떼면 돌아온다.
- R59. 잔디 칸에 마우스를 올리면 그날 날짜·합계와 프로젝트별 시간을 말풍선으로 보여주고, 그날 작업한 프로젝트의 버블 원 테두리가 반짝인다.
