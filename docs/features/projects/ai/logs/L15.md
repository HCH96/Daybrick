# L15 · 2026-11-05 · 수정: 버블 퍼센트 합 100 (r1 A11)

- 요구사항: R37
- 한 일: r1 AI 테스트 A11 실패(퍼센트를 하나씩 반올림해 합이 99·101이 됨)를 사용자 요청으로 고쳤다.
  `bubbleItems`가 새 순수 함수 `sumTo100`(최대 나머지 방식: 모두 내림 → 모자란 만큼 소수점 아래 큰 것부터 1씩, 같으면 시간 많은 쪽 먼저)으로 퍼센트를 정한다.
- 확인: Node로 `sumTo100` 예시 실행 — 300/120/45분 → 64/26/10, 같은 시간 3개 → 34/33/33, 1분 7개 → 15/15/14×5, 단일 → 100, 빈 목록 → [] (모두 합 100). `npm run build` 성공 (청크 크기 경고만)
- 사용자 확인: 대기 (r1 사용자 테스트 8번)
- 테스트 메모: 원 안 퍼센트를 더하면 늘 100. 같은 시간인 원은 1% 차이가 날 수 있다 (예: 34/33/33)
