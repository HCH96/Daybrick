# L07 · 2026-11-04 · 구현 4단계: 단계 칸·태스크 줄

- 요구사항: R29–R34
- 한 일: `ProjectDetail` 진행 판 아래에 `StageBoard`(남은 높이 차지)를 붙였다. 단계형은 같은 너비 칸, 주차형은 272px 칸 가로 넘기기 + 처음 열 때 현재 주차 칸을 맨 앞으로 스크롤.
  `StageColumn`: 이름(말줄임)·주차 기간·`현재`/`이번 주` 칩·`완료/전체`(모두 끝나면 초록)·`+`. 몸은 안 끝난 태스크 → `완료 N` 구분선 → 완료 태스크 → 입력 줄(플랜 `InlineTaskInput`, Enter 뒤에도 유지), 비면 안내 문구. 칸 안은 세로로 넘긴다.
  `StageTaskRow`: 플랜 목록 줄과 같은 `plan-task` 클래스(상태 돌리기·기간/`날짜 없음`·체크리스트·올린 줄 휴지통 → 같은 확인 창). 줄을 누르면 플랜 `TaskDetailModal`(연결 카드는 `ApplicationDetailModal`을 위에 띄움).
  `useStageTaskDrag`: 4px 넘게 끌면 기울어진 끄는 모습(플랜 `plan-drag-ghost--task` 클래스), 놓을 칸 보라 테두리, 다른 칸에 놓으면 `updateTask(id, { stageId })`. 끈 뒤 클릭은 막는다.
- 결정: D15 추가
- 계획과 달라진 점: (자동 진행 중 판단) 플랜 `TaskRow`·`DragGhost`는 플랜 끌기 컨텍스트(`usePlanDrag`)에 묶여 있어 그대로 쓰지 않고, 같은 클래스로 `StageTaskRow`·`StageDragGhost`(StageBoard 안)를 따로 만들었다(D15). 주차형 칩은 오늘이 그 주에 들어 있을 때만 `이번 주`, 시작 전·기간 뒤로 맞춘 칸은 `현재`. 목업 메모의 "이번 주 앞 칸부터"가 아니라 step 파일대로 현재 주차 칸을 맨 앞에 두었다.
- 확인: `npm run build` 성공 (tsc + vite). 화면 확인은 하지 않았다.
- 사용자 확인: 대기 (최종 테스트)
- 테스트 메모: 입력 줄은 완료 태스크 아래(칸 맨 아래)에 열린다. 줄의 상태 표시를 누른 채 4px 넘게 움직여도 끌기가 된다(플랜과 같음). 주차형을 시작 전·끝난 뒤에 열면 칩이 `현재`.
- 주요 파일: pages/projects/detail/{StageBoard,StageColumn,StageTaskRow}.tsx, useStageTaskDrag.ts, Detail.css
