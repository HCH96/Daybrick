# 데이터 동기화 (data-sync) 사용자 테스트 체크리스트 r1
작성: 2026-11-08 · 근거: 명세 R1–R33, 계획 step-01~07 "확인할 결과", 진행 기록 L02–L09

AI는 화면을 띄워 보지 않았습니다. 아래 문구는 앱 코드의 한글 문구를 모아 적은 것이고, 색은 theme.css 토큰 이름입니다.

## 준비
1. 시작 전 백업: 앱을 끄고 `%APPDATA%\com.daybrick.desktop` 폴더를 통째로 다른 곳(예: 바탕화면 `daybrick-backup-1108`)에 복사한다.
2. Supabase 대시보드를 브라우저에 열어 둔다. 앞으로 나오는 "서버 행"은 Table Editor › `sync_documents` 표를 말한다.
3. 서버 구조가 아직 9번인 상태로 시작한다 (U2를 먼저 하려고). 이미 10이면 U2는 건너뛰고 메모에 적는다.
4. 앱에 Google 계정 A로 로그인해 둔다. 다른 Google 계정 B를 하나 준비한다 (U23·U24용).
5. 테스트 데이터:
   - 플랜: 카테고리 "테스트"와 그 안에 태스크 "동기화 확인 1" (이하 **태스크 A**)
   - 캘린더: 아무 날짜에 일정 "동기화 일정" (이하 **일정 A**)
   - 지원 관리·투데이는 지금 있는 데이터 그대로 둔다
6. 동기화 구역 위치: 설정 › "데이터 동기화" 구역. 종류 줄은 위에서부터 플랜·캘린더·지원 관리·투데이. 줄마다 왼쪽에 종류 이름, 가운데 상태(맞음·대기·선택 필요·오류·건너뜀), 그 아래나 옆에 흐린 보조 문구(`--faint`), 오른쪽에 [고르기](선택 필요일 때)와 ⋯ 메뉴.
