# 데이터 동기화 요구사항: 올리기 (R9–R16)

### 올리기
- R9. 로컬 저장은 지금처럼 먼저 하고, 서버 올리기는 그 뒤에 따로 한다. 올리기가 실패해도 로컬 저장을 막지 않는다.
- R10. 동기화가 켜져 있고 로그인돼 있으면, 로컬 저장 뒤 몇 초 모았다가 바뀐 종류만 자동으로 올린다. (대기 시간은 계획 단계에서 정한다)
- R11. 올리지 못한 종류는 "대기"로 표시해 두고(앱을 다시 켜도 남음), 로그인·연결이 돌아오면 다시 올린다.
- R12. 창을 닫을 때 남은 올리기는 짧게 한 번 시도한다. 못 끝내도 닫기를 막지 않고, 다음 실행 때 올린다.
- R13. 로컬 파일을 읽지 못한 종류(깨진 파일, 모르는 버전)는 올리지 않는다.
- R14. 마지막으로 맞춘 뒤 서버 행이 다른 곳에서 바뀌었으면(리비전이 다르면) 덮어쓰지 않는다. 그 종류의 자동 올리기를 멈추고 R20의 선택창으로 넘긴다.
- R15. 로컬이 빈 데이터인데 서버에 내용이 있으면 자동으로 올리지 않고 R18의 "서버에서 받아오기" 질문으로 넘긴다.
- R16. 지금 로그인한 계정이 마지막으로 동기화한 계정과 다르면 자동으로 올리지 않고 물어본다.
