# 데이터 동기화 요구사항: 로그인 풀림·끄기 안전 (R24–R28)

### 로그인 풀림·끄기 안전
- R24. 로그인이 풀리거나 오프라인이면 올리기만 멈춘다. 로컬 저장은 계속하고 "대기" 표시는 남긴다.
- R25. 로그인 풀림·로그아웃·서버 연결 해제·동기화 끄기는 로컬 파일과 서버 행 어느 쪽도 지우거나 바꾸지 않는다.
- R26. 다시 로그인되면 대기 중인 종류를 R13–R16 검사를 거쳐 올린다.
- R27. 동기화를 꺼도 서버 데이터는 남는다. 다시 켜면 R17 흐름을 다시 탄다.
- R28. 서버 업데이트·자동 세팅 다시 실행은 동기화 테이블의 데이터를 지우지 않는다.

### 배경
하루쯤 지나면 데스크톱 로그인이 풀리는 문제가 있다(server-setup L22, 원인 미확정). 이 묶음은 그 상황에서도 데이터가 사라지거나 덮어써지지 않게 하는 규칙이다. 로그인 풀림 자체의 수정은 이 기능의 범위가 아니다.
