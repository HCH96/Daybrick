# 데이터 동기화 (data-sync)
PC 앱의 로컬 JSON(플랜·캘린더·지원 관리·투데이)을 사용자 본인 Supabase에 기능별 한 행씩 올려, 나중에 웹·폰이 읽을 수 있게 한다.

- 상태: 명세 완료
- 선행 기능: server-setup (연결·로그인·서버 구조 번호)
