# 플랜 사용자 테스트 체크리스트 (r1)

- 작성일: 2026-11-02 · 근거: [명세서](../../ai/spec/index.md), [구현 계획](../../ai/plan/index.md), [목업](../mockups/index.html)
- 범위: 주요 기능만 간단하게 (사용자 요청). 세부 규칙은 AI 테스트([../../ai/tests/r1/](../../ai/tests/r1/))에서 코드로 확인한다.
- 창 크기: 따로 적지 않은 항목은 1200x800 안팎이면 된다.

## 준비
1. apps/desktop에서 `npm run tauri dev`로 앱을 켠다.
2. 사이드바 `Plan`을 누른다.
3. 카테고리 두 개를 만든다: **카테고리 A** "C++ 공부"(파랑 계열), **카테고리 B** "취업 준비"(초록 계열).
4. 지원관리에서 카드 두 개를 준비한다: **카드 X** 상태 "지원 준비", 이번 주 수요일에 지원 마감 일정 / **카드 Y** 아무 상태, 이번 주 목요일 14:00 코딩테스트 일정. (U9·U11에서 씀)

### 1. 메뉴·화면 구성·주 이동
- 근거 요구사항: R1–R4, R21
- 수행 방법: 사이드바를 본다 → `Plan` 누르기 → `다음 주 ›` 두 번 → `‹ 이전 주` 한 번 → `이번 주` → 다른 메뉴(홈)에 갔다가 다시 `Plan`
- 예상 결과: 사이드바에 Calendar 대신 `Plan`이 있고, 화면 제목은 "플랜". 왼쪽 태스크 목록, 오른쪽 월~일 7칸 달력. 처음엔 오늘이 든 주(예: "2026년 11월 2일 – 8일")가 위에 보이고 오늘 칸이 강조, 토·일 글자색이 다르다. 버튼마다 기간 글자가 바뀌고, 다른 메뉴에 갔다 오면 이번 주로 돌아와 있다.
- 확인 위치: 사이드바, 화면 위쪽 기간 글자와 버튼, 달력 머리의 요일·날짜
- 실제 결과: 
- 판정: [O] 통과  [ ] 실패
- 메모: 디자인 수정 필요. 첫째, 화면 제목을 "플랜" 대신 영어 "Plan"으로 바꾸기. 둘째, 위쪽 기간 표시랑 대시 모양이 촌스러움. 셋째, 달력 머리의 요일과 날짜 글자 크기가 안 맞고, 숫자만 굵어서 따로 놀고, 한글 요일 때문에 전체적으로 촌스러움. 폰트는 나중에 전역으로 바꿀 거라 보류.

### 4. 상태 표시·완료 묶음·접기
- 근거 요구사항: R12, R14, R15, R18
- 수행 방법: "템플릿 정리"의 동그라미를 세 번 누르며 매번 본다 → 다시 두 번 눌러 완료(●)로 둔다 → 카테고리 A 머리의 개수 확인 → "완료 1개" 줄 누르기 → 카테고리 A 머리(버튼 말고 빈 곳)를 눌러 접기
- 예상 결과: ○ → ◐(진행 중) → ●(완료) → ○ 로 돈다. 동그라미를 눌러도 팝업은 열리지 않는다. 완료된 태스크는 묶음 맨 아래 "완료 1개" 접힌 줄로 들어가고, 머리 개수는 3 → 2로 준다. "완료 1개"를 누르면 펼쳐져 흐리게·취소선으로 보인다. 머리를 누르면 묶음이 접힌다.
- 확인 위치: 왼쪽 목록 카테고리 A 묶음
- 실제 결과: 
- 판정: [O] 통과  [ ] 실패
- 메모: 상태 순환은 정상. 완료 표시가 꽉 찬 원이 아니라 초록 바탕 체크 표시로 나와서 명세와 다름. 상태 순환은 정상. 완료 표시는 초록 원 안에 체크 표시인데, 체크가 한쪽으로 치우쳐 보여서 어색함. 체크가 아니어도 괜찮으니 보기 좋은 디자인으로 바꾸기.머리 개수 줄어드는 건 정상. 완료 항목은 흐리게만 보이고 취소선은 빼기.

### 5. 상세 팝업 고치기·자동 저장·삭제
- 근거 요구사항: R20, R35, R36, R40, R41
- 수행 방법: "STL 복습" 줄 누르기 → 아무것도 안 고친 채 머리 표시 보기 → 제목을 "STL 복습2"로, 카테고리를 B로, 상태를 진행 중으로 → `+ 날짜 정하기`로 이번 주 화요일 고르고 끝일을 목요일로 → 메모에 `# 제목` 과 `- 목록` 적기 → 닫았다 다시 열기 → 다른 태스크 "CS 네트워크"를 열어 `삭제` → 확인
- 예상 결과: 열기만 하면 "저장 중"이 뜨지 않는다. 고칠 때마다 뒤의 목록에 바로 반영되고, 카테고리를 바꾸면 B 묶음으로 옮겨간다. 목록 줄 기간이 "11/3–11/5"처럼 보이고 달력에 막대가 생긴다. 메모는 큰 제목·글머리표로 바로 바뀌고 다시 열어도 남아 있다. 머리 표시는 "저장 중" → "자동 저장됨". 삭제는 "메모와 체크리스트도 함께 지워지고, 되돌릴 수 없어요." 확인 창을 거친다.
- 확인 위치: 팝업 머리, 뒤쪽 목록, 달력
- 실제 결과: 
- 판정: [O] 통과  [ ] 실패
- 메모: 제목, 카테고리, 상태 변경은 정상. 디자인 수정 세 개. 첫째, 팝업의 "태스크" 글자에서 "크"가 "스"보다 훨씬 작게 보여서 어색함. 한글 대신 영어 "Task"로 바꾸기. 둘째, "메모" 칸은 메모가 아니라 공부하거나 작업한 내용을 요약 정리하는 본문 용도임. 지원관리 카드 팝업처럼 아래쪽에 마크다운 본문을 쓰는 형태로 바꾸고, "메모"라는 이름도 바꾸기. 셋째, 체크리스트 버튼을 아래가 아니라 카테고리, 상태, 기간, 지원 카드 같은 속성 줄과 같이 두기.태스크 팝업 디자인 전체를 지원관리 카드 팝업과 똑같은 디자인으로 맞추기.왼쪽 목록의 각 태스크 줄 오른쪽에 휴지통 버튼을 둬서, 팝업을 열지 않고 바로 삭제할 수 있게 하기.

### 8. 끌어 놓기

### 9. 지원 일정 표시
- 근거 요구사항: R31–R34
- 수행 방법: 이번 주 달력 위쪽 확인 → 알약에 마우스 올리기 → 알약 누르기 → 열린 지원 팝업에서 카드 Y의 코딩테스트 날짜를 금요일로 바꾸고 닫기 → 알약을 끌어 보기 → 지원관리에서 카드 X를 지원 완료로 바꾸고 플랜으로 → `지원 일정` 스위치 끄기 → 지원관리 메뉴의 달력 보기 확인
- 예상 결과: 날짜 칸 위쪽에 막대와 다른 작은 알약(종류 아이콘 + 회사 또는 카드 제목, 있으면 "14:00")이 보인다. 마우스를 올리면 풍선, 누르면 플랜 화면 위에 지원관리 상세 팝업이 뜨고 닫으면 플랜에 그대로 있다. 날짜를 바꾸면 알약이 금요일로 바로 옮겨진다. 알약은 끌어지지 않는다. 카드 X가 지원 완료면 지원 마감 알약이 사라진다. 스위치를 끄면 알약이 모두 숨는다. 지원관리 달력 보기는 예전과 똑같다.
- 확인 위치: 달력 위쪽 일정 줄, 화면 위쪽 `지원 일정` 스위치, 지원관리 달력
- 실제 결과: 
- 판정: [O] 통과  [ ] 실패
- 메모: 알약 표시, 풍선, 팝업 열기, 날짜 변경 반영, 끌기 막힘, 지원 완료 시 숨김, 스위치, 지원관리 달력 모두 정상. 수정할 점은 알약 풍선에 나오는 "누르면 지원관리 카드가 열려요" 문구를 삭제하기.

### 10. 체크리스트
- 근거 요구사항: R37, R38
- 수행 방법: 기간 있는 태스크 팝업 열기 → `+ 체크리스트` → `+ 항목 추가`로 "vector" Enter "map" Enter "set" Enter → 빈 채로 Enter → 두 개 체크 → 한 항목 글자 고치기 → 한 항목 지우기 → 항목 끌어 순서 바꾸기 → 닫고 목록·막대 보기 → 다시 열어 `체크리스트 삭제`
- 예상 결과: 처음엔 `+ 체크리스트` 버튼만 있다. Enter로 이어서 항목이 생기고, 빈 채 Enter면 그 빈 항목이 없어지고 입력이 멈춘다. 체크할 때마다 머리 진행도와 목록 줄·막대의 "2/3" 같은 글자가 같이 바뀐다. 고치기·지우기·순서가 다시 열어도 남아 있다. `체크리스트 삭제` 후 다시 `+ 체크리스트` 버튼만 남는다.
- 확인 위치: 팝업 체크리스트 칸, 목록 줄 오른쪽, 달력 막대 끝

### 12. 앱 재시작 후 유지
- 근거 요구사항: R5, R12, R33
- 수행 방법: 위 항목을 마친 상태에서 카테고리 하나를 접어 두고 `지원 일정` 스위치를 꺼 둔다 → 앱을 완전히 끄고 다시 켜기 → `Plan`
