플랜 목업

카테고리별 태스크를 주간 달력에 끌어 놓아 한 주를 계획하는 화면. 디자인 확인용 정적 화면이라 눌러도 동작하지 않는다.
색과 앱 창 틀은 메인 페이지·지원 관리 목업과 같다. 예시 날짜: 오늘 2026년 11월 2일 (월).

  • 1. 플랜 화면왼쪽 카테고리별 목록 + 오른쪽 주간 달력, 지원 일정·여러 날 막대·주 경계R1–R34
  • 2. 처음 화면태스크·카테고리가 없을 때, 다음 주로 옮기고 지원 일정을 끈 모습R7, R10, R16, R33
  • 3. 태스크 상세 팝업속성·지원 카드 연결·체크리스트·메모, 막 만든 태스크R35–R41
  • 4. 목록 부품태스크 줄 모양, 바로 적기, … 메뉴, 색 선택기, 순서 바꾸기, 날짜 지우기R7–R8, R12–R18, R27
  • 5. 달력 부품끌어 놓기, 막대 옮기기·끝 끌기, 더블클릭 새 태스크, 지원 일정 4종R22–R32
  • 6. 확인 창카테고리 삭제, 태스크 삭제R9, R40
  • 7. 지원 카드 고르기상세 팝업에서 지원관리 카드 하나를 골라 연결R39
