  • 빠른 입력은 목록 맨 위. 옆 칩에서 카테고리를 고른다 (기본 미분류)
  • 묶음 머리: 접기 ▾, 색 점, 이름, 안 끝난 개수. …·+는 마우스를 올렸을 때만 보인다
  • 미분류는 테두리만 있는 점, 맨 아래 고정, … 없음
  • 줄에 마우스를 올리면 왼쪽에 끌기 손잡이가 보인다
상태 표시
  • 시작 전: 회색 빈 원
  • 진행 중: 주황 반쪽 원
  • 완료: 초록 채운 원 + 체크, 제목 취소선·흐리게
  • 줄의 원을 누르면 다음 상태로 바뀐다 (R18)
주간 달력
  • 오늘 칸: 날짜 숫자를 보라 원으로, 칸 전체를 아주 옅게
  • 지원 일정은 둥근 알약 모양 + 종류 아이콘·색, 막대 위 점선 아래로 태스크 막대
  • 주 경계를 넘는 막대는 잘린 쪽 모서리를 각지게 하고 ‹ › 표시
