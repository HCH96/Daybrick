자동 저장됨
머리·속성
  • 제목은 누르면 바로 고치는 큰 글자
  • 카테고리·상태는 칩을 누르면 목록이 열린다
  • 기간은 날짜 칩 두 개 + 일수. "날짜 없음으로"를 누르면 둘 다 지워진다
  • 삭제는 휴지통 → 확인 창 (6. 확인 창)
지원 카드
  • 카드 제목(밑줄)을 누르면 지원관리 상세 팝업이 열린다
  • 회사 이름과 지원 상태 배지를 함께 보여준다
  • 연결이 없으면 "+ 지원 카드 연결" → 7. 지원 카드 고르기
체크리스트·메모
  • 처음엔 "+ 체크리스트" 버튼만. 만들면 진행도 막대가 생긴다
  • 항목에 마우스를 올리면 끌기 손잡이·× 표시, 누르면 그 자리에서 고친다
  • 메모는 지원관리 본문 편집기와 같은 모양
  • 저장 버튼 없이 아래에 "자동 저장됨"만 보여준다
