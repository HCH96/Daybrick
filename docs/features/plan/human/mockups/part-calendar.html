끌어 놓기
  • 놓일 칸(들)은 보라 테두리 + 옅은 보라 바탕
  • 아래에 놓였을 때의 날짜를 작은 알약으로 미리 알려준다
  • 옮기는 막대는 원래 자리에 흐린 점선 막대가 남는다
막대 고치기
  • 양 끝 손잡이는 마우스를 올렸을 때만 보인다
  • 더블클릭한 칸에 흰 바탕 입력 막대가 생기고, Enter로 만들고 Esc로 취소
  • 막대가 많으면 달력 몸통만 세로로 스크롤되고 요일 머리는 고정 (R29)
지원 일정
  • 색·아이콘: 지원 마감 빨강 깃발, 과제 주황 문서, 코딩테스트 보라 코드, 면접 청록 사람
  • 끌 수 없으므로 손잡이·그림자가 없다
  • 마우스를 올리면 카드 제목·종류·시간 풍선 (목업 제안)
