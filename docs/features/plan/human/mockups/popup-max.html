Notes

map vs unordered_map

  • std::map: 레드블랙 트리, 순서 유지, 찾기 O(log n)
  • std::unordered_map: 해시, 평균 O(1), 순서 없음
std::unordered_map<int, std::string> names;
names.reserve(1024);   // 재해시 줄이기

헷갈린 점

operator[]는 없는 키를 만들어 버린다 → 읽기만 할 땐 find나 contains (C++20).
