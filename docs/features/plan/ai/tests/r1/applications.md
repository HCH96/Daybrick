## A12 연결 정리 조건
- 테스트 내용: 지원 데이터를 다 읽었을 때만 연결을 정리하는지
- 근거 요구사항: R39, D14
- 수행 방법:
  - 코드 읽기: features/plan/useLinkCleanup.ts(전체), store.tsx에서 호출 위치
  - Node 실행: reducer `clear-missing-links`
- 예상 결과: 읽는 중·실패면 applicationId를 지우지 않음, 읽었고 카드 없으면 null
- 실제 결과:
  - 훅은 `plan.kind !== "ready" || applications.kind !== "ready"`면 바로 return → 읽는 중·읽기 실패면 아무것도 보내지 않음
  - 있는 카드(app1)는 그대로, 없는 카드(gone)를 가리키던 태스크만 null. 끊을 것이 없으면 같은 데이터 객체를 돌려줘 저장하지 않음
- 판정: 통과
