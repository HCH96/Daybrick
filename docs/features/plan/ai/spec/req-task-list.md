# 플랜 요구사항: 태스크 목록 (R11–R20)

### 태스크 목록
- R11. 왼쪽 목록은 날짜가 있든 없든 모든 태스크를 카테고리별 묶음으로 보여준다.
- R12. 묶음 머리에는 카테고리 색, 이름, 끝나지 않은 태스크 개수, `+` 버튼이 있고, 묶음은 접고 펼 수 있으며 접힌 상태는 다시 열어도 유지된다.
- R13. 묶음 안에서는 날짜 없는 태스크를 먼저, 그다음 날짜 있는 태스크를 시작일 순서로 보여준다.
- R14. 태스크 줄에는 상태 표시, 제목, 기간(예: `11/3–11/5`) 또는 "날짜 없음"을 보여주고, 체크리스트가 있으면 진행도(예: `2/5`)도 보여준다.
- R15. 완료한 태스크는 묶음 맨 아래 "완료 N개" 접힌 줄에 모이고, 누르면 펼쳐진다.
- R16. 목록 맨 위 빠른 입력칸에 제목을 적고 Enter를 누르면 날짜 없는 태스크가 생긴다. 카테고리는 입력칸 옆에서 고르고(기본 미분류), 만든 뒤에도 커서가 입력칸에 남아 이어서 입력할 수 있다.
- R17. 카테고리 머리의 `+`를 누르면 그 카테고리 안에 새 태스크 제목을 바로 적을 수 있다.
- R18. 태스크 줄의 상태 표시를 누르면 시작 전 → 진행 중 → 완료 순서로 바뀐다.
- R19. 새 태스크의 상태는 "시작 전"이다.
- R20. 태스크 줄을 누르면 상세 팝업(R35–R41)이 열린다.

| 상태 | 표시 (모양·색은 목업에서 확정) |
|---|---|
| 시작 전 | ○ |
| 진행 중 | ◐ |
| 완료 | ● (흐리게) |
