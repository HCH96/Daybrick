# 플랜: 다룰 데이터

**카테고리**: id, 이름, 색(직접 고른 색 값), 순서

**태스크**
| 항목 | 설명 |
|---|---|
| id | 고유 번호 (서버로 옮기기 쉽게 무작위 고유값) |
| 제목 | 텍스트 |
| 카테고리 id | 없으면 미분류 |
| 상태 | 시작 전 / 진행 중 / 완료 |
| 시작일, 끝일 | 날짜만. 둘 다 없거나 둘 다 있다 (하루짜리는 같은 날) |
| 메모 | 마크다운 텍스트 |
| 체크리스트 | 없음 또는 항목 목록 (id, 내용, 체크 여부, 순서) |
| 연결된 지원 카드 id | 없을 수 있음 |
| 만든 날, 고친 날, 완료한 날 | 날짜·시간 |

**화면 설정**: 접힌 카테고리 목록, 지원 일정 보이기 여부

**읽기만 하는 데이터**: 지원관리 카드의 전형 일정·상태·제목·회사 (지원관리 저장소에서 읽는다)

**저장 위치**: PC 안의 JSON 파일. 지원관리 저장 파일과는 따로 둔다. 구체적인 방식은 구현 계획에서 정한다.
