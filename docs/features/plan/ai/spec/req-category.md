# 플랜 요구사항: 카테고리 (R6–R10)

### 카테고리
- R6. 카테고리는 이름과 색을 가진다 (예: C++ 공부, TrialGround, 취업 준비).
- R7. 목록 아래쪽 `+ 카테고리 추가` 버튼으로 이름과 색을 정해 새로 만든다. 색은 색 선택기로 자유롭게 고른다.
- R8. 카테고리 줄의 `…` 메뉴로 이름·색을 고치고, 카테고리 줄을 끌어서 순서를 바꾼다.
- R9. 카테고리를 지우면 확인을 받은 뒤 지우고, 그 안의 태스크는 미분류로 옮긴다.
- R10. "미분류"는 맨 아래 고정 묶음으로 고치거나 지울 수 없고, 태스크가 없으면 보이지 않는다. 처음부터 카테고리 없이 태스크를 만들 수 있다.
