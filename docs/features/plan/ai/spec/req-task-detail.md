# 플랜 요구사항: 태스크 상세 팝업 (R35–R41)

### 태스크 상세 팝업
- R35. 팝업에서 제목, 카테고리, 상태, 기간(시작일·끝일 선택 또는 "날짜 없음")을 고친다.
- R36. 메모를 마크다운으로 적는다. 지원관리 본문과 같은 편집기를 쓴다.
- R37. 체크리스트는 처음에는 없고, `+ 체크리스트` 버튼을 누르면 만들어진다.
- R38. 체크리스트 항목은 추가·체크·고치기·지우기·끌어서 순서 바꾸기를 할 수 있고, `체크리스트 삭제`로 통째로 없앨 수 있다.
- R39. `지원 카드 연결`로 지원관리 카드 하나를 골라 연결한다. 연결된 카드 이름을 누르면 지원관리 상세 팝업이 열리고, 연결을 끊을 수 있으며, 연결된 카드가 지워지면 연결도 사라진다.
- R40. 태스크는 확인을 받은 뒤 지운다.
- R41. 고친 내용은 저장 버튼 없이 자동으로 저장된다.
