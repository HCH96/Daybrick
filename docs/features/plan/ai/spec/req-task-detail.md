# 플랜 요구사항: 태스크 상세 팝업 (R35–R43)

### 태스크 상세 팝업
- R35. 팝업에서 제목, 카테고리, 상태, 기간(시작일·끝일 선택 또는 "날짜 없음")을 고친다.
- R36. 팝업 아래쪽 `Notes` 칸에 공부하거나 작업한 내용을 마크다운으로 정리한다. 지원관리 본문과 같은 편집기를 쓴다. (L15에서 변경)
- R37. 체크리스트는 처음에는 없고, 속성 줄에 있는 `+ 체크리스트` 버튼을 누르면 만들어진다. (L15에서 변경)
- R38. 체크리스트 항목은 추가·체크·고치기·지우기·끌어서 순서 바꾸기를 할 수 있다. 끄는 동안 잡은 항목이 마우스를 따라온다. `체크리스트 삭제`로 통째로 없앨 수 있다. (L15에서 변경)
- R39. `지원 카드 연결`로 지원관리 카드 하나를 골라 연결한다. 연결된 카드 이름을 누르면 지원관리 상세 팝업이 열리고, 연결을 끊을 수 있으며, 연결된 카드가 지워지면 연결도 사라진다.
- R40. 태스크는 확인을 받은 뒤 지운다.
- R41. 고친 내용은 저장 버튼 없이 자동으로 저장된다.
- R42. 팝업은 지원관리 카드 팝업과 같은 디자인으로 만든다. 머리의 종류 글자는 `Task`이고, 위에서부터 제목 → 속성 목록(카테고리·상태·기간·지원 카드·체크리스트) → 체크리스트 항목 → 구분선 → Notes 순서다. 세부 모양은 목업에서 정한다.
- R43. 왼쪽 위 최대화 버튼으로 본문 영역을 꽉 채운다. 동작은 지원관리 명세 R13과 같다.

## 화면 구성
```
┌ [⤢]  Task                    자동 저장됨 [🗑] [✕] ┐
│   STL 복습                                        │
│   카테고리   ● C++ 공부                            │
│   상태       ◐ 진행 중                             │
│   기간       11/3 ~ 11/5 (3일)                     │
│   지원 카드  넥슨 게임 클라이언트  [연결 끊기]       │
│   체크리스트 2/5  [+ 체크리스트 / 체크리스트 삭제]   │
│     ☑ vector  ☑ map  ☐ set  [+ 항목]               │
│   ─────────────────────────────                  │
│   Notes                                           │
│   (마크다운 편집기)                                │
└──────────────────────────────────────────────────┘
```
머리 버튼 순서와 속성 줄 모양은 지원관리 팝업([지원 관리 mockup.md](../../../applications/ai/spec/mockup.md))을 따르고, 세부는 플랜 목업 r2에서 정한다.
