# 플랜 요구사항: 주간 달력 (R21–R30)

### 주간 달력
- R21. 월~일 7칸에 날짜를 표시하고 오늘 칸을 강조한다. 요일은 영어로 쓰고, 요일과 날짜는 크기·굵기가 어울리게 맞춘다(표기 방식은 목업에서 정한다). 시간대는 없고 날짜 칸만 있다. (L15에서 변경)
- R22. 왼쪽 태스크를 끌어 요일 칸에 놓으면 그날로 배치한다. 날짜가 없던 태스크는 하루짜리가 되고, 이미 기간이 있으면 길이를 유지한 채 시작일만 옮긴다.
- R23. 여러 날 태스크는 시작일부터 끝일까지 이어진 막대 하나로 보이고, 주 경계를 넘으면 잘린 쪽 끝을 표시한다.
- R24. 막대에는 카테고리 색, 제목, 상태 표시가 보이고, 완료한 태스크는 흐리게 남는다.
- R25. 막대를 끌어 다른 날로 옮기면 길이를 유지한 채 옮겨진다.
- R26. 막대의 왼쪽·오른쪽 끝을 끌어 시작일·끝일을 바꾼다.
- R27. 막대를 왼쪽 목록에 끌어 놓으면 날짜가 지워져 "날짜 없음"이 된다.
- R28. 날짜 칸의 빈 곳을 더블클릭하면 그날 새 태스크의 제목을 바로 적는다 (카테고리는 미분류, 나중에 상세 팝업에서 바꾼다).
- R29. 막대가 많아지면 달력이 세로로 늘어나 스크롤되고, 막대끼리는 겹치지 않게 줄을 나눈다.
- R30. 막대를 누르면 상세 팝업이 열린다.
