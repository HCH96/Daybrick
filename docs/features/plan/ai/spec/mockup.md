# 플랜: 목업에서 정한 것

## 목업
- 경로: [human/mockups/index.html](../../human/mockups/index.html) (2026-11-02 승인, 화면별 파일로 나눔)
- 화면: 1. 플랜 화면, 2. 처음 화면, 3. 태스크 상세 팝업, 4. 목록 부품, 5. 달력 부품, 6. 확인 창, 7. 지원 카드 고르기
- 화면 배치와 스타일은 이 목업을 기준으로 구현한다. 색은 메인 페이지의 그라파이트 바이올렛 색 목록을 그대로 쓴다.

### 목업에서 정한 것
| 항목 | 결정 |
|---|---|
| 배치 | 왼쪽 목록 폭 320px, 오른쪽 달력. 빠른 입력칸은 목록 맨 위, 기간·주 이동·`지원 일정` 스위치는 달력 위 한 줄 |
| 상태 표시 | 시작 전 회색 빈 원, 진행 중 주황 반쪽 원(`#F0B860`), 완료 초록 채운 원 + 체크(`#66CF95`), 완료 줄은 제목 취소선·흐리게 |
| 카테고리 표시 | 색 점 + 이름 + 안 끝난 개수. `…`·`+`는 마우스를 올렸을 때만. 미분류는 테두리만 있는 점, `…` 없음 |
| 태스크 줄 | 제목 아래 작은 회색 글자로 기간(또는 "날짜 없음")·체크리스트 진행도·연결 회사 |
| 오늘 칸 | 날짜 숫자를 보라 원으로, 칸 전체를 아주 옅은 보라로. 토요일 파랑, 일요일 빨강 글자 |
| 태스크 막대 | 카테고리 색 옅은 바탕 + 왼쪽 굵은 선, 앞에 상태 표시, 오른쪽 끝에 진행도. 넘치는 제목은 말줄임 |
| 주 경계 | 잘린 쪽 모서리를 각지게 하고 ‹ / › 표시 |
| 지원 일정 | 날짜 칸 위쪽 알약 모양 (아이콘 + 회사 + 시간). 지원 마감 빨강 깃발, 과제 주황 문서, 코딩테스트 보라 코드, 면접 청록 사람. 막대 영역과 점선으로 구분 |
| 끌기 표시 | 놓일 칸 보라 테두리 + 옅은 보라 바탕, 아래에 놓일 날짜 알약. 옮기는 막대는 원래 자리에 흐린 점선 막대 |
| 막대 끝 손잡이 | 마우스를 올렸을 때만 양 끝에 세로 손잡이 |
| 상세 팝업 | 머리: 종류 글자, 휴지통·닫기. 큰 제목, 속성 4줄(카테고리·상태·기간·지원 카드), 체크리스트(진행도 막대), 메모, 아래 "자동 저장됨" |
| 카테고리 색 선택 | 큰 견본 + 색 평면 + 색상 막대 + 색 값 입력 + 최근 쓴 색 |
| 삭제 확인 | 대상 이름을 따옴표로, 함께 일어나는 일 한 줄, 빨간 삭제 버튼 |

### 목업에 넣은 추가 제안 (목업과 함께 승인)
- 지원 일정에 마우스를 올리면 카드 제목·종류·시간 풍선
- 막대가 하나도 없는 주는 달력 아래쪽에 옅은 안내 한 줄
- 지원 카드 고르기 창: 찾기칸, 진행 중 카드 먼저(가까운 일정 순), 종료 카드는 아래에 흐리게
- 상세 팝업 기간 줄에 일수 표시와 "날짜 없음으로" 버튼
