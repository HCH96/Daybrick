# 구직 관리 (job-search) 사용자 테스트 체크리스트 r1
- 작성일: 2026-10-28 · 범위: 주요 기능 동작만 (사용자 요청으로 간단하게. 세부 표시·경계 상황은 실제 사용하며 고침)
- 근거: 테스트 계획 r1 (U1–U53 중 주요 기능을 묶어 16개로 줄임), AI 테스트 보고서 [../../ai/tests/r1/](../../ai/tests/r1/)
- 화면은 AI가 직접 보지 않았다. 예상 결과는 명세·진행 기록 기준이다.

## 준비
1. 테스트용 Supabase·Anthropic 키로 연결된 앱을 `npm run tauri dev`로 켠다.
2. 설정에서 서버 업데이트를 한 번 한다 (서버 구조 3·4·5번 적용, 함수 배포, 비밀값 만들기). 서버 함수가 없다는 문구("…서버 함수가 없어요. 서버 업데이트를 해 주세요.")가 보이면 이 단계가 빠진 것이다.
3. 프로필 자료: 이력서 PDF 1개, 포트폴리오 .md 1개를 준비한다.
4. 알림 확인용 Gmail: 지원 건 회사 도메인(또는 회사 이름이 제목에 든) 메일을 보낼 수 있는 다른 계정. 없으면 13·14번은 건너뛴다.
- 이후 "준비의 공고 A"는 4번 항목에서 수집·채점된 공고 중 점수가 가장 높은 카드를 뜻한다.
