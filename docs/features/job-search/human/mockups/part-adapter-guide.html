어댑터 작성 가이드

규칙 파일 형식예시: 게임잡예시: 넥슨AI에게 맡기기 (프롬프트 틀)시험 수집과 자주 나는 오류

규칙 파일 형식

어댑터는 JSON 파일 하나예요. 서버의 공용 수집 함수가 이 규칙대로 목록 페이지를 읽고 공고 상세를 가져와요. {{회사코드}}처럼 중괄호로 쓴 값은 사이트별 값으로 채워져요.

복사{ "name": "greeting", "version": 2, "siteValues": ["회사코드"], // 사이트마다 다른 값 "list": { "url": "https://{{회사코드}}.career.greetinghr.com", "item": "a[href*='/o/']", "title": ".opening-title", "deadline": ".opening-date", "nextPage": "button.next" }, "detail": { "body": "article.opening-content", "images": "article img" // 이미지 공고면 저장 } }
키뜻필수
list.item목록에서 공고 하나를 가리키는 선택자필수
list.deadline마감일 글자 위치 (없으면 상세에서 추출)선택
detail.images본문 대신 이미지로 된 공고의 이미지 선택자선택
프롬프트 틀
  • 사이트 주소와 HTML 일부를 붙이면 규칙 파일을 만들어 달라는 글, 복사 단추 있음
예시
  • 게임잡·넥슨 기본 어댑터 전체를 보여주고 복사 가능
규칙 키
  • 그림의 키 이름은 예시, 실제 형식은 계획 단계에서 정함
