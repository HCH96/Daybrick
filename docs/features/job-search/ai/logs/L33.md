# L33 · 2026-10-29 · 명세: 다른 사이트 중복 공고 묶기

- 요구사항: R35, R41 (변경), R82–R93 (추가)
- 한 일: 다른 사이트의 같은 공고(예: 스마일게이트 자사 채용 + 게임잡)가 두 개로 보이는 문제를 보완하는 명세를 썼다.
  - R35는 다른 사이트 판정 키의 정리 규칙을 강화했다(말머리·상투어·제목 속 회사명 제거).
  - 추출 뒤·2차 필터 전에 "중복 확인" 단계를 넣었다(R41, R83–R84). 회사 앞부분 일치, 마감일, 직무·제목 유사도를 엄격하게 본다.
  - 중복은 지우지 않고 대표에 묶는다. 대표는 자사 사이트를 우선하고, 늦게 온 자사 공고는 점수를 유지한 채 대표만 바꾼다. 숨김·지원 묶음은 계속 숨기고, 기존 공고에도 한 번 소급 적용한다(R82, R85–R89).
  - 사이트에 자사 여부를 두고(R90), 카드·팝업에 출처 이름과 링크, [따로 보기]를 보여준다(R91–R93).
- 결정: D52, D53 추가
- 확인: 문서 작업만 함. 직무·제목 유사도의 정확한 기준은 계획 단계에서 정한다.
