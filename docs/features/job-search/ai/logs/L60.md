# L60 · 2026-10-30 · 수정 목록 본문을 먼저·다시 챙기기

- 요구사항: R39 (영향: R37, R104)
- 한 일: 넥슨 원문 실패 5개(L59)의 원인을 더 봤다. 넥슨은 목록 응답이 본문을 주는데, 수집기는 이 본문을 메모리(`listBodies`)에만 들고 있다가 수집 끝의 `fetchBodies`에서 저장한다. 110초 예산이 모자라면 남은 목록 본문은 버려지고, 이후 상세 API는 403이라 영원히 못 받는다. 다음 수집도 새 공고만 목록 본문을 챙겨서 다시 채워지지 않았다.

  - `fetchBodies`: 목록 본문이 있는 공고를 먼저 저장한다.
