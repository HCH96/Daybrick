- 한 일: 사용자 체크리스트 r1의 "추가 수정 요청" 5개를 반영했다.
  1·2. 스크롤 바: `styles/base.css`에서 앱 전체 스크롤 바를 얇은 어두운 회색(`--border-2`, 올리면 `--faint`)으로 바꾸고 창(html·body) 스크롤을 막았다. 스크롤 칸은 모두 `overflow: auto`라 내용이 다 들어오면 막대가 안 나온다.
  3. [지금 평가]: 앱이 `js-collect bodies`(원문 받기) → `js-process queue`(10개씩)를 대기열이 빌 때까지 이어 부른다. 예약 이어 하기 앞뒤(시작 115초 전~시작 150초 뒤)에는 쉬었다 불러 같은 공고를 두 번 처리하지 않는다. [멈추기]가 있고, 실행기는 JobSearchProvider에 있어 탭을 옮겨도 이어 돈다.
  4. 보관함·걸러진 공고 머리의 [← 추천 공고]를 없애 제목이 왼쪽으로 붙었다. [추천 공고] 탭을 다시 누르면 카드 목록으로 돌아간다.
  5. 처리 상태 줄: 추천 공고 탭 상태 상자 3번째 줄과 수집 사이트 탭 단추 줄 아래에 "평가 중 / 예약 처리 중(HH:MM 시작) / 평가 대기 N개 · 원문 대기 N개 · 다음 예약 처리 HH:MM · 다 끝나기까지 약 n분"을 보여 준다. 30초마다·수집 뒤·평가 진행 때 다시 읽는다. 필터 탭 처리 순서 줄의 수집 칸에 "처리 전 N"도 붙였다 (r1 7번에서 "1차 통과 0"이 처리 전이라는 걸 알 수 없었음).
