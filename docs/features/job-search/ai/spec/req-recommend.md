# 구직 관리 요구사항: 페이지·추천 공고·상세 팝업 (R1–R16)

### 페이지
- R1. 사이드바에 "구직 관리" 메뉴 하나를 추가하고, 페이지 안을 탭으로 나눈다: 추천 공고 / 프로필 / 필터 / 수집 사이트 / 메일 제안 / 설정.
- R2. 서버 연결이나 로그인이 안 되어 있으면 탭 대신 연결 안내를 보여준다 (연결 화면은 server-setup 기능).
- R3. 구직 관리 데이터는 공유 웹에 공개하지 않는다.

### 추천 공고 탭
- R4. 필터를 통과하고 채점이 끝난 공고를 카드 목록으로 보여준다. 카드에는 회사, 제목, 마감일(D-n), 적합도 점수를 표시한다.
- R5. 정렬은 "적합도 높은 순"(기본)과 "마감 임박 순" 중에서 고른다. 마감일이 지난 공고는 목록에서 빠진다.
- R6. 탭 위쪽에 AI 사용액 줄(R75)과 마지막 수집 시각, 수집 실패 사이트 수를 표시한다.
- R7. 한도 때문에 채점이 미뤄진 공고는 "채점 대기 N개"로 개수만 표시한다.
- R8. 마지막으로 탭을 연 뒤 새로 들어온 공고 카드에 "새" 표시를 붙인다.
- R9. 탭 안에서 "지원 안 함 보관함"과 "걸러진 공고"(R46) 목록을 열 수 있다.

### 상세 팝업
- R10. 카드를 누르면 상세 팝업이 열린다: 공고 원문(텍스트 또는 이미지), 추출 항목(R48), 적합도 점수·등급, 강점, 부족한 점, 원문 링크.
- R11. 이미지 공고는 저장된 이미지를 보여주고, 누르면 크게 본다.
- R12. 강점과 부족한 점에는 근거(공고의 어느 요건, 프로필의 어느 항목)를 함께 적는다.
- R13. 인젝션 의심 공고는 팝업 위쪽에 경고와 의심 문장을 표시한다.
- R14. 팝업 아래에 "지원하기"와 "지원 안 함" 버튼이 있다.
- R15. "지원 안 함"을 누르면 추천 목록에서 숨기고 지원 안 함 보관함으로 옮긴다. 보관함에서 되돌릴 수 있다.
- R16. 지원했거나 지원 안 함으로 보낸 공고는 다시 수집되어도 추천 목록에 다시 나오지 않는다.
