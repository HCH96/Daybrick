# 구직 관리 요구사항: Gmail 연동·메일 제안 (R60–R70)

### Gmail 연동·메일 제안
- R60. 설정 탭에서 [Gmail 연결]을 누르면 앱에 로그인한 같은 Google 계정에 읽기 전용 권한(gmail.readonly)만 추가로 요청한다 (server-setup R52, D9). (L02에서 변경)
- R61. OAuth 클라이언트는 server-setup에서 만든 것을 그대로 쓰고 따로 만들지 않는다. Google이 띄우는 "확인되지 않은 앱" 경고와 계속하는 방법을 연결 화면에 안내한다. (L02에서 변경)
- R62. Gmail 토큰은 서버(Supabase)에 암호화해 저장하고 앱에는 저장하지 않는다.
- R63. "연결 해제"를 누르면 서버의 토큰을 지우고 Google 쪽 권한도 취소한다.
- R64. 서버가 하루 한 번, 지난 확인 이후 받은 메일을 확인한다.
- R65. 진행 중인 지원 건(종료가 아닌 것)의 회사 이름·도메인과 맞는 메일만 고르고, 나머지 메일은 AI에 보내지 않는다.
- R66. 고른 메일은 Haiku 5.5가 분류하며, 메일 안의 지시문은 따르지 않는다.
- R67. 분류 결과로 상태 변경 제안을 만든다: 대상 지원 건, 현재 상태 → 바꿀 상태, 근거 문장, 일정(날짜가 있을 때).
- R68. 메일 제안 탭에서 제안을 승인하거나 거절한다. 승인하면 로컬 카드의 상태·세부 단계·결과·전형 일정에 반영한다.
- R69. 서버에는 메일 전체를 저장하지 않고 제목, 보낸 사람, 받은 날, 짧은 근거 발췌만 저장한다.
- R70. 토큰이 만료되거나 권한이 취소되면 확인을 멈추고 알림을 보낸다.

| 메일 분류 | 제안할 상태 (지원 관리 기존 5단계) |
|---|---|
| 서류 합격·다음 전형 안내 | 전형 준비 + 세부 단계(과제/코딩테스트/면접) + 일정 |
| 전형 응시 확인 | 결과 대기 + 세부 단계 |
| 불합격 | 종료 + 결과 "불합격" |
| 최종 합격 | 종료 + 결과 "최종 합격" |
| 기타(접수 확인, 광고 등) | 제안 없음 |
