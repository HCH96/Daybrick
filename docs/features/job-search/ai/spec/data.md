# 구직 관리: 다룰 데이터
Supabase 테이블은 모두 `user_id`를 가지며, RLS로 본인 행만 읽고 쓴다.

| 데이터 | 주요 항목 | 저장 위치 |
|---|---|---|
| 프로필 자료 | 파일 이름, 종류(PDF/MD/텍스트), 내용 | Storage(비공개) + 테이블 |
| 프로필 | R19 항목, 출처, 버전, 저장일 | 테이블 |
| 어댑터 | 이름, 규칙 JSON, 버전, 기본 여부 | 테이블 |
| 수집 사이트 | 이름, 주소, 어댑터, 사이트별 값, 자사 채용 사이트 여부, 켜짐, 마지막 결과 | 테이블 |
| 수집 기록 | 사이트, 시각, 공고 수, 성공/실패, 이유 | 테이블 |
| 공고 | 사이트, 고유 id, 주소, 회사, 제목, 원문 텍스트, 이미지 경로, 수집일, 처리 단계, 숨김/지원 여부, 묶인 대표 공고, 사용자가 묶음을 풀었는지 | 테이블 + Storage(이미지) |
| 추출 결과 | R48 항목, 인젝션 의심 여부·문장 | 테이블 |
| 채점 결과 | 점수, 등급, 강점, 부족한 점, 요약, 프로필 버전 | 테이블 |
| 필터 조건 | 단계(1차/2차), 종류, 값, 켜짐 | 테이블 |
| 지원 건 요약 | 공고, 회사, 도메인, 로컬 카드 id, 상태 | 테이블 |
| 메일 제안 | 지원 건, 제목, 보낸 사람, 받은 날, 분류, 제안 상태, 근거 발췌, 처리 결과 | 테이블 |
| Gmail 연결 | 암호화된 토큰, 마지막 확인 시각 | 서버 비밀 저장(Vault 등) |
| AI 호출 기록 | 시각, 모델, 작업, 토큰, 비용 | 테이블 |
| 한도·단가·기준 잔액 기록 | 하루/월 한도, 모델 단가, 기준 잔액 입력 기록 | 테이블 |
| 지원 관리 카드 | 기존 그대로 + 서버 지원 건 id | PC 로컬 파일 |

**비밀값**: Anthropic API 키와 Google OAuth 클라이언트 비밀값은 서버 함수 비밀값에만 둔다. 둘 다 server-setup 자동 세팅이 등록한 것을 쓴다. 앱 코드와 앱 저장소에는 두지 않는다.
