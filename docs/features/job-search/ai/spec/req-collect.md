# 구직 관리 요구사항: 공고 수집 (R33–R40)

### 공고 수집
- R33. 서버가 일주일에 한 번(기본: 월요일 오전 6시) 켜진 모든 사이트를 수집한다.
- R34. 수집 사이트 탭의 "지금 수집" 버튼으로 바로 수집할 수 있다.
- R35. 같은 사이트 안에서는 공고 고유 id(없으면 주소)가 같으면, 사이트가 달라도 회사와 제목(공백·기호 정리)이 같으면 같은 공고로 본다. 같은 공고는 새로 저장하지 않는다.
- R36. 사이트에서 읽은 공고가 0개이거나, 필수 항목(제목·링크)이 빠진 공고가 절반을 넘으면 "수집 실패"로 기록하고 알림을 보낸다.
- R37. 같은 사이트에 연달아 요청할 때는 간격을 둔다.
- R38. 공고 본문이 이미지이면 이미지를 비공개 저장소에 저장한다.
- R39. 수집한 원문(텍스트·이미지)은 저장해 두고 다시 내려받지 않는다.
- R40. 수집이 끝나면 새 공고를 필터·분석 순서(R41)로 넘긴다.
