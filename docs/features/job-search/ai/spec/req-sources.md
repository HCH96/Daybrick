# 구직 관리 요구사항: 수집 사이트·어댑터 (R24–R32, R90)

### 수집 사이트·어댑터
- R24. 수집 사이트 탭에 트래킹할 사이트 목록을 보여준다: 이름, 주소, 사용 어댑터, 켜짐/꺼짐, 마지막 수집 결과(공고 수, 성공/실패와 이유), 마지막 수집 시각.
- R25. 어댑터는 규칙 파일(JSON)이다. 서버의 공용 수집 함수가 규칙을 읽어 실행하므로, 어댑터를 추가해도 서버 함수를 다시 배포하지 않는다.
- R26. 같은 채용 솔루션을 쓰는 회사는 어댑터 하나를 공유하고, 사이트마다 다른 값(회사 코드, 주소 등)만 사이트 설정에 적는다.
- R27. 기본 어댑터는 게임잡과 넥슨 두 개이며, 자동 세팅 때 사이트와 함께 들어간다.
- R28. 사이트 추가: 이름, 주소, 어댑터(기존 것 고르기 또는 규칙 파일 올리기), 사이트별 값을 넣는다.
- R29. 규칙 파일을 올리면 형식을 검사하고 "시험 수집"으로 읽힌 공고 수와 처음 5개 결과를 보여준다. 시험 수집이 성공해야 저장할 수 있다.
- R30. 앱에서 어댑터 작성 가이드를 연다: 규칙 파일 형식, 게임잡·넥슨 예시, AI에게 작성을 맡길 때 쓸 프롬프트 틀.
- R31. 사이트를 끄거나 지울 수 있다. 지워도 이미 모은 공고는 남는다.
- R32. 어댑터 규칙 파일을 새 버전으로 교체할 수 있고, 교체할 때도 시험 수집을 거친다.
- R90. 수집 사이트마다 "자사 채용 사이트" 여부를 둔다. 기본 사이트는 넥슨이 자사, 게임잡이 아님으로 정해지고, 사이트를 추가할 때 고르며 사이트 표에서 바꿀 수 있다. 바꾸면 다음 판정부터 적용한다(중복 공고 대표 고르기, R86).

## 화면 구성
사이트 표(이름 · 어댑터 · 자사 · 켜짐 · 결과 · 시각) + [사이트 추가] [어댑터 가이드]. 사이트 추가 창: 입력 → 시험 수집 결과 → 저장.
