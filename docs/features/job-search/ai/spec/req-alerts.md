# 구직 관리 요구사항: 보내는 알림 (R80–R81)

### 보내는 알림
- R80. 구직 관리는 아래 알림을 알림 센터(notifications 기능)에 보내며, 서버 작업이 만든 알림은 앱을 켤 때 받아 온다.
- R81. 알림을 누르면 관련 탭이나 팝업으로 이동한다.

| 알림 | 누르면 |
|---|---|
| 수집 실패: 사이트 이름, 이유 | 수집 사이트 탭 |
| 새 추천 공고 N개 (수집·채점이 끝난 뒤) | 추천 공고 탭 |
| 메일 제안 N개 | 메일 제안 탭 |
| AI 한도 80% / 초과 | 설정 탭 |
| 크레딧 부족 오류 | 설정 탭 |
| Gmail 연결 끊김 | 설정 탭 |
