# 구직 관리 요구사항: 프로필 (R17–R23)

### 프로필
- R17. 프로필 탭에서 자료를 넣는다: PDF 파일, 마크다운(.md) 파일, 텍스트 붙여 넣기. 여러 개를 함께 넣을 수 있다.
- R18. "프로필 만들기"를 누르면 서버 함수가 Opus 5.5로 자료를 분석해 프로필 초안을 만든다.
- R19. 프로필 항목: 희망 직무, 기술스택(숙련도), 경력 연수, 경력·프로젝트 목록(역할, 한 일, 성과, 사용 기술), 학력, 수상·자격, 강점 요약.
- R20. 항목마다 출처 자료를 기록한다. 자료에 없는 내용은 만들지 않고, 알 수 없는 값은 비워 둔다.
- R21. 사용자가 초안을 항목별로 고친 뒤 저장한다. 채점에는 저장된 프로필만 쓴다.
- R22. 다시 만들면 새 초안을 보여주고, 저장하기 전까지는 기존 프로필이 그대로 쓰인다.
- R23. 프로필을 바꾸면 기존 점수에 "이전 프로필 기준" 표시가 붙고, 사용자가 "다시 채점"을 누를 때만 다시 채점한다.

## 화면 구성
왼쪽: 자료 목록(추가·삭제)과 [프로필 만들기]. 오른쪽: 항목별 편집 칸(출처 표시)과 [저장].
