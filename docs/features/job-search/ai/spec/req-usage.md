# 구직 관리 요구사항: AI 사용량·한도 (R71–R79)

### AI 사용량·한도
- R71. 모델 배정: Haiku 5.5는 메일 분류·항목 추출·인젝션 검사, Opus 5.5는 적합도 채점·프로필 생성. 제공자는 Claude만 쓴다.
- R72. AI 호출은 모두 서버 함수에서 하고, 호출마다 모델, 작업 종류, 토큰 수(입력·출력·캐시), 토큰 수 × 단가로 계산한 비용을 기록한다.
- R73. 한도 기본값은 하루 100회, 월 $10이며 설정에서 바꿀 수 있다. 하루 횟수 한도는 바로 호출에만 적용하고, 일괄 처리는 월 한도로만 막는다(R110). 한도 검사는 서버 함수에서 한다. (L44에서 변경)
- R74. 한도의 80%에 이르면 알림을 보내고, 넘으면 AI 호출을 멈춘다. 미룬 작업은 다음 날(월 한도는 다음 달) 이어서 처리하고, 일괄 처리로 맡기지 못한 공고는 다음 일괄 처리 때 맡긴다. (L44에서 변경)
- R75. 추천 공고 탭에 사용액 줄을 표시한다: 오늘 호출 수/한도, 이번 달 사용액/한도, 기준 잔액, 기준 이후 사용액, 예상 잔액(기준 잔액 − 기준 이후 사용액).
- R76. 설정에서 기준 잔액을 입력하면 그 시점부터 사용액을 $0부터 다시 세고, 입력 기록(날짜, 금액)을 남긴다.
- R77. 남은 크레딧은 API로 조회하지 않고, 사용액은 "이 앱의 호출만 계산한 값"이라고 화면에 적는다.
- R78. API가 크레딧 부족 오류를 돌려주면 작업을 멈추고 알림을 보낸다.
- R79. 모델 단가표는 서버 설정에 두고 바꿀 수 있다.

참고 (명세 시점 확인, 2026-10-06 기준 단가, 100만 토큰당 입력/출력): Opus 5.5 $4/$20, Haiku 5.5 $0.10/$0.50. 일반 API 키로는 잔액 조회 불가. 비용 조회 API는 Admin 키가 필요하고 개인 계정에서는 쓸 수 없다 (공식 문서 확인).
