# 서버 연결 요구사항: 접속 확인·일시정지 (R37–R44)

### 접속 확인
- R37. 서버 연결 정보가 있으면 앱을 켤 때마다 서버에 접속해 상태를 확인한다.
- R38. 접속 확인은 앱 시작을 막지 않는다. 로컬 기능은 바로 쓸 수 있다.
- R39. 접속 확인은 데이터베이스를 실제로 읽는 요청으로 해서, 무료 플랜의 사용 기록으로 남게 한다.
- R40. 상태는 아래 중 하나이고, 상태마다 표시가 다르다.

| 상태 | 안내 띠 | 띠를 누르면 |
|---|---|---|
| 연결됨 | 없음 | — |
| 연결 안 함 | 없음 (서버가 필요한 화면에만 "서버 연결 필요") | 설정 → 서버 연결 |
| 로그인 필요 | "로그인이 필요합니다" | 설정 → 서버 연결 |
| 서버 업데이트 필요 | "서버 업데이트가 필요합니다" | 서버 업데이트 화면 (R23) |
| 앱 업데이트 필요 | "앱을 업데이트하세요" | 설정 → 서버 연결 |
| 일시정지 | "서버가 일시정지됐습니다" | 재개 안내 팝업 (R42) |
| 접속 불가 | "서버에 접속할 수 없습니다" | 설정 → 서버 연결 |

- R41. 안내 띠는 제목 표시줄 바로 아래에 가로로 뜨고, [닫기]로 이번 실행 동안만 숨길 수 있다.

### 일시정지·접속 불가
- R42. 일시정지면 재개 안내 팝업을 띄운다: 이유(무료 플랜은 7일 동안 쓰지 않으면 일시정지), [대시보드에서 재개](기본 브라우저), [PAT로 여기서 재개].
- R43. 재개를 요청하면 서버가 다시 켜질 때까지 진행 표시를 하고 주기적으로 다시 확인한다. 켜지면 "연결됨"으로 바꾸고 띠를 없앤다.
- R44. 접속 불가면 앱이 켜져 있는 동안 몇 분 간격으로 다시 확인한다. 설정 화면의 [지금 다시 확인]으로 바로 확인할 수도 있다.

## 화면 구성
```
┌ 제목 표시줄 ─────────────────────────────────────────┐
├ ⚠ 서버가 일시정지됐습니다. 재개 방법 보기        [×] ┤  ← 안내 띠
│ 사이드바 │ 화면                                       │

재개 안내 팝업:
┌ 서버가 일시정지됐습니다 ──────────────────┐
│ 무료 플랜은 7일 동안 쓰지 않으면 멈춥니다.  │
│ [Supabase 대시보드에서 재개 ↗]              │
│ PAT [••••••]  [여기서 재개]                 │
│ (재개 중… 1~2분 걸릴 수 있습니다)           │
└────────────────────────────────── [닫기] ┘
```
