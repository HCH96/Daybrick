# 서버 연결: 목업에서 정한 것

## 목업
- 경로: [human/mockups/index.html](../../human/mockups/index.html) (2026-10-26 승인, 화면별 파일로 나눔)
- 화면: 1. 첫 실행 안내, 2-1~2-6. 연결 마법사(① 준비, ② 주소·키, ③ 자동 세팅 입력·실행, 로그인, ④ 완료), 3. 설정 → 서버 연결(+ 키 교체·자동 세팅 다시 실행 창, 연결 해제 확인), 4. 안내 띠(+ 재개 안내 팝업), 5. 서버 업데이트·앱 업데이트 안내
- 화면 배치와 스타일은 이 목업을 기준으로 구현한다. 색과 앱 창 틀은 지원 관리 목업의 값을 그대로 쓴다.

### 목업에서 정한 것
| 항목 | 결정 |
|---|---|
| 상태 색 | 연결됨·완료 초록 `#66CF95`/`#1A3428`, 사용자가 할 일(로그인·업데이트·재개·일시정지) 주황 `#F0B860`/`#3A2F1C`, 오류·접속 불가·연결 해제 빨강 `#FF8A8A`/`#3A1F22`, 진행 중·지금 단계 보라(강조색), 연결 안 함 회색 |
| 마법사 틀 | 사이드바 없이 제목 표시줄 아래 전체 창. 위에 진행 표시 4단계, 왼쪽 입력, 오른쪽 460px 가이드, 아래 버튼 줄([취소] 왼쪽, [이전]·[다음] 오른쪽) |
| 진행 표시 | 지난 단계 초록 ✓, 지금 단계 보라 원, 남은 단계 회색 테두리 원. 이미 세팅된 서버면 3번 이름이 "로그인" |
| 가이드 | 번호 목록 + 외부 링크(보라, ↗), 주의 사항은 가이드 맨 아래 주황 상자 |
| "어디서 찾나요?" | 입력칸 바로 아래에 펼침. 메뉴 경로 칩 + Supabase 화면을 흉내 낸 작은 그림 |
| 확인 결과 줄 | 입력칸 아래 같은 자리에 아이콘 + 굵은 제목 + 설명 한 줄. 성공 초록, 오류 빨강, 일시정지 주황, 이미 세팅된 서버·업데이트 필요는 보라 |
| 자동 세팅 입력 | Supabase·Anthropic 묶음과 Google 묶음으로 나눔. 리디렉션 주소 줄(읽기 전용 + [복사])을 Google 칸 위에 둠 |
| 실행 단계 목록 | 한 줄에 표시 원 + 단계 이름·작은 설명 + 오른쪽 상태 글자. 실패한 단계 바로 아래에 이유와 [다시 시도] |
| Google 로그인 버튼 | 밝은 흰색 바탕 + Google 아이콘, 다른 버튼과 구별 (마법사·설정 공통) |
| 설정 화면 | 사이드바 맨 아래 Settings. 칸 머리 오른쪽에 상태 점 + 글자, 정보 행(이름 · 값 · 오른쪽 버튼), 위험한 버튼(바꾸기·연결 해제)은 칸 맨 아래 줄에 따로 |
| 안내 띠 | 제목 표시줄 바로 아래 전체 폭 40px, 본문을 아래로 밀어냄(겹치지 않음). 아이콘 + 굵은 문구 + 밑줄 링크 + 오른쪽 [×] |
| 작은 창 | 앱 창을 어둡게 덮고 가운데 500px(재개 팝업 560px). 머리 아이콘 상자 색으로 성격 표시, 아래 버튼 줄 |
| 데이터 유지 문구 | 연결 해제·바꾸기·자동 세팅 다시 실행 창에 초록 상자로 "서버의 데이터는 지워지지 않습니다" |

### 목업에 넣은 추가 제안 (목업과 함께 승인)
- ② 단계 오른쪽 버튼은 확인 전 [확인], 성공하면 [다음 →]으로 바뀜
- 비밀값 칸은 ●로 가리고 눈 아이콘으로 잠깐 보기
- 브라우저 로그인 대기 중 [브라우저 다시 열기] 버튼
- 자동 세팅 실행 중 위쪽 진행 막대("n / 6 단계")
- 설정의 "연결 안 함" 칸에 서버로 쓸 수 있는 기능 목록
- ④ 완료에 다음에 할 일 3줄(설정 위치, 일시정지 대처, 자동 세팅으로 끝났으면 PAT 지우기 안내)
- 재개 팝업을 닫아도 다시 확인은 계속됨
- 확인 팝업은 [취소]가 기본 버튼

### 계획 단계에서 정할 것 (목업 메모에서 넘어온 것)
- 가이드의 ✓ 표시를 실제로 자동 체크할지
- 자동 세팅 다시 실행 창의 Google 값 칸을 ID·비밀값 두 칸으로 나눌지
- 재개 후 다시 확인 간격, 오류 문구를 원인별로 어떻게 나눌지
