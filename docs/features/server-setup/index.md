# 서버 연결 (server-setup)
사용자마다 자기 Supabase와 Anthropic API 키를 연결하는 기능. 첫 실행 안내·설치 가이드, 빈 서버 자동 세팅, 서버 구조 갱신, 로그인, 접속 확인·일시정지 안내, 설정 화면.

- 상태: 목업 완료
- 이 기능을 먼저 쓰는 기능: notifications, job-search
