## 결정 (계획 중 정함, D1–D7)
- 닫기·종료 판단은 프론트가 한다. Rust는 막고 알리기만 한다 (D1).
- 프론트가 3초 안에 종료 요청에 응답하지 않으면 Rust가 바로 끈다 (D2).
- 종료 전 저장은 전부 합쳐 최대 5초까지만 기다린다 (D3).
- 종료 전 저장은 `app/quit.ts`에 등록한다. `onCloseRequested`는 쓰지 않는다 (D4).
- 첫 실행 자동 등록이 성공했을 때만 `autostartInitialized`를 true로 (D5).
- 개발 모드에서는 자동 시작 스위치를 비활성으로 둔다 (D6).
- 창은 숨긴 채 만들고 시작할 때 보여 줄지 정한다 (D7).

### 작은 규칙
- 로컬 설정 파일 `app-settings.json` (앱 데이터 폴더). 서버로 동기화하지 않는다.
- 자동 시작 인자는 `--autostart`. 이 인자가 있을 때만 창을 띄우지 않는다.
- R4 안내 창의 Esc는 안내만 닫는다 (숨기지 않고, 본 것으로 적지 않음).
- 종료 확인 창이 떠 있는 동안 다시 "종료"를 누르면 무시한다.
- 확인 창 문구: 제목 "앱 종료", 본문 "타이머가 실행 중이에요. 종료할까요?", 버튼 [취소]/[종료].
- R11은 기존 투데이 규칙(D9: 종료 때 `touchRunning`으로 lastSeenAt만 적고 다음 실행 때 복구)을 그대로 쓴다.
