# 백그라운드 실행 요구사항: 창 숨기기·트레이·종료 (R1–R12)

### 창 숨기기
- R1. 제목줄의 닫기(X)를 누르면 앱을 끄지 않고 창만 숨긴다.
- R2. Alt+F4처럼 윈도우가 보내는 닫기 요청도 R1과 똑같이 창만 숨긴다.
- R3. 창이 숨어 있는 동안에도 앱 안에서 돌던 동작(투데이 타이머, 데이터 동기화, 구직 메일 확인 등)은 그대로 계속된다.
- R4. 처음 창을 숨길 때 한 번만 안내 창을 띄운다. 문구는 "창을 닫아도 Daybrick은 트레이에서 계속 실행돼요. 완전히 끄려면 트레이 아이콘에서 '종료'를 누르세요."이고, [확인]을 누르면 창을 숨긴다. 그다음부터는 안내 없이 바로 숨긴다.
- R5. 최소화 버튼은 지금처럼 작업표시줄로 내린다.

### 트레이 아이콘
- R6. 앱이 떠 있는 동안 알림 영역에 Daybrick 아이콘을 둔다. 마우스를 올리면 "Daybrick"이라고 보여 준다.
- R7. 트레이 아이콘을 왼쪽 클릭하면 창을 보여 준다. 최소화돼 있으면 되돌리고, 맨 앞으로 가져와 포커스를 준다.
- R8. 트레이 아이콘을 오른쪽 클릭하면 "열기"와 "종료" 메뉴가 나온다. "열기"는 R7과 같다.

### 종료
- R9. "종료"를 누르면 앱을 완전히 끈다. 앱을 완전히 끄는 방법은 이것 하나뿐이다.
- R10. 종료할 때 투데이 타이머가 실행 중이거나 일시정지 상태면, 창을 보여 주고 "타이머가 실행 중이에요. 종료할까요?" 확인 창을 띄운다. [종료]를 누르면 끄고, [취소]를 누르면 아무것도 하지 않는다.
- R11. 확인하고 종료했을 때 실행 중이던 타이머는 지금 투데이 기능의 규칙대로 처리한다. 이 기능에서 새 규칙을 만들지 않는다.
- R12. 종료하기 전에 아직 저장되지 않은 데이터를 먼저 저장한다.

보충: R11의 지금 규칙은 앱을 다시 켤 때 마지막 확인 시각(lastSeenAt)까지 기록하는 것으로 보인다. 계획 단계에서 투데이 코드로 확인한다.
