# 백그라운드 실행 사용자 테스트 체크리스트 (r1)
작성: 2026-11-09 · 근거: ai/spec/req-tray.md, req-startup.md, ai/plan/step-01~05, 진행 기록 L01–L07
AI는 앱을 띄워 보지 않았습니다. 아래 예상 결과는 명세와 코드 문구를 근거로 적었습니다.

## 준비
1. **앱 데이터 폴더**: 탐색기 주소창에 `%APPDATA%\com.daybrick.desktop`을 입력해 엽니다. `app-settings.json`, `today.json`이 이 폴더에 있습니다. 테스트를 시작하기 전에 폴더 전체를 다른 곳에 복사해 백업합니다.
2. **개발 모드 실행**: `apps/desktop`에서 `npm run tauri dev`를 실행합니다. 1~21번은 개발 모드에서, 22~26번은 설치본에서 확인합니다.
3. **태스크 T**: 투데이 페이지에 태스크 하나를 둡니다(없으면 플랜에서 오늘 태스크를 하나 만듭니다). 이후 "태스크 T"로 부릅니다. 타이머는 카드의 ▶로 시작합니다.
4. **Run 키 확인 명령**: PowerShell에서 아래 명령으로 자동 시작 등록을 봅니다. 이후 "Run 키 확인"으로 부릅니다.
   `reg query HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
5. **작업 관리자**: 프로세스가 끝났는지는 작업 관리자 › 세부 정보 탭에서 `daybrick.exe`가 사라졌는지로 봅니다.
6. 창 크기는 결과에 영향이 없으므로 기본 크기로 진행합니다.
