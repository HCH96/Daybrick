투데이 목업

오늘 태스크 칸반, 태스크 타이머, 오늘 요약, 끝내지 못한 태스크 처리. 기능 없이 배치와 스타일만 보여주는 정적 화면이다.

예시 시점은 2026년 11월 3일(화) 오후 3시 20분. 색과 앱 틀은 플랜 목업과 같다.

  • 1. 투데이 화면타이머 달리는 중, 시작 막힘 안내, 스트릭에 마우스 올린 달력R1–R31, R40–R48
  • 2. 아침 빈 상태타이머 없음, 빈 열 문구, 미완료 버튼 숨김R7, R11, R15, R21
  • 3. 오늘 요약 항목항목을 하나씩 크게, 목표 고치기, 스트릭 달력 두 시점 (R32는 뺌)R27–R31
  • 4. 타이머 카드달리는 중 / 일시정지 / 빈 상태 — 하루 목표 달리기 트랙R16–R21, R40–R47
  • 4-4. 타이머 카드 골인목표 달성 뒤 점프·깃발·색종이, 골인 뒤 일시정지R44–R45
  • 5. 카드 끌기실행 중 카드를 완료 열로 끄는 순간R13
  • 6. 미완료 팝업목록, 가져오기 미리보기, 다른 날 고르기R34–R39
