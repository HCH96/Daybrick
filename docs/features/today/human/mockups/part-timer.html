숫자 (R16, R40–R41)
  • 큰 숫자: 이번 세션에 흐른 시간 H:MM. 초 없음. 일시정지 시간은 빼고 이어서 센다.
  • 달리는 중에는 콜론만 2초마다 은은하게 깜빡인다. 일시정지면 회색으로 멈춘다.
  • 보조 문구: 오늘 이 태스크 누적(지금 세션 포함). 1분 미만은 "막 출발했어요".
트랙 (R42–R43)
  • 하루 전체 기록 / 하루 목표. 캐릭터 가로 위치 = 진행률, 지나온 길·상의 = 지금 태스크의 카테고리 색.
  • 숫자는 숨기고, 마우스를 올리거나 포커스하면 "3:20 / 6:00".
일시정지 · 빈 상태 (R44, R46)
  • 일시정지: 앉아서 눈 감고 숨쉬기, z z Z, 구름 멈춤, 지나온 길 흐리게, 첫 버튼 "재개".
  • 빈 상태: 버튼을 숨기고 캐릭터는 오늘 진행 위치에 서 있다. 아침(0%)은 2. 아침 빈 상태.
