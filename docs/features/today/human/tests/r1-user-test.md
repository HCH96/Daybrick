# 투데이 r1 사용자 테스트 체크리스트
주요 기능만 간단히 본다. 계산·경계 규칙은 AI 테스트(../../ai/tests/r1/)가 맡았다.

## 준비
1. `%APPDATA%\com.daybrick.desktop\` 폴더의 `plan.json`을 다른 곳에 복사해 백업한다 (`today.json`은 아직 없다. 테스트 중 처음 생긴다).
2. `apps/desktop`에서 `npm run tauri dev`로 앱을 켜고 창을 1200x800 정도로 둔다.
3. 플랜 화면에서 카테고리 두 개(아래 "카테고리 1·2")를 쓰는 태스크를 만든다. "오늘"은 PC 날짜다.
   - 태스크 A: 오늘 하루, 시작 전, 카테고리 1
   - 태스크 B: 오늘~모레(3일), 시작 전, 카테고리 2
   - 태스크 C: 오늘 하루, 완료
   - 태스크 D: 날짜 없음
   - 태스크 E: 내일 하루
   - 태스크 F: 끝일이 4일 전인 3일짜리, 진행 중
   - 태스크 G: 끝일이 3일 전인 3일짜리, 시작 전
   - 태스크 H: 끝일이 어제인 하루짜리, 시작 전

- 수행 방법: (1) 시작 전 카드 B를 진행 중 열로 끌어 놓는다. (2) B를 시작 전 열로 되돌리고 ▶로 시작 → 1분 뒤 B를 완료 열 위로 끌고 가서 멈췄다가 놓는다. (3) 다른 카드를 끄는 중에 Esc.

### 13. 미완료 팝업
- 근거 요구사항: R7, R34–R39
- 수행 방법: 진행 바의 `미완료 3` → 팝업 목록 확인 → F(진행 중)에 `오늘로 가져오기` → G(시작 전)에 `다른 날로` → 달력에서 오늘 날짜를 눌러 본 뒤 다음 주 날짜를 골라 "이 날로 미루기" → H에 `완료 처리` → 플랜 달력에서 F·G·H 확인.
- 예상 결과: 진행 바 막대·버튼이 꾸며진 모양이다. 팝업 제목 "끝내지 못한 태스크", 줄마다 카테고리 색·제목·원래 기간·상태·"N일 지남", 많이 지난 순(F, G, H). 버튼에 마우스를 올리면 바뀔 기간이 미리 보인다. F는 시작일 그대로 끝일만 오늘로 늘어난다. 달력에서 오늘까지는 고를 수 없고, G는 3일 길이 그대로 고른 날부터 시작한다. H는 완료. 처리한 줄은 빠지고 버튼 숫자가 줄며, 셋 다 처리하면 팝업이 닫히고 버튼이 사라진다. 플랜 달력도 같은 기간·상태. (달력이 열린 채 Esc를 누르면 달력만 닫힌다)
