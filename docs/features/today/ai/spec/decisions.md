# 투데이: 결정 사항
형식: `D번호. 내용 (적용: …) (기록: L번호)`. 양식은 docs/common/ai/formats/record-format.md의 "결정 올리기".

- D1. PROJECT.md의 "집중 타이머" 기능은 투데이로 합치고, 사이드바 Timer 메뉴를 Today로 바꾼다 (적용: 이후 전체) (기록: L01)
- D2. 태스크 상태는 태스크 하나에 하나다. 여러 날 태스크도 완료하면 전체가 완료된다 (적용: 이후 전체) (기록: L01)
- D3. 시간 기록은 태스크 밖의 별도 목록에 시작·끝 구간으로 쌓고, 합계는 계산한다 (적용: 이후 전체) (기록: L01)
- D4. 하루 목표는 사용자가 오늘 요약의 집중 시간 타일에서만 고치고, 처음 기본값은 6시간(360분)이다. 같은 목표를 스트릭과 타이머 트랙이 함께 쓴다 (적용: 이후 전체) (기록: L02)
- D5. 타이머 카드는 사용자 시안(Bar/Pause/Goal.dc.html)의 배치·크기·애니메이션을 따르고, 색·글꼴은 앱 토큰(common.css 값)으로 바꿔 쓴다. 시안의 IBM Plex 글꼴은 쓰지 않는다 (적용: 이후 전체) (기록: L02)
- D6. 골인 장면(점프·깃발·색종이)은 목표를 넘은 뒤 그날 하루 종일 반복한다 (적용: 이후 전체) (기록: L02)
- D7. 타이머 카드의 상의·지나온 길 색은 지금 태스크의 카테고리 색 한 가지다. 타이머가 없을 때는 앱 강조색(보라)을 쓴다 (적용: 이후 전체) (기록: L02)
- D8. 시간 기록·실행 중 타이머·하루 목표는 앱 데이터 폴더 `today.json` 하나에 두고(플랜 파일과 따로), Rust `load_today`/`save_today`와 0.5초 자동 저장을 쓴다 (적용: 이후 전체) (기록: L04)
- D9. 앱 종료(R24)는 창을 닫을 때 실행 중 타이머의 마지막 확인 시각만 지금으로 적어 저장하고, 기록 옮기기·태스크 시작 전 되돌리기는 다음 실행 때 강제 종료 복구(R25)와 같은 길로 한다 (적용: 4단계 이후 전체) (기록: L04)
- D10. 실행 중 태스크를 다른 화면에서 완료로 바꾸면 타이머 완료, 시작 전으로 바꾸면 중단과 같이 기록한다. 태스크를 지우면 그때까지 기록하고 타이머를 끈다 (적용: 4단계 이후 전체) (기록: L04)
- D11. 메뉴 id `timer`를 `today`로 바꾸고, 홈 카드는 이동할 곳만 고친다 (적용: 1단계) (기록: L04)
