# 투데이: 목업에서 정한 것

## 목업
- 경로: [human/mockups/index.html](../../human/mockups/index.html) (r1·r2·r3 2026-11-03 승인, 화면별 파일로 나눔)
- 화면: 1. 투데이 화면, 2. 아침 빈 상태, 3. 오늘 요약 항목, 4. 타이머 카드, 4-4. 타이머 카드 골인, 5. 카드 끌기, 6. 미완료 팝업
- 화면 배치와 스타일은 이 목업을 기준으로 구현한다. 색과 앱 틀은 플랜 목업과 같은 그라파이트 바이올렛 값(common.css)이다.
- 타이머 카드는 사용자 시안(Bar/Pause/Goal.dc.html)을 옮긴 것이다. 캐릭터 좌표는 sprites.js, 모양·애니메이션 값은 [timer-visual.md](timer-visual.md).

### 목업에서 정한 것
| 항목 | 결정 |
|---|---|
| 배치 | 페이지 제목 `투데이` + 날짜, 아래 이번 주 진행 바 한 줄, 그 아래 칸반 60% : 오른쪽 40%(위 타이머 카드 250px, 아래 오늘 요약) (R3) |
| 이번 주 진행 바 | `이번 주 11/2 – 11/8` + 초록 막대 + `완료 3 / 8`, 오른쪽 끝 빨간 `미완료 N` 버튼. N이 0이면 숨김 (R5–R7) |
| 칸반 열 | 머리에 상태 표시(plan과 같은 모양)·열 이름·개수 칩. 빈 열은 점선 상자 안에 한두 줄 문구 (R8, R15) |
| 칸반 카드 | 왼쪽 카테고리 색 띠 + 제목 + 색 점·카테고리 이름, 여러 날만 `D-N` 칩(마지막 날 주황 `오늘 마감`). 오른쪽 둥근 ▶ 버튼 (R10–R11) |
| 실행 중 카드 | 보라 테두리 + 아래에 보라 점과 `0:42` (초 없음). 다른 카드의 ▶는 자물쇠로 바뀌고 누르면 이유 말풍선 (R11, R48) |
| 완료 카드 | 투명 바탕, 제목만 흐리게(취소선 없음), 끝낸 때 `오늘 11:32 완료` / `11/2 완료` (R9, r2) |
| 카드 끌기 | 놓을 열 전체를 보라 점선 + 옅은 보라 바탕, 끄는 카드는 기울어 따라오고 원래 자리 점선. 타이머 카드면 "놓으면 타이머 완료/중단" 말풍선 (R13) |
| 타이머 카드 (r3) | 제목·배지·초·시작 시각 없음. 카테고리 점·이름·기간 → 제목 → `0:42` 56px(콜론만 깜빡임) → "1시간 20분 달리는 중". 아래 버튼 3개: 일시정지(보라)·완료(초록)·중단(회색) (R16, R40–R41) |
| 달리기 트랙 (r3) | 카드 오른쪽 160×130. 오늘 기록 / 하루 목표만큼 도트 캐릭터가 달려가고, 지나온 길은 지금 태스크 카테고리 색, 남은 길 점선, 끝에 깃발. 숫자는 마우스를 올려야 툴팁 `3:20 / 6:00` (R42–R43, D7) |
| 일시정지 (r3) | 숫자 회색 정지, "달리고 쉬는 중", 캐릭터 앉아서 졸기 + z z Z, 구름 멈춤, 길 흐리게, 첫 버튼 `재개` (R18, R44) |
| 골인 (r3) | 트랙·눈금·깃발을 카테고리 색으로, 금색 꼭지, 캐릭터 두 팔 들고 점프, 색종이 8개. 그날 하루 종일 반복. 골인 뒤 일시정지는 깃발 앞에서 졸기, 색종이 없음 (R45, D6) |
| 타이머 빈 상태 (r3) | "돌고 있는 타이머 없음 / 칸반 카드에서 시작하세요 / 오늘 N 달렸어요", 버튼 대신 안내 한 줄. 캐릭터는 오늘 진행 위치에 서 있고 색은 보라 (R21, R46) |
| 오늘 요약 | 위 타일 3개(집중 `3:20 / 6:00` + 보라 막대·연필, 완료 `2 / 7`, 스트릭 `🔥 4일`), 아래 카테고리별 막대 + 범례, 타임라인(08–24시, 실행 중 구간 빗금, 빨간 지금 선). 남은 기간은 뺐다 (R27–R32, r2) |
| 하루 목표 고치기 | 집중 타일의 연필 → 그 자리에서 `[6]시간 [00]분` + 저장·취소. 기본 6시간, 스트릭·트랙이 같은 목표를 씀 (R27, D4) |
| 스트릭 달력 (r2) | 마우스를 올린 동안만 타일 아래 작은 달력. 요일·월 이름 없이 1~말일 숫자 7개씩, 채운 날 주황 빛, 못 채운 날 꺼짐, 오늘 테두리, 남은 날 흐린 숫자 (R30) |
| 미완료 팝업 | 720px, 머리 "끝내지 못한 태스크" + 빨간 개수. 줄마다 색 점·제목·`N일 지남`(빨강), 둘째 줄 카테고리·원래 기간·상태, 버튼 `오늘로 가져오기`·`다른 날로`·`완료`. 많이 지난 것부터 (R34–R35, R38) |
| 미리보기·날짜 고르기 | 버튼에 마우스를 올리면 오른쪽에 바뀔 기간. `다른 날로`는 팝업 위에 뜨는 달력(월요일 시작), 오늘까지 흐리게, 고른 날부터 기간 길이만큼 칠함 + "이 날로 미루기" (R36–R37) |
