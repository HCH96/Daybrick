# 투데이 요구사항: 페이지·이번 주 진행 바 (R1–R7)

### 페이지
- R1. 사이드바의 Timer 메뉴 자리를 Today(화면 제목 "투데이")로 바꾼다.
- R2. 투데이는 플랜과 같은 태스크 저장소를 읽고 쓰며 새 태스크 데이터를 만들지 않는다. 여기서 바꾼 상태·날짜는 플랜 달력에 바로 반영된다.
- R3. 위쪽에 이번 주 진행 바 한 줄, 그 아래 왼쪽 약 60%에 칸반, 오른쪽 약 40%에 위로 타이머·아래로 오늘 요약을 둔다.
- R4. "오늘"은 PC 시계의 날짜이고, 자정이 지나면 화면을 새 날짜로 다시 그린다.

### 이번 주 진행 바
- R5. 이번 주(월~일, 플랜과 같은 주 계산) 중 하루라도 기간이 걸린 태스크를 대상으로 완료 개수 / 전체 개수를 막대와 숫자("완료 3 / 8")로 보여준다.
- R6. 여러 날 태스크도 1개로 센다.
- R7. 진행 바 오른쪽 끝에 "미완료 N" 버튼을 둔다(R34–R39). N이 0이면 숨긴다.
