# 투데이 요구사항: 오늘 요약 (R27–R33)

### 오늘 요약
- R27. 오늘 집중 시간과 하루 목표 대비 진행도를 보인다. 목표는 기본 6시간이고 요약 칸에서 바로 고친다.
- R28. 완료 개수를 보인다 (오늘 칸반의 완료 / 전체).
- R29. 오늘 시간을 카테고리별로 나눠 보인다.
- R30. 스트릭: 집중 시간이 목표 이상인 날이 며칠 연속인지 보인다. 오늘 아직 목표에 못 미쳤으면 어제까지 이어진 수를 보인다.
- R31. 타임라인: 오늘 시간 구간을 시간 축 위에 카테고리 색 막대로 보인다.
- R32. 오늘 칸반에 있는 여러 날 태스크마다 남은 기간을 보인다.
- R33. R27–R32는 후보다. 목업을 본 뒤 남길 것을 고르고 명세서를 고친다.

목업에서는 가짜 데이터로 채운다 (예: 집중 3시간 20분 / 목표 6시간, C++ 공부 2시간, TrialGround 1시간 20분, 스트릭 4일). 타이머 진행 중 상태와 미완료 팝업이 열린 상태도 볼 수 있게 한다.
