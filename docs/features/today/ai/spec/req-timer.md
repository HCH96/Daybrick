# 투데이 요구사항: 타이머 (R16–R26, R40–R48)
모양·크기·애니메이션 값은 [timer-visual.md](timer-visual.md). 목업: human/mockups/part-timer.html, part-timer-goal.html.

### 타이머 동작
- R16. 카드에서 시작하면 태스크가 진행 중으로 옮겨지고, 타이머 카드에 카테고리 색 점·카테고리 이름·기간, 태스크 제목, 이번 세션에 흐른 시간(R40)이 보인다. (목업 r3에서 변경)
- R17. 타이머는 한 번에 하나만 돈다.
- R18. 일시정지·재개가 있고, 멈춘 동안의 시간은 기록되지 않는다. 일시정지 중에는 첫 버튼이 "재개"로 바뀐다. (목업 r3에서 변경)
- R19. 완료: 흐른 시간을 기록하고 태스크를 완료로 바꾸며 완료한 날을 지금으로 적는다. 여러 날 태스크도 태스크 전체가 완료된다.
- R20. 중단: 흐른 시간을 기록하고 태스크를 시작 전으로 되돌린다.
- R21. 타이머가 돌지 않을 때는 빈 상태 카드(R46)를 보인다. (목업 r3에서 변경)
- R22. 시간은 태스크별 구간(시작 시각~끝 시각)으로 쌓이고, 날짜별 합계는 구간에서 계산한다. 자정을 넘긴 구간은 날짜별로 나눠 센다.
- R23. 다른 메뉴로 가도 타이머는 계속 흐른다.
- R24. 앱이 꺼지면 꺼지는 시각까지 기록하고 중단 처리한다. 지금은 창을 닫으면 앱이 꺼지고, 나중에 백그라운드 상주가 생기면 백그라운드까지 꺼질 때가 기준이다.
- R25. 강제 종료·PC 꺼짐에 대비해 타이머가 도는 동안 마지막 확인 시각을 1분마다 저장하고, 다음 실행 때 그 시각까지 기록하고 중단 처리한다.
- R26. 시작은 한 곳의 시작 흐름을 거친다. 나중에 안드로이드 연동 팝업(QR·숫자 입력)을 이 흐름에 끼울 수 있게 한다 ([extension.md](extension.md)).

### 타이머 카드 표시 (목업 r3, 사용자 시안 Bar/Pause/Goal)
- R40. 큰 숫자는 이번 세션에 흐른 시간을 `H:MM`으로 보인다(초 없음, 예: 0:42, 1:05). 세션은 시작부터 완료·중단까지이고, 일시정지 시간은 빼고 재개하면 이어서 센다. 달리는 중에는 콜론만 2초 주기로 은은하게 깜빡이고, 일시정지 중에는 숫자가 회색으로 멈춘다.
- R41. 숫자 아래 보조 문구는 오늘 이 태스크의 누적 시간(지금 세션 포함)이다. 달리는 중·골인은 "{누적} 달리는 중", 일시정지는 "{누적} 달리고 쉬는 중". 누적은 1시간 미만이면 "N분", 이상이면 "N시간 M분". 1분이 안 됐으면 "막 출발했어요".
- R42. 오른쪽에 하루 목표 달리기 트랙을 둔다. 진행률 = 오늘 전체 기록 시간(모든 태스크, 지금 세션 포함) / 하루 목표(R27). 캐릭터의 가로 위치가 진행률이고, 지나온 길과 캐릭터 상의는 지금 태스크의 카테고리 색 한 가지로 칠한다. 남은 길은 회색 점선, 10%마다 눈금, 끝에 깃발.
- R43. 트랙에는 숫자를 보이지 않고, 마우스를 올리거나 키보드로 포커스하면 툴팁으로 "오늘 기록 / 목표"(예: 3:20 / 6:00)를 보인다.
- R44. 일시정지 중에는 캐릭터가 그 자리에 앉아 눈을 감고 숨쉬듯 들썩이며 머리 위로 z z Z가 떠오른다. 구름은 멈추고 지나온 길은 흐려진다.
- R45. 골인: 진행률이 100% 이상이면 트랙·눈금·깃발을 카테고리 색으로 채우고, 캐릭터는 깃발 앞에서 두 팔을 들고 제자리 점프하며 색종이가 떨어진다. 점프·깃발·색종이는 한 번(2초 안) 재생하고 깃발 앞 만세 자세로 멈춘다(L14에서 변경). 달리는 중에 100%를 넘으면 그 자리에서 골인 장면으로 바뀌고, 타이머와 기록은 계속된다. 넘은 뒤에도 캐릭터는 깃발 앞에 있고 툴팁은 넘은 값 그대로(예: 6:10 / 6:00). 골인 뒤 일시정지하면 깃발 앞에 앉아 졸고(R44), 깃발은 멈추며 색종이는 없다.
- R46. 빈 상태 카드: "돌고 있는 타이머 없음", "칸반 카드에서 시작하세요", 오늘 누적("오늘 3시간 20분 달렸어요", 0이면 "오늘 아직 출발 전이에요")을 보인다. 버튼은 숨기고, 트랙에는 캐릭터가 오늘 진행 위치에 서 있다. 상의·지나온 길은 앱 강조색(보라).
- R47. 운영체제의 "애니메이션 줄이기"가 켜져 있으면 반복 움직임(달리기·점프·색종이·z·구름·콜론 깜빡임)을 멈추고 상태별 자세만 보인다.
- R48. 칸반의 실행 중 카드에도 같은 `H:MM` 흐른 시간을 보인다(초 없음).
