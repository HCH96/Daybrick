## 결정 (계획 중 정함, D8–D11)
- 시간 기록·실행 중 타이머·하루 목표는 앱 데이터 폴더 `today.json` 하나에 둔다. Rust `load_today`/`save_today`, 0.5초 자동 저장 (D8).
- 앱 종료(R24)는 창을 닫을 때 마지막 확인 시각만 지금으로 적어 저장하고, 기록·중단 처리는 다음 실행 때 강제 종료 복구(R25)와 같은 길로 한다 (D9).
- 실행 중 태스크를 다른 화면에서 완료로 바꾸면 타이머 완료, 시작 전으로 바꾸면 중단과 같다. 태스크를 지우면 그때까지 기록하고 타이머를 끈다 (D10).
- 메뉴 id `timer`를 `today`로 바꾼다. 홈 카드는 이동할 곳만 고친다 (D11).

### 작은 규칙
- 지운 태스크의 기록도 합계에 넣고, 카테고리는 회색 "미분류"로 센다.
- 스트릭은 지금 목표를 지난 날에도 같게 적용해 계산한다 (저장하지 않음, data.md).
- 길이 0초 구간은 버린다. 일시정지하면 구간이 닫히고, 재개하면 새 구간을 연다.
- 자정이 지나 실행 중 태스크가 칸반에서 빠져도 타이머는 계속 돈다.
- 카테고리 색은 플랜과 같이 `--cat` 변수로 넘긴다. 타이머 카드·트랙은 `--c` 하나로 칠한다 (D7).
- 화면 시계는 타이머 부품 안에서만 1초마다 갱신한다(페이지 전체를 다시 그리지 않음).
- 순수 함수(`stats.ts`·`overdue.ts`·`format.ts`)는 Node로 실행해 확인한다. 테스트 도구는 아직 없다.
