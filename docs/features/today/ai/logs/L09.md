# L09 · 2026-11-03 · 구현 5단계: 달리기 트랙·애니메이션

- 요구사항: R42–R47 (R46 트랙 부분)
- 한 일: 목업 sprites.js의 run1·run2·sit·cheer·stand 좌표를 `sprites.ts`(`{x,y,w,h,fill,opacity}` 배열, 상의 `var(--c)`)로 옮기고 `Sprite.tsx`로 그린다. `RunTrack`이 오늘 전체 기록/목표로 진행률과 장면(달리는 중·일시정지·골인·골인+일시정지·빈 상태)을 정하고, `TrackScene`이 트랙·눈금·깃발·구름·먼지·z·그림자·색종이와 툴팁(마우스 올림·포커스 때만)을 그린다. keyframes·크기는 목업 timer.css를 `track.css`로 옮겼고, `prefers-reduced-motion: reduce`에서 반복 움직임과 콜론 깜빡임을 끈다. `TimerCard`·`TimerEmpty` 오른쪽 칸에 붙였다.
- 계획과 달라진 점: `RunTrack`도 `useNow(달리는 중)`으로 1초마다 진행률을 다시 계산한다(트랙 부품 안에서만, D12와 같은 방식). 클래스 이름은 앱 방식으로 `track-scene__*`·`track-scene--run/paused/goal/idle`로 바꿨고, 색종이 길이는 목업처럼 각 조각 인라인 값만 쓴다(목업의 nth-of-type 규칙은 인라인 값에 덮여 옮기지 않음). 툴팁 위치는 목업대로 평소 가운데(80), 골인 때 70에 고정 (자동 진행 중 판단)
- 확인: `npm run build` 성공 (타입 검사 포함). Rust는 고치지 않아 `cargo check`는 하지 않았다. 화면은 띄워 보지 않았다
- 사용자 확인: 대기 (최종 테스트)
- 테스트 메모: 진행률 0%면 지나온 길 없이 점선만, 캐릭터는 출발선(left 0). 빈 상태에서 이미 목표를 넘었으면 골인 장면 없이 깃발 앞 끝(left 100)에 서 있다
- 주요 파일: apps/desktop/src/pages/today/timer/RunTrack.tsx, apps/desktop/src/pages/today/timer/TrackScene.tsx, apps/desktop/src/pages/today/timer/track.css, apps/desktop/src/pages/today/timer/sprites.ts
