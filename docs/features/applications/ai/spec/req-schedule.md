# 지원 관리 요구사항: 전형 일정 (R23–R27)

### 전형 일정
- R23. 전형 일정은 속성 목록에 나오지 않는다. 카드 내부 정보로만 저장한다.
- R24. 상태 배지 옆 📅 버튼 옆에 다음 일정 하나만 보여준다 (예: "D-3 코딩테스트"). 카드 아래쪽 줄(R38)과 같은 규칙이라 지원 준비 카드는 지원 마감도 보여준다. 보여줄 날짜가 없으면("지원 완료", "예정된 일정 없음"인 경우 포함) 아무것도 보이지 않는다. (L18에서 변경)
- R25. 📅 버튼을 누르면 작은 창이 열린다. `지원 마감` `과제 마감` `코딩테스트` `면접` 버튼 중 하나를 누르고 작은 달력에서 날짜를 클릭하면 저장된다. (L18에서 변경)
- R26. 같은 창에서 저장된 일정 목록을 보고, 날짜·시간·메모를 고치거나 지울 수 있다.
- R27. 같은 종류의 일정을 여러 개 저장할 수 있다 (예: 1차·2차 면접은 메모로 구분).
- R39. 지원 마감은 카드 하나에 하나만 둔다. 이미 있는데 `지원 마감` 버튼으로 날짜를 다시 고르면 새로 추가하지 않고 그 날짜를 바꾼다.
