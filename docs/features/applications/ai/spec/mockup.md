# 지원 관리: 목업에서 정한 것

## 목업
- 경로: [human/mockups/index.html](../../human/mockups/index.html) (2026-10-22 승인, 화면별 파일로 나눔)
- 화면: 1. 갤러리, 2. 달력, 3. 상세 팝업, 4. 상세 팝업 최대화, 5. 작은 창 모음(상태 선택, 전형 일정 창, 종료 결과 고르기, 선택 항목 추가·색, 속성 추가, 삭제 확인, 종료 카드)

| 항목 | 결정 |

| 상태 색 | 지원 준비 회색 `#CDCDD6`/`#2B2B31`, 지원 완료 파랑 `#7AA8FF`/`#1E2740`, 전형 준비 주황 `#F0B860`/`#3A2F1C`, 결과 대기 초록 `#66CF95`/`#1A3428`, 종료는 바탕 없이 테두리만(보조 글자색) |

| 갤러리 열 수 | 4열, 창 폭이 좁으면 3열 |

### 목업에 넣은 추가 제안 (목업과 함께 승인)
- D-1·당일 일정은 D-day를 빨간색으로 표시
- 카드에 남은 일정이 없으면 "예정된 일정 없음"을 흐리게 표시 (팝업의 📅 옆은 R24대로 비워 둠)
- 팝업 바깥(어두운 부분)을 누르면 닫힘
- 달력 하루 칸에 일정이 3개를 넘으면 "+N개 더"로 접음
