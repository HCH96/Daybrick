# 지원 관리 요구사항: 상세 팝업 (R12–R16)

### 상세 팝업
- R12. 카드를 누르면 앱 안 가운데에 팝업이 뜬다. OS 창이 아니다.
- R13. 왼쪽 위 최대화 버튼을 누르면 본문 영역을 꽉 채운다. 사이드바가 펼쳐져 있으면 사이드바는 남기고, 접혀 있으면 사이드바 자리까지 채운다. 내용은 가운데 정렬로 보여준다.
- R14. 팝업은 위에서부터 제목 → 상태 배지와 일정 버튼 → 속성 목록 → 본문 순서로 구성한다.
- R15. 고치는 즉시 자동 저장한다. 저장 버튼은 없다.
- R16. 카드를 삭제할 수 있고, 삭제 전에 확인 창을 띄운다.
