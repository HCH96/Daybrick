# 지원 관리: 범위

## 이번 범위에서 제외하는 것
- 상세 창을 OS 창으로 따로 띄우기
- 상태 목록 편집
- 댓글 영역
- 지원 경로 속성
- 달력 주 단위 보기, 달력에서 날짜를 눌러 일정 추가
- 카드 순서를 끌어서 바꾸기, 정렬 방식 바꾸기, 필터
- 검색
- 본문 이미지 크기 조절
- Supabase 동기화, 여러 기기 사용

## 나중에 고려할 것
- 캘린더 계획 기능과 지원 일정 연동
- 달력 페이지에서 바로 일정 추가
- 검색, 속성별 필터·정렬
- 본문 템플릿 (공고 내용 / 자소서 메모 / 면접 질문 틀)
- Supabase 동기화와 이미지 저장소 이전
- 공유 웹(친구용 지원 현황 페이지)에 노출
- 일정 알림 (예: 코딩테스트 하루 전)
