# 지원 관리 요구사항: 달력 (R7–R11)

### 달력
- R7. 월 단위 달력에 각 카드의 전형 일정을 표시한다. 형식은 `<카드 제목> · <일정 종류>`다.
- R8. 지원 준비 상태인 카드의 지원 마감 일정은 전형 일정과 구분되게 흐린 색(점선)으로 표시한다. 지원 준비가 아니면 지원 마감은 달력에 나오지 않는다. (L18에서 변경)
- R9. 대기·준비 같은 상태 자체는 달력에 표시하지 않는다.
- R10. 종료된 지원의 지난 일정도 달력에 남긴다.
- R11. 달력의 일정을 누르면 그 카드의 상세 팝업이 열린다.

## 화면 구성

**지원 관리 페이지 (달력)** (R7–R11): 월 이동 버튼과 월 달력이 있고, 날짜 칸마다 `제목 · 일정 종류`가 줄지어 표시된다. 지원 준비 카드의 지원 마감은 흐린 색으로 표시한다.
