# 지원 관리 요구사항: 페이지·갤러리 (R1–R6)

### 지원 관리 페이지
- R1. 페이지 위쪽에 `갤러리 | 달력` 전환 버튼을 둔다. 기본은 갤러리다.
- R2. 오른쪽 위 "+ 새 지원" 버튼으로 카드를 만든다. 새 카드의 상태는 "지원 준비"이고 다른 속성은 모두 "없음"이다.

### 갤러리
- R3. 카드를 바둑판처럼 나열한다.
- R4. 위쪽에 `진행 중 | 종료 | 전체` 탭을 둔다. 기본은 "진행 중"(종료가 아닌 카드)이다.
- R5. 기본 정렬은 마감일이 가까운 순이다. 마감일이 없는 카드는 맨 뒤에 둔다.
- R6. 카드 앞면에는 제목, 상태 배지(세부 단계 포함), 회사, 다음 일정(예: "D-3 코딩테스트"), 우선순위를 보여준다.
