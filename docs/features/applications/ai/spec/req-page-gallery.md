# 지원 관리 요구사항: 페이지·갤러리 (R1–R6)

### 지원 관리 페이지
- R1. 페이지 위쪽에 `갤러리 | 달력` 전환 버튼을 둔다. 기본은 갤러리다.
- R2. 오른쪽 위 "+ 새 지원" 버튼으로 카드를 만든다. 새 카드의 상태는 "지원 준비"이고 다른 속성은 모두 "없음"이다.

### 갤러리
- R3. 카드를 바둑판처럼 나열한다.
- R4. 위쪽에 `진행 중 | 종료 | 전체` 탭을 둔다. 기본은 "진행 중"(종료가 아닌 카드)이다.
- R5. 기본 정렬은 카드 아래쪽 줄에 보이는 날짜(지원 마감 또는 다음 전형 일정, R38)가 가까운 순이다. 날짜가 없는 카드("지원 완료", "예정된 일정 없음")는 맨 뒤에 만든 순서로 둔다. 탭 줄 글자는 "일정 가까운 순"이다. (L18에서 변경)
- R6. 카드 앞면에는 제목, 상태 배지(세부 단계 포함), 회사, 다음 일정(예: "D-3 코딩테스트"), 우선순위를 보여준다.
- R38. 카드 아래쪽 줄(다음 일정)은 상태에 따라 이렇게 보여준다.
  - 지원 준비: 지원 마감과 다음 전형 일정 중 더 가까운 것. 지원 마감은 회색 "D-5 지원 마감".
  - 지원 완료: 지원 마감은 날짜와 상관없이 보이지 않는다. 앞으로 남은 전형 일정이 있으면 그것, 없으면 "지원 완료"(파랑).
  - 전형 준비·결과 대기: 다음 전형 일정, 없으면 "예정된 일정 없음".
  - 종료: 지금처럼 "마지막 일정 M/D 종류" (없으면 "일정 없음").
