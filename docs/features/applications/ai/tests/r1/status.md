## A8. 상태 전환 규칙
- 근거: R18, R20, R21, R22, D13
- 수행 방법: `transitions.ts`의 `changeStatus`, `createStageEvent` 실행. `StatusRow.tsx` 코드 읽기
- 예상 결과:
  - 지원 완료로 바꾸면 오늘 "지원 완료" 일정 생성, 지원일이 비었으면 오늘로 채움, 이미 있으면 그대로
  - 같은 날 "지원 완료" 일정이 이미 있으면 새로 만들지 않음
  - 같은 상태·세부 단계를 다시 고르면 아무것도 안 바뀜
  - 어느 상태에서든 종료로 바꿀 수 있고, 세부 단계는 비워짐. 종료면 결과 고르기 창, 전형 준비 세부면 날짜 창이 이어서 뜸
  - 과제 세부 단계의 날짜는 "과제 마감" 일정. 같은 종류·같은 날 일정이 있으면 안 만듦
- 실제 결과:
  - 지원 준비 → 지원 완료: 일정 `applied 2026-10-23` 1개, 지원일 `2026-10-23`. 지원일이 10/01이면 그대로 10/01
  - 같은 날 지원 완료 일정이 있으면 일정 수 1개 유지
  - 전형 준비·면접 → 전형 준비·면접: 같은 객체를 그대로 돌려줌
  - 지원 준비·지원 완료·전형 준비·결과 대기 → 종료 모두 성공, `stage: null`
  - `StatusRow.pick`: 종료 + 결과 속성 사용 가능 → 결과 창, 전형 준비 + 세부 → 날짜 창(건너뛰기 버튼 있음)
  - 과제 → `assignment-due`, 같은 날 코테가 있으면 null
- 판정: 통과 (검사 12개)
