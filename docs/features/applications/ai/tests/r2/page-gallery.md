- 실제 결과:
  - 지원 준비, 마감 10-25·면접 10-30 → `deadline 10-25, D-2` ("D-2 지원 마감")
  - 지원 준비, 마감 10-30·코테 10-26 → `event coding-test, D-3`
  - 지원 준비, 일정 없음 → `null` → "예정된 일정 없음"
  - 지원 완료, 지원 마감만 있음 → `applied` → 파랑 "지원 완료" (지원 마감은 보지 않음)

  - 결과 대기, 지난 일정만 → `null` → "예정된 일정 없음"
  - 종료, 마감 11-20·면접 10-15·코테 10-08 → `getLastEvent` = 면접 10-15 (더 늦은 지원 마감 제외) → "마지막 일정 10/15 면접"

## A9 정렬 계산
- 테스트 내용: `sortByNextDate` 순서

- 수행 방법: 카드 7장(만든 날 순서를 섞음)으로 실행

- 판정: **통과**
