# r2 · 달력·이번 주 일정 수 (A10, A11)

공통 수행 방법: 시험 파일에서 `npx rolldown` → `node` 실행. 카드 3장: 지원 준비(지원 마감 10-24, 면접 10-24 10:00), 지원 완료(지원 마감 10-22, 코테 10-22), 종료(지원 마감 10-21, 면접 10-21). 오늘 = 2026-10-23(금), 이번 주 = 10-19(월)~10-25(일).

## A10 달력 일정 목록
- 테스트 내용: 달력에 들어가는 일정과 표시 형식
- 근거 요구사항: R8, R7
- 수행 방법: `calendarEntries.ts`의 `groupEntriesByDate` 실행, `CalendarEventChip.tsx`(제목 · 종류, `isDeadline`이면 `cal-ev--deadline` 클래스) 읽음
- 예상 결과: 지원 준비 카드의 지원 마감만 흐린 표시로 포함, 형식 "제목 · 지원 마감"
- 실제 결과:
  - 10-24: `준비카드 · 면접`, `준비카드 · 지원 마감`(isDeadline, 같은 날 맨 뒤)
  - 10-22: `완료카드 · 코딩테스트` (지원 완료 카드의 지원 마감 없음)
  - 10-21: `종료카드 · 면접` (종료 카드의 지원 마감 없음, 전형 일정은 남음)
- 판정: **통과**

## A11 이번 주 일정 수
- 테스트 내용: 페이지 부제의 이번 주 일정 수
- 근거 요구사항: R8 (D21)
- 수행 방법: `schedule.ts`의 `countEventsThisWeek` 실행
- 예상 결과: 지원 마감은 지원 준비 카드일 때만 셈
- 실제 결과: `3` = 준비카드 2(지원 마감 + 면접) + 완료카드 1(코테만, 지원 마감 제외). 종료 카드는 진행 중이 아니라 빠짐.
- 판정: **통과**
