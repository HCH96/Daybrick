## 결정 (계획 중 정함)
- 저장 파일 v1→v2: 앱을 열 때 자동으로 옮기고 곧바로 v2로 저장한다. 백업하지 않는다 (사용자 답, D20).
- D12·D16 없앰(L18 대체), D4·D18은 L18 문구대로 (마감일·지원일 역할 제거, 달력은 지원 마감 일정).

### 작은 규칙
- 새 일정 종류 id `application-due`, 이름 "지원 마감", 회색(흐림). 📅 창 버튼 순서: 지원 마감 → 과제 마감 → 코딩테스트 → 면접.
- 지원 마감은 지원 준비 카드일 때만 센다: 달력, 페이지 부제 "이번 주 일정 N개" (D21). 종료 카드 "마지막 일정"은 전형 일정만 본다.
- 정렬(R5): 날짜가 같거나 둘 다 없으면 만든 순. 종료 탭은 모두 날짜 없음 → 만든 순.
- 옮기기: 마감일 값은 상태와 상관없이 지원 마감 일정 하나로(시간·메모 없음), 속성은 id(`deadline`, `applied-date`)로 찾는다. 지운 속성이면 건너뛴다.
