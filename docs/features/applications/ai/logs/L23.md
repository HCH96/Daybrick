# L23 · 2026-10-23 · 구현 수정1 4단계: 최대화 움직임

- 요구사항: R13
- 한 일:
  - `Modal`의 최대화 층에서 `left` 전환을 기본 규칙(`.modal-layer--max`)에서 빼고, 새 클래스 `.modal-layer--follow`로 옮김.
  - `maximized`가 true가 되면 두 프레임 뒤(새 위치가 그려진 뒤)에 `--follow`를 붙이고, false가 되면 바로 뗌. 그래서 최대화·원래 크기로 바뀌는 순간은 전환 없이 바로 자리 잡고, 최대화한 채 사이드바를 접고 펼 때만 0.15s로 따라감.
  - props 모양은 그대로 (다른 기능도 쓰는 공용 컴포넌트).
- 확인: `npm run build` 통과(번들 크기 경고만). 화면 움직임은 실행해 보지 않음.
- 사용자 확인: 대기 (최종 테스트)
- 주요 파일: `apps/desktop/src/components/common/Modal.tsx`, `Modal.css`
