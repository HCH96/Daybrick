# 지원 관리 (applications) 사용자 테스트 체크리스트 r1

- 작성: 2026-10-23 (AI 초안). AI 테스트 결과: [../../ai/tests/r1/index.md](../../ai/tests/r1/index.md) (16개 모두 통과)
- AI는 앱 화면을 띄워 보지 않았다. 아래 예상 결과는 명세·목업·코드를 근거로 적은 것이다.
- 위에서부터 차례로 진행한다. 앞 항목에서 바꾼 상태를 뒤 항목이 이어서 쓴다.
- 날짜는 "오늘+3일"처럼 테스트하는 날 기준으로 적었다.

## 준비
1. `apps/desktop`에서 `npm run tauri dev`로 앱을 켠다. 창은 처음 크기(1200x800)로 둔다.
2. (기존 데이터가 있으면) `%APPDATA%\com.daybrick.desktop\applications.json`을 다른 곳에 복사해 둔다. 테스트 카드는 끝나고 지워도 된다.
3. 사이드바 "지원 현황"을 누른다.
4. "+ 새 지원"을 4번 눌러 카드 4개를 만들고, 각 카드를 눌러 팝업에서 아래처럼 채운다 (상태는 모두 "지원 준비" 그대로).
   - **카드 A**: 제목 `A 넥슨`, 회사 `넥슨`(새 항목으로 추가), 마감일 오늘+5일, 우선순위 높음
   - **카드 B**: 제목 `B 네오플`, 회사 `네오플`(새 항목), 마감일 오늘+10일, 우선순위 중간
   - **카드 C**: 제목 `C 크래프톤`, 우선순위 낮음 (마감일 없음)
   - **카드 D**: 제목 `D 스마일게이트` (나머지 비움)
5. 본문 붙여 넣기용으로 아무 화면이나 캡처(Win+Shift+S)할 준비를 해 둔다.
