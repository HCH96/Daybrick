# r1 · 달력 (R7–R11)

## A13. 달력 일정 모으기
- 근거: R7, R8, R9, R10, D18
- 수행 방법: `calendarEntries.ts`의 `groupEntriesByDate` 실행 (지원 준비 "넥슨" 마감 10/30·코테 10/29, 전형 준비 "네오플" 마감 10/31·면접 10/30 10:00, 종료 "크래프톤" 면접 10/5). `CalendarDayCell.tsx` 코드 읽기
- 예상 결과:
  - 일정마다 카드 제목 + 종류 라벨 (`네오플 · 면접`)
  - 지원 준비 카드만 마감일을 넣고 표시용 표시(`isDeadline`)를 붙임
  - 상태 자체는 일정으로 만들지 않음
  - 종료 카드의 지난 일정도 남음
  - 같은 날이면 마감일은 맨 뒤
  - 한 칸에 3개가 넘으면 2개 + "+N개 더"
- 실제 결과:
  - 10/30: 네오플 면접 + 넥슨 마감(`isDeadline: true`, 맨 뒤). 네오플의 10/31 마감은 없음
  - 전체 4개(일정 3 + 마감 1)뿐이라 상태용 일정 없음. 10/5 크래프톤 면접 남아 있음
  - 마감일 속성 없이 부르면 3개(마감 건너뜀)
  - `MAX_ROWS = 3`, 넘으면 `slice(0, 2)` + `+{전체-2}개 더`. "더 보기" 창에서 일정을 누르면 창을 닫고 팝업을 엶
- 판정: 통과 (검사 7개 + 코드 읽기)
- 참고: 칸 안의 실제 글자(`제목 · 종류`), 점선·회색·흐림, 클릭으로 팝업 열기(R11)는 사용자 테스트
