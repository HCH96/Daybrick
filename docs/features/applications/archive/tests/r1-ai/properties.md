# r1 · 속성 (R28–R33)

## A11. 속성 종류·기본 속성·종류 변경 막기
- 근거: R28, R29, R31, R33, D6, D8, 계획 결정 3
- 수행 방법: `propertyTypes.ts`, `defaultProperties.ts`, `propertyReducer.ts` 실행. `PropertyMenu.tsx` 코드 읽기
- 예상 결과:
  - 종류 7가지: 텍스트·숫자·선택·다중 선택·날짜·URL·체크박스
  - 기본 속성 10개가 명세 순서·처음 항목대로 있음, 제목·상태는 속성이 아니라 지울 수 없음
  - 역할 속성 5개(결과·회사·마감일·지원일·우선순위)는 종류 변경 불가, 화면과 reducer 둘 다 막음
  - 역할 속성도 삭제는 가능하고, 삭제하면 모든 카드에서 값이 지워짐
  - 빈 이름은 저장 안 함, 속성 삭제는 확인 창
- 실제 결과:
  - 종류 목록 일치. 기본 속성 `결과,회사,직무,공고 링크,마감일,지원일,우선순위,제출 자료,경력 구분,고용 형태`. 결과 항목 `최종 합격,불합격,지원 포기`, 제출 자료 다중 선택 7항목
  - `canChangeType`: 역할 5개만 false. reducer에 마감일 종류 변경을 보내면 상태 그대로
  - 마감일 삭제: 속성 목록에서 빠지고 카드 값도 지워짐
  - `PropertyMenu`: 이름이 공백뿐이면 `rename-property`를 보내지 않음. 삭제는 `ConfirmDialog`를 거침. 역할 속성은 "앱 기능에 쓰이는 기본 속성이라 종류를 바꿀 수 없어요." 안내
- 판정: 통과 (검사 9개 + 코드 읽기)
- 참고: 숫자 쉼표 제거(D8)와 항목 색 고르기(R30)는 화면 입력이라 사용자 테스트로 넘김
