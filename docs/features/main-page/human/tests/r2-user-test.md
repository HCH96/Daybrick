## 준비
1. `apps/desktop`에서 `npm run tauri dev`로 앱을 켠다.
2. 데이터 백업: 앱을 끄고 `%APPDATA%\com.daybrick.desktop` 폴더를 통째로 복사해 둔다 (24번에서 비운 뒤 되돌릴 때 쓴다).
3. 앱을 켜고 다음 데이터를 만든다. 예시 날짜는 오늘 = 11/9 (월) 기준이다. 다른 날 테스트하면 같은 간격으로 옮긴다.
   - **프로젝트 색**: 보라 색 프로젝트(또는 카테고리) "보라", 청록 색 프로젝트 "청록"을 둔다.
   - **태스크 A~E** (플랜, 기간에 오늘 포함): A 진행 중·"보라" 소속, B 시작 전·"청록" 소속, C 시작 전·미분류, D 시작 전, E 완료.
   - **태스크 F**: 2일 전 ~ 2일 뒤(11/11) 기간, 시작 전 (끝나는 날에만 보여야 함).
   - **일정 G**: 오늘 시각 없는 개인 일정 / **일정 H**: 2일 뒤 ~ 5일 뒤(11/11~11/14) 여러 날 개인 일정 / **일정 I**: 10일 뒤 개인 일정 (7일 밖).
   - **일정 L**: 5일 뒤(11/14 토) 18:00 개인 일정 / **일정 M**: 6일 뒤(11/15 일) 시각 없는 개인 일정.
   - **지원 J** (회사 "넥슨"): 오늘 14:00 면접 + 2일 뒤(11/11) 지원 마감. **지원 K**: 20일 뒤 과제 마감.
   - **프로젝트 P1~P5**: 진행 중 5개 (주차형 1개, 단계형 1개 이상, 단계 없는 것 1개 포함, "보라"·"청록"도 여기 포함해도 된다). 1~2개에는 작업 시간을 기록해 둔다.
   - 이렇게 하면 다가오는 7일은 "내일(11/10) 빈 하루"와 "11/12–11/13 이틀 빈 날"이 생긴다. 프로젝트 주차 깃발이 그 사이 날짜에 걸리면 빈 날이 달라지니, 깃발 날짜를 확인해 두고 11번에서 감안한다.
   - 서버 연결·로그인이 된 상태에서 구직 관리 추천 탭을 한 번 열었다 닫는다.
   - 투데이 하루 목표 값을 확인해 둔다 (예시는 6시간).
