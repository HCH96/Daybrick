- 대상 R: R12–R15, R17, R22–R47 · 영향받는 R: R4, R16
- 다시 하는 이전 항목: 없음 (2차 사용자 테스트 11개 통과, 1개 해당 없음)

## 준비
1. `apps/desktop`에서 `npm run tauri dev`로 앱을 켠다.
2. 데이터 백업: 앱을 끄고 `%APPDATA%\com.daybrick.desktop` 폴더를 통째로 복사해 둔다 (18번에서 비운 뒤 되돌릴 때 쓴다).
3. 앱을 켜고 다음 데이터를 만든다 (오늘 = 테스트하는 날, 예시는 11/7 토 기준).
   - **태스크 A~E** (플랜, 기간에 오늘 포함): A 진행 중, B·C·D 시작 전, E 완료. A는 색 있는 카테고리나 프로젝트에 둔다.
   - **태스크 F**: 2일 전 ~ 2일 뒤 기간, 시작 전 (끝나는 날에만 보여야 함).
   - **일정 G**: 오늘 시각 없는 개인 일정 / **일정 H**: 2일 뒤 ~ 5일 뒤 여러 날 개인 일정 / **일정 I**: 10일 뒤 개인 일정 (7일 밖).
   - **지원 J** (회사 "넥슨"): 오늘 14:00 면접 + 2일 뒤 지원 마감. **지원 K**: 20일 뒤 과제 마감.
   - **프로젝트 P1~P5**: 진행 중 5개 (주차형 1개, 단계형 1개 이상, 단계 없는 것 1개 포함). 1~2개에는 작업 시간을 기록해 둔다.
   - 서버 연결·로그인이 된 상태에서 구직 관리 추천 탭을 한 번 열었다 닫는다.
