6. 빈 상태 · 불러오는 중 · 못 읽음

R13, R17, R22, R34, R41, R46

요약 줄 빈 값 (R13)
  • 숫자 대신 회색 문장 한 줄, 칸 높이는 그대로
  • 오늘 집중은 비어도 0:00 / 6:00과 빈 막대
빠른 추가 (R12, R22)
  • 입력 중에는 보라 테두리, 아래에 어디로 들어가는지 작게 안내
  • 공백만 쓰고 Enter는 아무 일도 없음, 화면 이동 없음
카드 상태 (R17)
  • 빈 상태 아이콘은 이동할 메뉴의 아이콘
  • 못 읽음은 이동 버튼 없이 안내만 (제목 링크로는 이동 가능)
