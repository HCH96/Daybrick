# 메인 페이지 요구사항: 기능 화면·공통 (R18–R21)

### 기능 화면
- R18. 아직 만들지 않은 기능 화면은 제목과 "준비 중" 안내를 보여준다.

### 공통
- R19. 색은 어두운 톤 "그라파이트 바이올렛" 하나만 쓴다. 값은 apps/desktop/src/styles/theme.css가 기준이다. (L13에서 변경: 처음에는 차콜 브릭) (L49에서 변경: 바탕·카드·테두리 대비 정리)

  | 역할 | 색 | 쓰는 곳 |
  |---|---|---|
  | 배경 | `#131316` | 본문 전체 바탕 |
  | 사이드바 | `#1C1C20` | 왼쪽 메뉴 영역 |
  | 카드 | `#1F1F24` (한 단계 밝은 칸 `#29292F`) | 요약 카드 바탕 |
  | 테두리 · 진행 막대 바탕 | `#2E2E35` / 막대 바탕 `#34343C` | 카드 테두리, 구분선, 진행 막대/원형 바탕 |
  | 기본 글자 | `#EDEDF2` | 제목, 본문 |
  | 보조 글자 | `#9B9BA8` | 날짜, 시간, 완료한 할 일, 비선택 메뉴 |
  | 강조색 | `#A68CFF` | 선택 메뉴, 버튼, 진행률, D-day, 다음 일정 |
  | 강조 배경 | `#2D2745` | 선택된 메뉴 바탕 |
  | 강조 위 글자 | `#17171A` | 강조색 버튼 위의 글자 |
  | 지원함 | `#CDCDD6` / 바탕 `#2B2B31` | 지원 상태 카드 (바탕은 아이콘 상자에도 사용) |
  | 서류 통과 | `#7AA8FF` / 바탕 `#1E2740` | 지원 상태 카드 |
  | 면접 | `#F0B860` / 바탕 `#3A2F1C` | 지원 상태 카드 |
  | 최종 합격 | `#66CF95` / 바탕 `#1A3428` | 지원 상태 카드 |

- R20. 이모지는 쓰지 않는다. 아이콘이 필요하면 선 아이콘(SVG)을 쓴다. (L13에서 추가)
- R21. 나중에 기능을 연결할 수 있는 확장 지점을 둔다 ([extension.md](extension.md)).
