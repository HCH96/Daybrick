# 메인 페이지 요구사항: 홈 상단·요약 줄·카드 틀 (R10–R17, R22–R28)
카드별 내용은 [req-home-upcoming.md](req-home-upcoming.md) (다가오는 7일), [req-home-cards.md](req-home-cards.md) (나머지 카드).

### 홈 상단
- R10. 오늘 날짜와 요일을 표시한다. (예: 2026년 10월 21일 (수))
- R11. 짧은 인사 문구 한 줄을 표시한다 ("좋은 하루예요", 이모지 없음).
- R12. 오른쪽에 빠른 추가 칸을 둔다. 제목을 쓰고 Enter를 누르면 플랜 태스크를 하나 만든다: 미분류, 오늘 하루짜리(시작·끝 = 오늘), 시작 전 상태. (L34에서 변경)
- R22. 빠른 추가는 빈 제목(공백만 있는 것 포함)을 무시하고, 만든 뒤에는 입력칸을 비우고 포커스를 유지한다. 화면은 이동하지 않는다.

### 요약 줄
- R13. 상단 아래에 요약 줄 4칸(오늘 집중, 오늘 완료, 다음 일정, 가까운 마감)을 둔다. 칸을 누르면 해당 메뉴로 이동한다. (L34에서 변경)

  | 칸 | 보이는 값 | 비었을 때 | 누르면 |
  |---|---|---|---|
  | 오늘 집중 | `3:20 / 6:00` + 작은 진행 막대 | `0:00 / 6:00` | 투데이 |
  | 오늘 완료 | `2 / 5` | "오늘 태스크 없음" | 투데이 |
  | 다음 일정 | `오늘 14:00 넥슨 면접` | "7일 안에 일정 없음" | 캘린더 |
  | 가까운 마감 | `D-2 넥슨 서류 마감` | "남은 마감 없음" | 지원 관리 |

- R23. 오늘 집중은 투데이 시간 기록의 오늘 합계(실행 중인 타이머 포함)와 투데이 하루 목표(투데이 R27)를 쓰고, 타이머가 도는 동안 계속 갱신한다.
- R24. 오늘 완료는 투데이 칸반과 같은 대상(오늘이 기간 안인 태스크)의 완료 수 / 전체 수다.
- R25. 다음 일정은 다가오는 7일(R29) 안의 개인 일정·지원 전형 중 지금 이후 가장 가까운 하나다. 시각이 없는 항목은 그날 하루 내내 "앞으로"로 본다. 날짜는 "오늘 / 내일 / 11/12 (수)"로 쓴다.
- R26. 가까운 마감은 지원 전형 일정 중 서류 마감·과제 마감에서 오늘 이후(오늘 포함) 가장 가까운 하나다. 기간 제한은 없고, 오늘이면 `D-day`로 쓴다.

### 홈 카드
- R14. 본문은 최대 1280px로 가운데 정렬하고 카드는 12칸 벤토 그리드에 놓는다. 다가오는 7일은 큰 카드(7칸×2줄)이고, 나머지 크기와 배치는 목업에서 정한다. 창 너비 1280px 미만이면 모두 6칸. 카드 높이는 창에 맞춰 늘리지 않는다(줄 최소 200px). (L34에서 변경)
- R15. 카드는 6개다. (L34에서 변경)

  | 카드 | 내용 | 이동 | 요구사항 |
  |---|---|---|---|
  | 다가오는 7일 | 오늘~6일 뒤 날짜별 일정·마감 목록 | 캘린더 | R29–R34 |
  | 지금 하는 것 | 실행 중 타이머, 없으면 오늘 태스크 + 시작 | 투데이 | R35–R37 |
  | 이번 주 집중 | 요일별 집중 시간 막대 | 투데이 | R38–R39 |
  | 프로젝트 진행 | 진행 중 프로젝트마다 한 줄 | 프로젝트 | R40–R41 |
  | 지원 현황 | 지금 그대로 | 지원 관리 | R42 |
  | 새 추천 공고 | 새 공고 수 + 상위 3개 | 구직 관리 | R43–R47 |

  빠지는 카드: 오늘 할 일(투데이 칸반과 겹침), 오늘 일정(다가오는 7일로 넓어짐), 오늘 집중 시간(요약 줄과 지금 하는 것으로 옮김).
- R16. 모든 카드는 같은 틀(제목, 오른쪽 위 링크, 본문)을 공유한다. 카드 제목이나 링크를 누르면 해당 메뉴 화면으로 이동한다.
- R17. 카드 본문은 상황에 따라 세 가지 상태를 보인다: 불러오는 중("불러오는 중…"), 못 읽음("○○을 불러오지 못했어요"), 비었음(무엇이 보일지 안내 + 이동 버튼). (L34에서 변경)

### 공통
- R27. 홈은 각 기능의 저장소를 읽기만 한다. 예외는 빠른 추가(R12)와 타이머 조작(R35–R36)이고, 이때도 각 기능의 공용 함수를 쓴다. 다른 화면에서 바꾼 내용은 홈에 바로 보인다.
- R28. "오늘"은 PC 시계의 날짜이고, 자정이 지나면 홈을 새 날짜로 다시 그린다.
