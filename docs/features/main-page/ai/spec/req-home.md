# 메인 페이지 요구사항: 홈 (R10–R17)

### 홈 상단
- R10. 오늘 날짜와 요일을 표시한다. (예: 2026년 10월 21일 (수))
- R11. 짧은 인사 문구 한 줄을 표시한다 ("좋은 하루예요", 이모지 없음).
- R12. 오른쪽에 할 일 빠른 추가 칸을 둔다. 지금은 비활성으로만 보여준다 ("할 일 기능을 만들면 사용할 수 있어요"). (L15에서 추가)
- R13. 그 아래 요약 줄 4칸(오늘 할 일, 오늘 집중, 다음 일정, 가장 가까운 마감)을 둔다. 지금은 값 "—"와 "○○ 연결 전"을 보여주고, 눌러도 이동하지 않는다. (L15에서 추가)

### 홈 카드
- R14. 본문은 최대 1280px로 가운데 정렬하고, 카드는 12칸 벤토 그리드로 놓는다 (할 일 7칸×2줄, 일정·집중·이번 주 5칸, 지원 7칸). 창 너비 1280px 미만이면 모두 6칸. 카드 높이는 창에 맞춰 늘리지 않는다(줄 최소 200px). (L14에서 변경: 처음에는 2열 그리드)
- R15. 카드는 5개다. (이번 주 집중은 L14에서 추가)

  | 카드 | 나중에 보여줄 내용 | 지금 표시 |
  |---|---|---|
  | 오늘 할 일 | 오늘 날짜의 할 일 목록, 완료 개수 | 빈 상태 + [캘린더로 가기] |
  | 오늘 일정 | 오늘 일정을 시간순으로 | 빈 상태 + [스케줄러로 가기] |
  | 지원 현황 | 상태별 지원 개수(지원함/서류 통과/면접/결과) | 빈 상태 + [지원 현황으로 가기] |
  | 오늘 집중 시간 | 오늘 누적 집중 시간, 타이머 시작 버튼 | 빈 상태 + [타이머로 가기] |
  | 이번 주 집중 | 요일별 집중 시간 막대 | 월~일 납작한 막대, 오늘 요일 강조, "타이머를 연결하면 기록이 쌓여요" |

- R16. 모든 카드는 같은 틀(제목, 오른쪽 위 링크, 본문)을 공유한다. 카드 제목이나 버튼을 누르면 해당 메뉴 화면으로 이동한다.
- R17. 기능이 연결되기 전 카드 본문은 빈 상태("아직 연결되지 않았어요" + 무엇이 보일지 안내 + 이동 버튼)로 보여준다.
