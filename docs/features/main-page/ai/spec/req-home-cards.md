# 메인 페이지 요구사항: 홈 나머지 카드 (R35–R47)

### 지금 하는 것
- R35. 타이머가 실행 중이거나 일시정지 상태면 카테고리·프로젝트 색과 이름, 상태, 태스크 제목, 이번 세션 경과 시간(1초마다 갱신, 가운데 큰 숫자), 오늘 집중 합계와 하루 목표 막대, [일시정지/재개]·[완료]·[중단]을 보인다. 실행 중에는 태스크의 카테고리·프로젝트 색을 카드 위 띠·시계 초·막대에 쓰고, 일시정지면 색을 뺀다. 투데이의 공용 타이머 저장소를 그대로 써서 결과도 투데이와 같다. 달리기 트랙 그림은 넣지 않는다. (L49에서 변경: "오늘 이 태스크" 줄 대신 오늘 집중 막대, 프로젝트 색)
- R36. 실행 중인 타이머가 없으면 오늘이 기간 안인 미완료 태스크를 최대 3개(투데이 칸반 순서: 진행 중 → 시작 전) 보이고, 줄마다 [▶ 시작]을 둔다. 시작은 투데이와 같은 시작 흐름(투데이 R26)을 거친다.
- R37. 3개를 넘으면 아래에 "외 N개 · 투데이에서 보기"를 둔다. 0개면 빈 상태("오늘 할 태스크가 없어요" + [투데이로 가기]).

### 이번 주 집중
- R38. 이번 주(월~일, 플랜과 같은 주 계산) 요일별 집중 시간을 막대로 보이고, 오늘 요일을 강조한다. 실행 중인 타이머도 포함하고, 아직 안 온 요일은 빈 막대다.
- R39. 하루 목표 높이에 가로 기준선을 긋고, 카드 위쪽에 이번 주 합계("이번 주 18시간 40분")를 쓴다. 막대에 마우스를 올리면 그날 시간이 보인다.

### 프로젝트 진행
- R40. 진행 중 프로젝트(프로젝트 화면 순서)를 최대 4개 한 줄씩 보인다: 색 점·이름, 현재 자리(주차형 "3주차 / 8", 단계형 "2단계 · 단계 이름"), 진행 막대(끝난 단계 + 다음 단계 완료 비율, 프로젝트 R23과 같은 계산), 누적 시간.
- R41. 4개를 넘으면 "외 N개"를 쓴다. 줄을 누르면 프로젝트 화면으로 이동한다. 진행 중 프로젝트가 없으면 빈 상태(+ [프로젝트로 가기]).

### 지원 현황
- R42. 지금 내용(종료를 뺀 상태별 개수와 세부 단계 개수, 지원 관리 R36–R37)을 그대로 쓴다. 칸은 색 바탕 대신 회색 칸 + 왼쪽 상태색 띠 + 상태색 숫자로 보인다. (L49에서 변경)

### 새 추천 공고
- R43. 서버 연결과 로그인이 되어 있을 때만 구직 관리의 추천 공고를 서버에서 읽는다. 언제 다시 읽을지는 계획 단계에서 정한다.
- R44. "새 공고"는 구직 관리 추천 탭의 new 표시와 같은 기준(탭을 마지막으로 떠난 시각 뒤에 수집된 공고, 구직 관리 R8)이고, 마감이 지난 공고는 뺀다(구직 관리 R5).
- R45. "새 공고 N개"와 함께 적합도 높은 순 상위 3개(회사·제목·D-n·점수)를 보인다. 공고를 누르면 구직 관리 추천 탭으로 이동한다.
- R46. 새 공고가 0개면 "새 추천 공고가 없어요"와 마지막 수집 시각을 보인다. 서버가 연결되지 않았으면 "서버를 연결하면 추천 공고가 보여요" + [구직 관리로 가기]를 보인다.
- R47. 홈에서 보는 것으로는 new 기준 시각을 바꾸지 않는다.
