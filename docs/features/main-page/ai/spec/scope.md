# 메인 페이지: 범위

## 이번 범위에서 제외하는 것
- 할 일, 일정, 지원, 타이머의 실제 데이터 저장/조회
- 빠른 추가의 실제 입력 처리 (비활성으로만 표시)
- Supabase 연동, 로그인
- 라이트/다크 전환 기능, 설정 화면
- 반응형(모바일) 대응. PC 창 크기만 고려한다.
- 자정이 지났을 때 날짜 자동 갱신
