# 메인 페이지: 범위

## 이번 범위에서 제외하는 것
- 카드 순서·표시 여부를 사용자가 고르는 기능 (L34)
- 홈에서 일정·태스크를 직접 고치기. 빠른 추가만 가능하다 (L34)
- 항목을 눌러 상세 팝업 열기, 캘린더의 특정 날짜로 바로 가기 (L34)
- 제목 표시줄에 타이머 보이기 (L34)
- Supabase 연동 자체, 로그인 (서버 연결 기능이 맡는다)
- 라이트/다크 전환 기능
- 반응형(모바일) 대응. PC 창 크기만 고려한다.

L34에서 제외 목록에서 뺀 것: 실제 데이터 저장/조회 연결, 빠른 추가의 실제 입력 처리, 자정이 지났을 때 날짜 자동 갱신 (이제 R12·R27·R28로 범위 안).

## 나중에 고려할 것
- 화면이 많아지거나 화면 안에 하위 경로가 필요해지면 라우터(react-router) 도입 ([extension.md](extension.md) 3)
- 남은 개선 후보 (2차 테스트 참고 사항, L29): "로/으로"의 영문·숫자 처리, 카드 버튼으로 이동한 뒤의 키보드 포커스 위치
