# 메인 페이지: 결정 사항

형식: `D번호. 내용 (적용: 범위) (기록: L번호)`.
- D1. 메뉴 구성: "캘린더"와 "스케줄러"를 따로 둔다. (적용: 이후 전체) (기록: L02)
- D2. 홈 카드에 "오늘 집중 시간"을 넣는다. D4로 대체해 이 카드는 빠진다. (적용: L34 전까지) (기록: L02) (L34에서 변경)
- D3. 창 크기 1200x800 (최소 960x640은 구현 때 적용). 높이 720 대안을 검토했으나 800으로 확정. (적용: 이후 전체) (기록: L02)
- D4. 홈은 오늘을 처리하는 화면이 아니라 앞으로 일주일과 앱 전체를 요약하는 화면으로 한다. 투데이와 겹치는 "오늘 할 일"·"오늘 집중 시간" 카드는 뺀다. (적용: 이후 전체) (기록: L34)
- D5. 빠른 추가로 만든 태스크는 미분류·오늘 하루짜리·시작 전으로 한다. (적용: 이후 전체) (기록: L34)
- D6. 다가오는 7일은 오늘부터 7일이고, 플랜 태스크는 끝나는 날에만 넣는다. (적용: 이후 전체) (기록: L34)
- D7. 가까운 마감은 지원 서류 마감·과제 마감만 센다. (적용: 이후 전체) (기록: L34)
- D8. 새 추천 공고는 구직 관리 new 표시와 같은 기준을 쓰고, 홈은 그 기준 시각을 바꾸지 않는다. (적용: 이후 전체) (기록: L34)
