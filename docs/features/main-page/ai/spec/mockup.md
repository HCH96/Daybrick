### 목업에서 정한 것
- 배치 (R14): 1줄·2줄 = 다가오는 7일 7칸×2줄 + 오른쪽에 지금 하는 것 5칸, 이번 주 집중 5칸. 3줄 = 프로젝트 진행·지원 현황·새 추천 공고 각 4칸. 창 높이를 넘으면 본문이 스크롤된다.
- 카드 링크는 "캘린더 ›"처럼 메뉴 이름 + ›. 요약 줄 칸은 오른쪽 위에 이동할 곳을 흐리게 적고, 마우스를 올리면 칸이 밝아진다.
- 요약 줄: 급한 값(다음 일정 날짜·시각, D-n)만 강조색. 오늘 집중 아래에 목표 대비 가는 막대. 빈 값은 숫자 대신 회색 문장.
- 다가오는 7일: 오늘 날짜 머리는 강조색 + "11/7 (토)"를 작게. 줄 높이 32px, 마우스를 올리면 줄 배경이 밝아짐. 지원 줄 오른쪽 끝에 전형 종류 아이콘(면접만 강조색). 아래는 흐림 처리 + 얇은 스크롤 막대.
- 지금 하는 것: 경과 시간은 고정폭 큰 숫자 + 상태 알약(진행 중 초록, 일시정지 주황). 버튼 [일시정지/재개]·[완료]·[중단]에서 실행 중엔 [완료], 일시정지엔 [재개]를 강조. 타이머가 없으면 태스크 줄마다 상태와 [▶ 시작], 첫 줄만 강조.
- 이번 주 집중: 지난 요일은 어두운 보라, 오늘만 강조색, 안 온 요일은 납작한 회색 막대. 하루 목표는 점선 + "목표 6시간". 마우스를 올리면 막대 위에 "11/5 (목) 4시간" 말풍선.
- 프로젝트 진행: 한 프로젝트 두 줄(색 점·이름·누적 시간 / 현재 자리·프로젝트 색 진행 막대).
- 지원 현황: 지금 카드 내용을 4칸 폭에 맞게 2×2 타일로.
- 새 추천 공고: "새 공고 N개", 줄마다 이니셜 배지·회사·제목·D-n·점수. 점수 80 이상 보라, 미만 회색. D-7 이하 주황. 아래에 마지막 수집 시각.
- 상태 (R17): 빈 상태는 이동할 메뉴의 아이콘 + 안내 두 줄 + 이동 버튼. 불러오는 중은 회색 줄 3개 + "불러오는 중…". 못 읽음은 빨간 아이콘·문장만(이동 버튼 없음).
- 빠른 추가: 입력 중 보라 테두리, 아래에 "플랜에 오늘 할 일로 추가돼요 (미분류)" 안내.
- 제목 표시줄 오른쪽에 알림 종(알림 기능 목업과 같은 자리), 사이드바는 지금 메뉴(Home·Plan·Projects·Calendar·Applications·Job Search·Today, 아래 Settings).
