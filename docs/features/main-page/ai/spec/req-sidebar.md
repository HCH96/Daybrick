# 메인 페이지 요구사항: 사이드바 (R5–R9)

### 사이드바
- R5. 맨 위에 앱 이름(Daybrick), 그 아래 메뉴 5개, 맨 아래에 버전을 표시한다.

  | 메뉴 (화면 제목·카드 버튼) | 사이드바 표시 이름 | 연결될 기능 (PROJECT.md) | 이번 작업에서 |
  |---|---|---|---|
  | 홈 | Home | 메인 대시보드 | 대시보드 화면 |
  | 캘린더 | Calendar | 캘린더 계획 | 빈 페이지 |
  | 스케줄러 | Scheduler | 일정 관리 | 빈 페이지 |
  | 지원 현황 | Applications | 지원 관리 | 빈 페이지 |
  | 타이머 | Timer | 집중 타이머 | 빈 페이지 |

- R6. 사이드바에는 영어 이름을, 화면 제목과 "○○로 가기" 버튼에는 한글 이름을 쓴다. (L13에서 추가)
- R7. 현재 선택된 메뉴는 강조 표시하고, 메뉴를 누르면 본문이 해당 화면으로 바뀐다.
- R8. 사이드바 너비는 약 200px 고정이다. 제목 표시줄 버튼과 `Ctrl+B`로 접고 펼치며, 접힘 상태는 다시 켜도 유지된다. (L19에서 변경: 처음에는 접기 기능 없음)
- R9. 뒤로·앞으로 버튼, `Alt+←/→`, 마우스 옆 버튼으로 방문 기록을 오간다. (L19에서 추가)
