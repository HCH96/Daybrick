# 메인 페이지 요구사항: 홈 다가오는 7일 (R29–R34)

### 다가오는 7일
- R29. 오늘부터 6일 뒤까지 7일을 날짜별로 묶어 보여준다. 날짜 머리는 "오늘", "내일", 그 뒤는 "11/10 (화)".
- R30. 항목은 캘린더와 같은 규칙으로 모으고(캘린더 R8–R17), 네 종류를 넣는다: 개인 일정, 지원 전형(서류 마감·과제 마감·코딩 테스트·면접), 프로젝트 주차 깃발, 플랜 태스크.
- R31. 플랜 태스크는 끝나는 날에만 한 번 넣고, 완료된 태스크는 뺀다. 여러 날 개인 일정은 7일 안의 첫날에 한 번 넣고 끝날(`~11/12`)을 붙인다.
- R32. 한 날짜 안에서는 시각이 있는 항목을 시각 순으로 먼저 놓고, 그다음 시각이 없는 항목을 캘린더 순서(지원 → 깃발 → 개인 → 태스크)로 놓는다.
- R33. 각 줄은 종류 표시(태스크는 카테고리·프로젝트 색 점, 지원은 회사 이니셜 배지, 깃발은 프로젝트 색 깃발, 개인 일정은 기본 색 점), 시각(있을 때), 제목을 보인다. 항목이 없는 날은 날짜 머리 한 줄만 흐리게 보인다.
- R34. 내용이 카드 높이를 넘으면 카드 안에서 스크롤한다. 줄을 누르면 캘린더로 이동한다. 7일 모두 비었으면 빈 상태("앞으로 7일 동안 일정이 없어요" + [캘린더로 가기])를 보인다.
