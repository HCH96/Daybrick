docs/ai/features 아래에서 "$ARGUMENTS" 기능의 명세서를 찾아 읽고 구현 계획을 세워줘.
명세서를 찾지 못하면 계획을 세우지 말고 나에게 알려줘.
이미 진행 기록 파일(docs/ai/logs/<기능명>-log*.md)이 있으면 최신 파일의 목차를 확인하고, 필요한 항목만 읽어줘.
목업이 있으면 맨 앞 목업 목차만 읽고 필요한 ID 구역만 읽어줘.

아직 코드는 작성하지 마.

계획에는 다음을 넣어줘.
1. 만들거나 수정할 파일 목록
2. 컴포넌트 구조
3. 구현 순서 (단계별)
4. 단계마다 내가 확인할 수 있는 결과
5. 단계마다 참고할 목업 구역 ID와 관련 요구사항 번호 (예: `applications.html#parts-status`, R18–R19)

계획을 보여준 뒤 내가 승인하면 다음을 해줘.
- docs/ai/plans/<기능명>-plan.md로 저장
- 해당 기능 명세서의 "## 구현 계획" 절에 계획 문서 경로(승인 날짜)와 계획에서 정한 것 한두 줄을 기록
- DOCS_INDEX.md에 경로와 한 줄 설명을 추가
- 진행 기록 파일에 "계획" 항목을 남기기 (/implement 명령의 "진행 기록 쓰는 법". 이전 작업 묶음이 테스트까지 끝난 뒤의 새 계획이면 새 기록 파일로 넘어간다)
- 계획 중 정한 결정 중 앞으로 지켜야 할 것은 명세서 결정 사항에 D 번호로 올리기 (/implement 명령의 "결정 올리기")
